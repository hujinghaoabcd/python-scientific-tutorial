# 假设检验

假设检验是统计推断的核心方法，用于判断观察到的差异是否具有统计学意义。

## 什么是假设检验？

**通俗理解**：判断观察到的现象是真实存在，还是随机偶然发生的。

**生活例子**：
- 新药是否真的有效？还是安慰剂效应？
- 两个班级的成绩差异是真的，还是抽样误差？
- 广告改版后转化率提高了，是真的有效还是运气好？

## 核心概念

### 原假设（H₀）和备择假设（H₁）

**原假设 H₀**：没有效果、没有差异（保守假设）
**备择假设 H₁**：有效果、有差异（我们想证明的）

**例子**：
- H₀：新药无效（μ = 0）
- H₁：新药有效（μ ≠ 0）

### p 值（p-value）

**定义**：在原假设为真的情况下，观察到当前结果或更极端结果的概率。

**通俗解释**：如果没有真实差异，看到这么大差异的概率是多少？

**判断准则**：
- p < 0.05：拒绝原假设（有显著差异）
- p ≥ 0.05：无法拒绝原假设（无显著差异）

### 显著性水平 α

常用：α = 0.05（5%）
严格：α = 0.01（1%）
宽松：α = 0.10（10%）

### 两类错误

**I 型错误（假阳性）**：
- 原假设为真，但被拒绝
- 概率 = α

**II 型错误（假阴性）**：
- 原假设为假，但未被拒绝
- 概率 = β

## t 检验

### 单样本 t 检验

检验样本均值是否与已知值有显著差异。

```python
from scipy import stats
import numpy as np

# 问题：某班学生平均身高是否显著不同于全国平均 170 cm？
heights = np.array([168, 172, 165, 180, 175, 171, 169, 173, 170, 167,
                    174, 169, 172, 168, 176, 171, 170, 169, 173, 172])

# 单样本 t 检验
# H₀: μ = 170
# H₁: μ ≠ 170
t_stat, p_value = stats.ttest_1samp(heights, 170)

print("=" * 60)
print("单样本 t 检验")
print("=" * 60)
print(f"样本均值: {np.mean(heights):.2f} cm")
print(f"样本标准差: {np.std(heights, ddof=1):.2f} cm")
print(f"样本数: {len(heights)}")
print(f"\nt 统计量: {t_stat:.4f}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：拒绝原假设 (α=0.05)")
    print("样本均值与 170 cm 有显著差异")
else:
    print("\n结论：无法拒绝原假设 (α=0.05)")
    print("样本均值与 170 cm 无显著差异")
```

### 独立样本 t 检验

比较两个独立样本的均值。

```python
# 问题：男生和女生的考试成绩是否有显著差异？
male_scores = np.array([85, 78, 92, 88, 79, 91, 84, 87, 90, 82])
female_scores = np.array([88, 94, 89, 92, 95, 87, 91, 93, 90, 88])

# 独立样本 t 检验
t_stat, p_value = stats.ttest_ind(male_scores, female_scores)

print("=" * 60)
print("独立样本 t 检验")
print("=" * 60)
print(f"男生均值: {np.mean(male_scores):.2f}")
print(f"女生均值: {np.mean(female_scores):.2f}")
print(f"差异: {np.mean(female_scores) - np.mean(male_scores):.2f}")
print(f"\nt 统计量: {t_stat:.4f}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：两组成绩有显著差异")
else:
    print("\n结论：两组成绩无显著差异")

# 可视化
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 6))
plt.boxplot([male_scores, female_scores], labels=['男生', '女生'])
plt.ylabel('考试成绩')
plt.title(f'成绩对比 (p = {p_value:.4f})')
plt.grid(True, alpha=0.3, axis='y')
plt.show()
```

### 配对样本 t 检验

比较同一组对象在两种条件下的测量值。

```python
# 问题：训练前后的成绩是否有显著提高？
before_training = np.array([65, 70, 68, 72, 69, 71, 67, 73, 70, 68])
after_training = np.array([70, 75, 72, 78, 73, 76, 71, 77, 74, 72])

# 配对样本 t 检验
t_stat, p_value = stats.ttest_rel(before_training, after_training)

improvement = after_training - before_training

print("=" * 60)
print("配对样本 t 检验")
print("=" * 60)
print(f"训练前均值: {np.mean(before_training):.2f}")
print(f"训练后均值: {np.mean(after_training):.2f}")
print(f"平均提高: {np.mean(improvement):.2f}")
print(f"\nt 统计量: {t_stat:.4f}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：训练显著提高了成绩")
else:
    print("\n结论：训练效果不显著")

# 可视化配对数据
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
x = np.arange(len(before_training))
plt.plot(x, before_training, 'o-', label='训练前', markersize=8)
plt.plot(x, after_training, 's-', label='训练后', markersize=8)
for i in range(len(x)):
    plt.plot([i, i], [before_training[i], after_training[i]],
             'k--', alpha=0.3)
plt.xlabel('学生编号')
plt.ylabel('成绩')
plt.legend()
plt.title('训练前后成绩对比')
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.bar(range(len(improvement)), improvement, edgecolor='black')
plt.axhline(0, color='r', linestyle='--')
plt.xlabel('学生编号')
plt.ylabel('成绩提高')
plt.title(f'个体提高量 (p = {p_value:.4f})')
plt.grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()
```

## 卡方检验

### 独立性检验

检验两个分类变量是否独立。

```python
from scipy.stats import chi2_contingency

# 问题：性别和产品偏好是否独立？
# 列联表
observed = np.array([
    [30, 20],  # 男性：喜欢产品A 30人，喜欢产品B 20人
    [10, 40]   # 女性：喜欢产品A 10人，喜欢产品B 40人
])

chi2, p_value, dof, expected = chi2_contingency(observed)

print("=" * 60)
print("卡方独立性检验")
print("=" * 60)
print("观测频数:")
print("           产品A  产品B")
print(f"男性        {observed[0,0]:3d}    {observed[0,1]:3d}")
print(f"女性        {observed[1,0]:3d}    {observed[1,1]:3d}")

print("\n期望频数（假设独立）:")
print("           产品A  产品B")
print(f"男性      {expected[0,0]:5.1f}  {expected[0,1]:5.1f}")
print(f"女性      {expected[1,0]:5.1f}  {expected[1,1]:5.1f}")

print(f"\nχ² 统计量: {chi2:.4f}")
print(f"自由度: {dof}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：性别和产品偏好不独立（有关联）")
else:
    print("\n结论：性别和产品偏好可能独立")

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 堆叠条形图
categories = ['男性', '女性']
products = ['产品A', '产品B']

axes[0].bar(categories, observed[:, 0], label='产品A', alpha=0.7)
axes[0].bar(categories, observed[:, 1], bottom=observed[:, 0],
            label='产品B', alpha=0.7)
axes[0].set_ylabel('人数')
axes[0].set_title('观测频数')
axes[0].legend()
axes[0].grid(True, alpha=0.3, axis='y')

# 比例图
proportions = observed / observed.sum(axis=1, keepdims=True)
axes[1].bar(categories, proportions[:, 0], label='产品A', alpha=0.7)
axes[1].bar(categories, proportions[:, 1], bottom=proportions[:, 0],
            label='产品B', alpha=0.7)
axes[1].set_ylabel('比例')
axes[1].set_title(f'偏好比例 (p = {p_value:.4f})')
axes[1].legend()
axes[1].grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()
```

## 方差分析（ANOVA）

比较三组或更多组的均值。

```python
from scipy.stats import f_oneway

# 问题：三种教学方法的效果是否有显著差异？
method_a = np.array([78, 82, 75, 80, 79, 81, 77, 83])
method_b = np.array([85, 88, 86, 89, 87, 90, 84, 88])
method_c = np.array([72, 75, 73, 76, 74, 77, 71, 75])

# 单因素方差分析
f_stat, p_value = f_oneway(method_a, method_b, method_c)

print("=" * 60)
print("单因素方差分析 (ANOVA)")
print("=" * 60)
print(f"方法A均值: {np.mean(method_a):.2f}")
print(f"方法B均值: {np.mean(method_b):.2f}")
print(f"方法C均值: {np.mean(method_c):.2f}")
print(f"\nF 统计量: {f_stat:.4f}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：至少有一组的均值与其他组显著不同")
else:
    print("\n结论：三组均值无显著差异")

# 可视化
plt.figure(figsize=(10, 6))
plt.boxplot([method_a, method_b, method_c], labels=['方法A', '方法B', '方法C'])
plt.ylabel('成绩')
plt.title(f'三种教学方法效果对比 (p = {p_value:.4f})')
plt.grid(True, alpha=0.3, axis='y')
plt.show()
```

## 非参数检验

当数据不满足正态分布假设时使用。

### Mann-Whitney U 检验（非参数版 t 检验）

```python
from scipy.stats import mannwhitneyu

# 非正态分布的数据
group1 = np.array([5, 7, 8, 10, 12, 15, 18, 20, 25, 30])
group2 = np.array([3, 6, 9, 11, 14, 16, 19, 22, 28, 35])

# Mann-Whitney U 检验
u_stat, p_value = mannwhitneyu(group1, group2, alternative='two-sided')

print("=" * 60)
print("Mann-Whitney U 检验（非参数）")
print("=" * 60)
print(f"组1中位数: {np.median(group1):.2f}")
print(f"组2中位数: {np.median(group2):.2f}")
print(f"\nU 统计量: {u_stat:.4f}")
print(f"p 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：两组分布有显著差异")
else:
    print("\n结论：两组分布无显著差异")
```

### Wilcoxon 符号秩检验（非参数版配对 t 检验）

```python
from scipy.stats import wilcoxon

# 配对数据（非正态）
before = np.array([5, 7, 10, 8, 12, 15, 9, 11])
after = np.array([8, 9, 12, 10, 15, 18, 11, 14])

# Wilcoxon 符号秩检验
stat, p_value = wilcoxon(before, after)

print("=" * 60)
print("Wilcoxon 符号秩检验（非参数）")
print("=" * 60)
print(f"前测中位数: {np.median(before):.2f}")
print(f"后测中位数: {np.median(after):.2f}")
print(f"\np 值: {p_value:.4f}")

if p_value < 0.05:
    print("\n结论：前后测量有显著差异")
else:
    print("\n结论：前后测量无显著差异")
```

## 实际应用：A/B 测试

```python
"""
场景：网站改版后，转化率是否真的提高了？
"""

# 控制组（旧版本）
visitors_A = 1000
conversions_A = 120  # 12% 转化率

# 实验组（新版本）
visitors_B = 1000
conversions_B = 145  # 14.5% 转化率

# 构造数据（1=转化，0=未转化）
group_A = np.concatenate([np.ones(conversions_A),
                          np.zeros(visitors_A - conversions_A)])
group_B = np.concatenate([np.ones(conversions_B),
                          np.zeros(visitors_B - conversions_B)])

# 方法1：双样本 t 检验
t_stat, p_value_t = stats.ttest_ind(group_A, group_B)

# 方法2：卡方检验
observed = np.array([[conversions_A, visitors_A - conversions_A],
                     [conversions_B, visitors_B - conversions_B]])
chi2, p_value_chi2, _, _ = chi2_contingency(observed)

# 方法3：比例检验
from statsmodels.stats.proportion import proportions_ztest
counts = np.array([conversions_A, conversions_B])
nobs = np.array([visitors_A, visitors_B])
z_stat, p_value_prop = proportions_ztest(counts, nobs)

print("=" * 60)
print("A/B 测试结果")
print("=" * 60)
print(f"控制组: {conversions_A}/{visitors_A} = {conversions_A/visitors_A*100:.1f}%")
print(f"实验组: {conversions_B}/{visitors_B} = {conversions_B/visitors_B*100:.1f}%")
print(f"差异: {(conversions_B/visitors_B - conversions_A/visitors_A)*100:.1f} 个百分点")

print(f"\n检验结果:")
print(f"  t 检验 p 值: {p_value_t:.4f}")
print(f"  卡方检验 p 值: {p_value_chi2:.4f}")
print(f"  比例检验 p 值: {p_value_prop:.4f}")

if p_value_t < 0.05:
    print("\n✓ 结论：新版本显著提高了转化率！")
    print("  建议采用新版本设计。")
else:
    print("\n✗ 结论：新版本的效果不够显著。")
    print("  建议继续测试或保持原设计。")

# 计算置信区间
conversion_rate_B = conversions_B / visitors_B
se = np.sqrt(conversion_rate_B * (1 - conversion_rate_B) / visitors_B)
ci_lower = conversion_rate_B - 1.96 * se
ci_upper = conversion_rate_B + 1.96 * se

print(f"\n实验组转化率的 95% 置信区间:")
print(f"  [{ci_lower*100:.2f}%, {ci_upper*100:.2f}%]")

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 转化率对比
axes[0].bar(['控制组', '实验组'],
            [conversions_A/visitors_A, conversions_B/visitors_B],
            alpha=0.7, edgecolor='black')
axes[0].set_ylabel('转化率')
axes[0].set_title(f'转化率对比 (p = {p_value_t:.4f})')
axes[0].grid(True, alpha=0.3, axis='y')

# 置信区间
conversion_rate_A = conversions_A / visitors_A
se_A = np.sqrt(conversion_rate_A * (1 - conversion_rate_A) / visitors_A)
ci_A = [conversion_rate_A - 1.96*se_A, conversion_rate_A + 1.96*se_A]
ci_B = [ci_lower, ci_upper]

axes[1].errorbar([0, 1],
                 [conversion_rate_A, conversion_rate_B],
                 yerr=[[conversion_rate_A - ci_A[0], conversion_rate_B - ci_B[0]],
                       [ci_A[1] - conversion_rate_A, ci_B[1] - conversion_rate_B]],
                 fmt='o', markersize=10, capsize=10, capthick=2)
axes[1].set_xticks([0, 1])
axes[1].set_xticklabels(['控制组', '实验组'])
axes[1].set_ylabel('转化率')
axes[1].set_title('95% 置信区间')
axes[1].grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()
```

## 假设检验选择指南

```
问题类型决策树：

1. 比较均值？
   ├─ 一个样本 vs 已知值
   │  └─> 单样本 t 检验 (ttest_1samp)
   │
   ├─ 两个独立样本
   │  ├─ 正态分布 → 独立样本 t 检验 (ttest_ind)
   │  └─ 非正态分布 → Mann-Whitney U 检验 (mannwhitneyu)
   │
   ├─ 两个配对样本
   │  ├─ 正态分布 → 配对 t 检验 (ttest_rel)
   │  └─ 非正态分布 → Wilcoxon 检验 (wilcoxon)
   │
   └─ 三组或更多
      └─> 方差分析 (f_oneway)

2. 分类数据（计数）？
   └─> 卡方检验 (chi2_contingency)

3. 相关性？
   └─> 见下一章
```

## 小结

- 假设检验判断差异是否显著
- p < 0.05 通常认为有显著差异
- t 检验用于比较均值
- 卡方检验用于分类数据
- ANOVA 用于多组比较
- 非参数检验不要求正态分布
- A/B 测试是典型应用场景
