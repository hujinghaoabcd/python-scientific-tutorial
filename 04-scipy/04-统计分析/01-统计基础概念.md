# 统计基础概念

统计分析是数据科学的核心，SciPy 提供了丰富的统计工具。

## 为什么需要统计？

**核心问题**：
1. **描述数据**：数据有什么特征？
2. **推断总体**：样本能告诉我们什么？
3. **检验假设**：两组数据真的有差异吗？
4. **预测未来**：基于历史数据做判断

## scipy.stats 模块结构

```python
from scipy import stats

# 主要功能：
"""
1. 概率分布
   - 连续分布：norm, expon, t, chi2, f等
   - 离散分布：binom, poisson等

2. 描述性统计
   - describe()：综合统计
   - 均值、中位数、标准差等

3. 假设检验
   - t检验、卡方检验、方差分析等

4. 相关性分析
   - Pearson, Spearman相关系数

5. 概率函数
   - PDF, CDF, PPF等
"""
```

## 概率分布基础

### 什么是概率分布？

**通俗理解**：描述随机变量可能取值及其概率的规律。

**生活例子**：
- **正态分布**：身高、体重、考试成绩
- **泊松分布**：单位时间内的事件次数（网站访问量）
- **指数分布**：等待时间（客服响应时间）

### 关键概念

#### PDF（Probability Density Function）概率密度函数

```python
from scipy.stats import norm
import numpy as np
import matplotlib.pyplot as plt

# 标准正态分布 N(0, 1)
x = np.linspace(-4, 4, 200)
pdf = norm.pdf(x, loc=0, scale=1)

plt.plot(x, pdf, 'b-', linewidth=2)
plt.fill_between(x, pdf, alpha=0.3)
plt.xlabel('x')
plt.ylabel('概率密度')
plt.title('标准正态分布 PDF')
plt.grid(True, alpha=0.3)
plt.show()
```

**含义**：x 附近单位区间的概率

#### CDF（Cumulative Distribution Function）累积分布函数

```python
cdf = norm.cdf(x, loc=0, scale=1)

plt.plot(x, cdf, 'r-', linewidth=2)
plt.xlabel('x')
plt.ylabel('累积概率 P(X ≤ x)')
plt.title('标准正态分布 CDF')
plt.grid(True, alpha=0.3)
plt.axhline(0.5, color='g', linestyle='--', alpha=0.5)
plt.axvline(0, color='g', linestyle='--', alpha=0.5)
plt.show()
```

**含义**：P(X ≤ x)，随机变量小于等于 x 的概率

#### PPF（Percent Point Function）分位数函数

```python
# CDF 的反函数
# 问题：有多少 x 使得 P(X ≤ x) = 0.95？
x_95 = norm.ppf(0.95, loc=0, scale=1)
print(f"95% 分位数: {x_95:.4f}")  # 约 1.645

# 常用分位数
quantiles = [0.025, 0.25, 0.50, 0.75, 0.975]
for q in quantiles:
    x_q = norm.ppf(q)
    print(f"{q*100:.1f}% 分位数: {x_q:.4f}")
```

## 常用概率分布

### 1. 正态分布（最重要！）

```python
from scipy.stats import norm

# 创建正态分布对象
# loc = μ (均值), scale = σ (标准差)
normal = norm(loc=100, scale=15)

# 计算概率
prob_less_than_110 = normal.cdf(110)
print(f"P(X < 110) = {prob_less_than_110:.4f}")

# 生成随机样本
samples = normal.rvs(size=1000)

# 可视化
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
x = np.linspace(50, 150, 200)
plt.plot(x, normal.pdf(x), 'b-', linewidth=2, label='理论分布')
plt.hist(samples, bins=30, density=True, alpha=0.5, label='随机样本')
plt.xlabel('x')
plt.ylabel('概率密度')
plt.title('正态分布 N(100, 15)')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(x, normal.cdf(x), 'r-', linewidth=2)
plt.xlabel('x')
plt.ylabel('累积概率')
plt.title('累积分布函数')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

**应用场景**：
- 测量误差
- 自然现象（身高、体重）
- 中心极限定理的基础

### 2. t 分布

```python
from scipy.stats import t

# 自由度 df = n - 1
df = 10
t_dist = t(df=df)

# t 分布 vs 正态分布
x = np.linspace(-4, 4, 200)
plt.plot(x, t_dist.pdf(x), 'b-', linewidth=2, label=f't分布 (df={df})')
plt.plot(x, norm.pdf(x), 'r--', linewidth=2, label='标准正态分布')
plt.xlabel('x')
plt.ylabel('概率密度')
plt.title('t分布 vs 正态分布')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

**特点**：
- 尾部比正态分布更厚
- 自由度越大，越接近正态分布
- 用于小样本统计推断

### 3. 卡方分布

```python
from scipy.stats import chi2

df = 5
chi2_dist = chi2(df=df)

x = np.linspace(0, 20, 200)
plt.plot(x, chi2_dist.pdf(x), linewidth=2)
plt.xlabel('x')
plt.ylabel('概率密度')
plt.title(f'卡方分布 (df={df})')
plt.grid(True, alpha=0.3)
plt.show()
```

**应用场景**：
- 方差检验
- 独立性检验
- 拟合优度检验

### 4. 二项分布（离散）

```python
from scipy.stats import binom

# n 次试验，每次成功概率 p
n, p = 10, 0.3
binom_dist = binom(n=n, p=p)

# 概率质量函数 PMF
k = np.arange(0, n+1)
pmf = binom_dist.pmf(k)

plt.bar(k, pmf, alpha=0.7, edgecolor='black')
plt.xlabel('成功次数 k')
plt.ylabel('概率 P(X = k)')
plt.title(f'二项分布 B(n={n}, p={p})')
plt.grid(True, alpha=0.3, axis='y')
plt.show()
```

**应用场景**：
- 抛硬币
- 产品合格率
- A/B 测试

### 5. 泊松分布（离散）

```python
from scipy.stats import poisson

# 平均发生率 λ
lam = 3
poisson_dist = poisson(mu=lam)

k = np.arange(0, 15)
pmf = poisson_dist.pmf(k)

plt.bar(k, pmf, alpha=0.7, edgecolor='black')
plt.xlabel('事件次数 k')
plt.ylabel('概率 P(X = k)')
plt.title(f'泊松分布 (λ={lam})')
plt.grid(True, alpha=0.3, axis='y')
plt.show()
```

**应用场景**：
- 单位时间的事件次数
- 网站访问量
- 呼叫中心来电数

## 描述性统计

### 使用 describe 函数

```python
from scipy.stats import describe

# 生成样本数据
data = np.random.normal(100, 15, 1000)

# 综合统计
desc = describe(data)

print("=" * 60)
print("描述性统计")
print("=" * 60)
print(f"样本数: {desc.nobs}")
print(f"最小值: {desc.minmax[0]:.2f}")
print(f"最大值: {desc.minmax[1]:.2f}")
print(f"均值: {desc.mean:.2f}")
print(f"方差: {desc.variance:.2f}")
print(f"标准差: {np.sqrt(desc.variance):.2f}")
print(f"偏度 (Skewness): {desc.skewness:.4f}")
print(f"峰度 (Kurtosis): {desc.kurtosis:.4f}")
```

### 统计量的含义

**偏度（Skewness）**：
- = 0：对称分布（正态分布）
- \> 0：右偏（尾部向右延伸）
- < 0：左偏（尾部向左延伸）

**峰度（Kurtosis）**：
- = 0：与正态分布相同
- \> 0：比正态分布更尖锐
- < 0：比正态分布更平坦

## 统计推断基础

### 置信区间

```python
from scipy import stats

# 样本数据
sample = np.random.normal(100, 15, 50)
n = len(sample)

# 样本统计量
mean = np.mean(sample)
std = np.std(sample, ddof=1)  # 样本标准差
se = std / np.sqrt(n)  # 标准误

# 95% 置信区间（使用 t 分布）
confidence = 0.95
alpha = 1 - confidence
t_critical = stats.t.ppf(1 - alpha/2, df=n-1)

ci_lower = mean - t_critical * se
ci_upper = mean + t_critical * se

print(f"样本均值: {mean:.2f}")
print(f"95% 置信区间: [{ci_lower:.2f}, {ci_upper:.2f}]")
print(f"解释：我们有 95% 的把握认为总体均值在此区间内")
```

## 统计分布速查表

| 分布 | SciPy 名称 | 参数 | 主要用途 |
|------|------------|------|----------|
| 正态分布 | `norm` | loc, scale | 连续数据，中心极限定理 |
| t分布 | `t` | df | 小样本推断 |
| 卡方分布 | `chi2` | df | 方差检验，独立性检验 |
| F分布 | `f` | dfn, dfd | 方差比检验，ANOVA |
| 二项分布 | `binom` | n, p | 成功/失败型试验 |
| 泊松分布 | `poisson` | mu | 计数数据 |
| 指数分布 | `expon` | scale | 等待时间 |
| 均匀分布 | `uniform` | loc, scale | 随机数生成 |

## 实用示例

### 示例1：检验数据是否服从正态分布

```python
from scipy.stats import normaltest, shapiro

# 生成数据
normal_data = np.random.normal(0, 1, 100)
non_normal_data = np.random.exponential(2, 100)

# Shapiro-Wilk 检验
stat1, p1 = shapiro(normal_data)
stat2, p2 = shapiro(non_normal_data)

print("正态性检验 (Shapiro-Wilk):")
print(f"正态数据 p值: {p1:.4f} - {'服从正态分布' if p1 > 0.05 else '不服从正态分布'}")
print(f"指数数据 p值: {p2:.4f} - {'服从正态分布' if p2 > 0.05 else '不服从正态分布'}")

# 可视化对比
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 正态数据
axes[0, 0].hist(normal_data, bins=20, density=True, alpha=0.7, edgecolor='black')
axes[0, 0].set_title('正态数据 - 直方图')

stats.probplot(normal_data, dist="norm", plot=axes[0, 1])
axes[0, 1].set_title('正态数据 - Q-Q图')

# 指数数据
axes[1, 0].hist(non_normal_data, bins=20, density=True, alpha=0.7, edgecolor='black')
axes[1, 0].set_title('指数数据 - 直方图')

stats.probplot(non_normal_data, dist="norm", plot=axes[1, 1])
axes[1, 1].set_title('指数数据 - Q-Q图')

plt.tight_layout()
plt.show()
```

## 小结

- SciPy 提供丰富的概率分布
- 每个分布有 PDF/CDF/PPF/RVS 等方法
- 正态分布是最重要的分布
- `describe()` 提供综合统计
- 置信区间用于参数估计
- 正态性检验判断数据分布类型
