## 2026 版重点

- 不再使用已从 SciPy 移除的二维插值旧接口；规则网格优先 `RegularGridInterpolator` / `RectBivariateSpline`，散点数据使用 `LinearNDInterpolator`、`CloughTocher2DInterpolator` 或 `griddata`。
- ODE 示例统一使用 `solve_ivp()`，不再把旧式积分接口作为主线。
- 线性代数优先 `scipy.linalg`，大规模稀疏问题使用 `scipy.sparse.linalg`。
- 每一节都强调“数据结构 → 算法选择 → 结果检查”，而不是只罗列函数名。
