# 优化基础概念

优化是寻找使函数达到最大值或最小值的输入参数的过程。

## 什么是优化？

**通俗理解**：在所有可能的选择中，找到最好的那一个。

### 生活中的优化例子

1. **旅行路线**
   - 目标：最短路径
   - 变量：路线选择
   - 约束：必经景点

2. **投资组合**
   - 目标：收益最大化，风险最小化
   - 变量：各资产配置比例
   - 约束：总资金固定，风险上限

3. **生产计划**
   - 目标：利润最大化
   - 变量：产品数量
   - 约束：原料、时间、设备限制

## 基本术语

### 目标函数（Objective Function）
要最大化或最小化的函数。

```python
# 示例：最小化平方函数
def objective(x):
    return x**2 + 2*x + 1
```

### 决策变量（Decision Variables）
可以调整的参数。

```python
# x 是决策变量
x = 3
y = objective(x)
```

### 约束条件（Constraints）
决策变量必须满足的条件。

```python
# 示例约束：
# x >= 0  （非负约束）
# x + y = 10  （等式约束）
# x² + y² <= 100  （不等式约束）
```

### 最优解（Optimal Solution）
使目标函数达到最优的决策变量值。

## 优化问题的类型

### 1. 无约束优化
没有限制条件，自由寻找最优解。

**示例**：找到函数 f(x) = x² - 4x + 5 的最小值

```python
from scipy.optimize import minimize

def f(x):
    return x**2 - 4*x + 5

result = minimize(f, x0=0)  # 从 x=0 开始搜索
print(f"最小值位置: x = {result.x[0]:.2f}")
print(f"最小值: f(x) = {result.fun:.2f}")
```

### 2. 约束优化
必须满足某些条件。

**示例**：最小化 f(x, y) = x² + y²，约束条件 x + y = 1

```python
from scipy.optimize import minimize

def objective(vars):
    x, y = vars
    return x**2 + y**2

# 约束：x + y = 1
constraints = {'type': 'eq', 'fun': lambda vars: vars[0] + vars[1] - 1}

result = minimize(objective, x0=[0, 0], constraints=constraints)
print(f"最优解: x = {result.x[0]:.2f}, y = {result.x[1]:.2f}")
```

### 3. 线性规划
目标函数和约束都是线性的。

**示例**：
- 最大化：profit = 3x + 2y
- 约束：x + y ≤ 4, x ≥ 0, y ≥ 0

### 4. 非线性规划
包含非线性的目标函数或约束。

## 优化方法分类

### 局部优化 vs 全局优化

```python
import numpy as np
import matplotlib.pyplot as plt

# 多峰函数（有多个局部最小值）
def multi_peak(x):
    return (x - 2)**2 + 2 * np.sin(2*x)

x = np.linspace(-2, 6, 200)
y = multi_peak(x)

plt.figure(figsize=(10, 5))
plt.plot(x, y, 'b-', linewidth=2)
plt.axhline(y=0, color='k', linestyle='--', alpha=0.3)
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('多峰函数：有多个局部最小值')
plt.grid(True, alpha=0.3)

# 标记局部最小值
plt.plot(2, multi_peak(2), 'ro', markersize=10, label='全局最小值')
plt.plot(-0.5, multi_peak(-0.5), 'yo', markersize=10, label='局部最小值')
plt.legend()
plt.show()
```

**局部优化**：
- 找到附近的最小值
- 快速但可能不是全局最优
- 方法：梯度下降、牛顿法

**全局优化**：
- 寻找所有可能中的最小值
- 较慢但更可靠
- 方法：遗传算法、模拟退火

## SciPy 优化模块概览

```python
from scipy import optimize

# 主要功能分类：
"""
1. 标量函数优化
   - minimize_scalar()  一维函数最小化

2. 多变量函数优化
   - minimize()  多维函数最小化
   - 支持多种算法：BFGS, Nelder-Mead, CG等

3. 曲线拟合
   - curve_fit()  非线性最小二乘拟合
   - least_squares()  更通用的最小二乘

4. 求根（方程求解）
   - root()  多元方程组
   - fsolve()  非线性方程组（常用）
   - brentq(), newton()  一元方程

5. 线性规划
   - linprog()  线性规划问题

6. 全局优化
   - differential_evolution()  差分进化
   - basinhopping()  盆地跳跃
"""
```

## 选择优化方法的指南

### 决策树

```
你的问题是什么？

├─ 一维函数最小化
│  └─> minimize_scalar()

├─ 多维函数最小化
│  ├─ 无约束
│  │  └─> minimize(method='BFGS')  # 默认首选
│  └─ 有约束
│     └─> minimize(method='SLSQP')  # 序列二次规划

├─ 曲线拟合（有数据点）
│  └─> curve_fit()

├─ 方程求解（找 f(x) = 0）
│  ├─ 一元方程
│  │  └─> brentq() 或 newton()
│  └─ 多元方程组
│     └─> fsolve()

├─ 线性规划
│  └─> linprog()

└─ 需要全局最优（多峰函数）
   └─> differential_evolution()
```

## 优化的一般步骤

### 步骤 1：定义目标函数

```python
def objective(x):
    """
    定义要最小化的函数

    参数:
        x: 决策变量（可以是标量或数组）

    返回:
        函数值
    """
    return x**2 + 2*x + 1
```

### 步骤 2：选择初始猜测

```python
x0 = 0  # 初始猜测值

# 对于多维问题
x0 = np.array([0, 0, 0])
```

### 步骤 3：设置约束（如果有）

```python
# 等式约束：g(x) = 0
constraints_eq = {'type': 'eq', 'fun': lambda x: x[0] + x[1] - 1}

# 不等式约束：g(x) >= 0
constraints_ineq = {'type': 'ineq', 'fun': lambda x: x[0] - x[1]}
```

### 步骤 4：调用优化器

```python
from scipy.optimize import minimize

result = minimize(objective, x0, constraints=constraints_eq)
```

### 步骤 5：检查结果

```python
print(f"成功: {result.success}")
print(f"信息: {result.message}")
print(f"最优解: {result.x}")
print(f"目标函数值: {result.fun}")
print(f"迭代次数: {result.nit}")
```

## 简单示例

### 示例 1：抛物线最小值

```python
from scipy.optimize import minimize
import numpy as np
import matplotlib.pyplot as plt

# 目标函数
def f(x):
    return (x - 3)**2 + 2

# 优化
result = minimize(f, x0=0)

# 可视化
x = np.linspace(-2, 8, 100)
plt.plot(x, f(x), 'b-', label='f(x) = (x-3)² + 2')
plt.plot(result.x, result.fun, 'ro', markersize=10, label='最小值')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.legend()
plt.grid(True)
plt.title(f'最小值: x = {result.x[0]:.2f}, f(x) = {result.fun:.2f}')
plt.show()
```

### 示例 2：二维函数优化

```python
# 目标函数：Rosenbrock 函数
def rosenbrock(x):
    return (1 - x[0])**2 + 100*(x[1] - x[0]**2)**2

# 优化
x0 = np.array([0, 0])
result = minimize(rosenbrock, x0, method='BFGS')

print(f"起始点: {x0}")
print(f"最优解: {result.x}")
print(f"最小值: {result.fun:.6f}")
print(f"理论最优: x = [1, 1], f(x) = 0")
```

## 常见陷阱

### 1. 初始猜测的重要性

```python
def multi_minima(x):
    return x**4 - 3*x**3 + 2

# 不同初始点可能找到不同的局部最小值
for x0 in [0, 2, 4]:
    result = minimize(multi_minima, x0)
    print(f"起始点 x0={x0}: 找到最小值 x={result.x[0]:.2f}")
```

### 2. 数值精度问题

```python
# 函数梯度过大可能导致数值不稳定
def unstable(x):
    return 1e10 * x**2

# 解决：归一化函数
def stable(x):
    return x**2  # 除以 1e10
```

### 3. 约束不相容

```python
# 矛盾的约束
# x > 10 且 x < 5  # 不可能！

# 检查约束是否可行
def check_constraints(x, constraints):
    for con in constraints:
        if not con['fun'](x) >= 0:  # 假设不等式约束
            return False
    return True
```

- 局部优化 vs 全局优化

- 初始猜测很重要
- 需要验证结果的合理性
