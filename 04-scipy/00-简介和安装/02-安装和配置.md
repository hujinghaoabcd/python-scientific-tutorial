# 安装和配置 SciPy

## 方法一：使用 pip（推荐）

```bash
# 安装 SciPy
pip install scipy

# 同时安装相关库（推荐）
pip install numpy scipy matplotlib pandas
```

### 验证安装

```python
import scipy
import numpy as np

print(f"SciPy 版本: {scipy.__version__}")
print(f"NumPy 版本: {np.__version__}")
```

**预期输出**：
```
SciPy 版本: 1.11.4
NumPy 版本: 1.26.2
```

## 方法二：使用 Anaconda（科学计算推荐）

Anaconda 是一个 Python 发行版，预装了 SciPy 和其他科学计算库。

### 安装 Anaconda

1. 下载：https://www.anaconda.com/download
2. 安装后，SciPy 已经预装好了

### 使用 conda 安装

```bash
# 创建新环境（可选）
conda create -n scientific python=3.11

# 激活环境
conda activate scientific

# 安装 SciPy
conda install scipy

# 安装科学计算全家桶
conda install numpy scipy matplotlib pandas jupyter scikit-learn
```

## 测试安装

创建一个测试文件 `test_scipy.py`：

```python
"""测试 SciPy 安装"""
import numpy as np
from scipy import interpolate, optimize, stats, io

print("=" * 50)
print("SciPy 安装测试")
print("=" * 50)

# 1. 基本信息
print(f"\nSciPy 版本: {scipy.__version__}")
print(f"NumPy 版本: {np.__version__}")

# 2. 测试插值
print("\n[测试 1] 插值模块")
x = np.array([0, 1, 2, 3])
y = np.array([0, 1, 4, 9])
f = interpolate.interp1d(x, y)
print(f"  插值 f(1.5) = {f(1.5)}")
print("  ✓ 插值模块正常")

# 3. 测试优化
print("\n[测试 2] 优化模块")
result = optimize.minimize_scalar(lambda x: (x - 2)**2)
print(f"  最小值位置: x = {result.x:.2f}")
print("  ✓ 优化模块正常")

# 4. 测试统计
print("\n[测试 3] 统计模块")
data = np.random.normal(0, 1, 100)
mean = np.mean(data)
print(f"  随机样本均值: {mean:.2f}")
print("  ✓ 统计模块正常")

# 5. 测试文件 I/O
print("\n[测试 4] 文件 I/O 模块")
test_data = {'test_array': np.array([1, 2, 3])}
io.savemat('test.mat', test_data)
loaded = io.loadmat('test.mat')
print(f"  保存并读取 MATLAB 文件成功")
print("  ✓ 文件 I/O 模块正常")

print("\n" + "=" * 50)
print("所有测试通过！SciPy 安装成功！")
print("=" * 50)
```

运行测试：
```bash
python test_scipy.py
```

## 常见问题

### 问题 1：安装失败

**错误信息**：`Failed building wheel for scipy`

**解决方案**：
```bash
# 更新 pip
pip install --upgrade pip

# 安装构建工具
pip install --upgrade setuptools wheel

# 重新安装
pip install scipy
```

### 问题 2：Import 错误

**错误信息**：`ImportError: No module named scipy`

**解决方案**：
1. 确认 Python 环境正确
   ```bash
   which python  # Linux/Mac
   where python  # Windows
   ```

2. 检查是否安装在正确的环境
   ```bash
   pip list | grep scipy
   ```

### 问题 3：版本冲突

**错误信息**：版本不兼容警告

**解决方案**：
```bash
# 查看依赖
pip show scipy

# 更新相关包
pip install --upgrade numpy scipy matplotlib
```

## 验证完整环境

```python
"""验证科学计算环境"""
import sys

packages = [
    'numpy',
    'scipy',
    'matplotlib',
    'pandas',
]

print("Python 版本:", sys.version)
print("\n已安装的包：")
print("-" * 40)

for package in packages:
    try:
        module = __import__(package)
        version = getattr(module, '__version__', '未知')
        print(f"✓ {package:15s} {version}")
    except ImportError:
        print(f"✗ {package:15s} 未安装")
```
