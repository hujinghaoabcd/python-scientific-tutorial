# 二维插值和应用

二维插值的关键不是“选一个插值函数”，而是先判断数据属于哪一种结构：**规则网格、非规则网格，还是散点观测**。SciPy 新代码应根据数据结构选择对应工具。

## 1. 规则网格：RegularGridInterpolator

规则网格指横纵坐标分别有固定的一维坐标轴，数据值落在它们的笛卡尔积上。

```python
import numpy as np
from scipy.interpolate import RegularGridInterpolator

x = np.linspace(0, 4, 5)
y = np.linspace(0, 3, 4)
X, Y = np.meshgrid(x, y, indexing="ij")
Z = np.sin(X) + np.cos(Y)

f = RegularGridInterpolator(
    (x, y),
    Z,
    method="linear",
    bounds_error=False,
    fill_value=np.nan,
)

points = np.array([
    [0.5, 0.5],
    [1.3, 2.1],
    [3.7, 1.2],
])
print(f(points))
```

### 生成高分辨率网格

```python
xf = np.linspace(x.min(), x.max(), 100)
yf = np.linspace(y.min(), y.max(), 80)
XF, YF = np.meshgrid(xf, yf, indexing="ij")
query = np.column_stack([XF.ravel(), YF.ravel()])
ZF = f(query).reshape(XF.shape)
```

## 2. 规则网格样条：RectBivariateSpline

当数据比较平滑，希望得到更平滑的二维曲面或需要导数时，可以使用二维样条。

```python
from scipy.interpolate import RectBivariateSpline

spline = RectBivariateSpline(x, y, Z, kx=3, ky=3)
ZF_spline = spline(xf, yf)
```

`RectBivariateSpline` 要求输入是真正的矩形网格，并且 `Z.shape == (len(x), len(y))`。

## 3. 散点数据：griddata

当观测点不是规则网格，例如采样站、传感器或不规则空间样点，可以使用 `griddata`。

```python
from scipy.interpolate import griddata

rng = np.random.default_rng(42)
points = rng.uniform([0, 0], [10, 8], size=(80, 2))
values = np.sin(points[:, 0] / 2) + np.cos(points[:, 1] / 2)

grid_x, grid_y = np.meshgrid(
    np.linspace(0, 10, 120),
    np.linspace(0, 8, 100),
)

grid_z = griddata(
    points,
    values,
    (grid_x, grid_y),
    method="linear",
)
```

可选方法：

- `nearest`：最快，可在凸包外给出最近邻值；
- `linear`：基于三角剖分的线性插值，常用默认方案；
- `cubic`：二维下使用分片三次方法，曲面更平滑，但更容易产生过冲。

## 4. 显式散点插值器

如果同一组观测点需要反复查询，直接构造插值器更高效。

```python
from scipy.interpolate import LinearNDInterpolator

linear = LinearNDInterpolator(points, values, fill_value=np.nan)
query_points = np.array([[2.5, 4.0], [7.0, 3.0]])
print(linear(query_points))
```

平滑二维散点可以考虑：

```python
from scipy.interpolate import CloughTocher2DInterpolator

smooth = CloughTocher2DInterpolator(points, values)
print(smooth(query_points))
```

## 5. 可视化比较

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()

ax.scatter(points[:, 0], points[:, 1], s=12)
ax.set_title("Scattered-data interpolation")
fig.colorbar(mesh, ax=ax, label="value")
plt.show()
```

## 6. 图像放大：优先 ndimage.zoom

二维数组如果代表图像，通常不需要手工构造二维插值器。

```python
from scipy.ndimage import zoom

image = np.arange(25, dtype=float).reshape(5, 5)
large = zoom(image, zoom=4, order=3)
print(image.shape, large.shape)
```

`order=0` 是最近邻，`order=1` 是线性，`order=3` 是三次样条。

## 7. 外推要特别谨慎

许多二维插值方法只在采样区域内可靠。对散点数据而言，线性插值通常只在观测点凸包内部有定义。凸包外出现 `NaN` 不一定是错误，而是在提醒你“这里没有足够信息”。

可视化凸包：

```python
from scipy.spatial import ConvexHull

hull = ConvexHull(points)
for simplex in hull.simplices:
    p = points[simplex]
    plt.plot(p[:, 0], p[:, 1], "k-")
plt.scatter(points[:, 0], points[:, 1])
plt.show()
```

## 8. 交叉验证选择方法

插值方法应通过留出观测点检验，而不是只看图“够不够平滑”。

```python
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

train_idx, test_idx = train_test_split(
    np.arange(len(points)), test_size=0.2, random_state=42
)

train_points = points[train_idx]
train_values = values[train_idx]
test_points = points[test_idx]
test_values = values[test_idx]

model = LinearNDInterpolator(train_points, train_values)
pred = model(test_points)
mask = np.isfinite(pred)
rmse = mean_squared_error(test_values[mask], pred[mask]) ** 0.5
print(f"RMSE: {rmse:.4f}")
```

## 9. 如何选

| 数据结构 | 推荐方法 | 典型用途 |
| --- | --- | --- |
| 规则 N 维网格 | `RegularGridInterpolator` | 温度场、模型网格 |
| 规则二维平滑曲面 | `RectBivariateSpline` | 平滑场、导数计算 |
| 散点快速一次性插值 | `griddata` | 站点观测制图 |
| 散点重复查询 | `LinearNDInterpolator` | 多次空间预测 |
| 二维散点平滑曲面 | `CloughTocher2DInterpolator` | 平滑表面 |
| 图像缩放 | `scipy.ndimage.zoom` | 栅格/图像重采样 |

## 10. 常见错误

1. 把散点数据错误地 reshape 成“规则网格”；
2. 忽略坐标单位差异，例如经纬度与米混合参与欧氏距离；
3. 在观测范围之外进行大范围外推；
4. 只比较视觉平滑程度，不做留出验证；
5. 对明显不连续的变量使用高阶平滑插值。

二维插值的核心流程是：**识别数据结构 → 选择插值器 → 检查边界/外推 → 用留出样本验证误差**。
