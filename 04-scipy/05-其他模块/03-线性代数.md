# SciPy 线性代数

`numpy.linalg` 能处理常见任务，`scipy.linalg` 在矩阵分解、结构化矩阵和高级算法方面更完整。

```python
import numpy as np
from scipy import linalg

A = np.array([[4.0, 2.0], [1.0, 3.0]])
b = np.array([1.0, 2.0])

x = linalg.solve(A, b)
print(x)
```

## LU / QR / SVD

```python
P, L, U = linalg.lu(A)
Q, R = linalg.qr(A)
U_svd, s, Vh = linalg.svd(A)
```

## 特征值

```python
w, v = linalg.eig(A)
print(w)
```

对称矩阵优先使用专门算法：

```python
S = np.array([[2.0, 1.0], [1.0, 2.0]])
w, v = linalg.eigh(S)
```

## 不要显式求逆解线性方程

推荐：

```python
x = linalg.solve(A, b)
```

而不是：

```python
x = linalg.inv(A) @ b
```

前者通常更稳定、更快。
