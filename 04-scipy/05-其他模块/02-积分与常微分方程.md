# 数值积分与常微分方程

## 一维定积分

```python
from scipy.integrate import quad
import numpy as np

value, error = quad(lambda x: np.exp(-x**2), 0, 2)
print(value, error)
```

`quad` 同时返回积分估计和数值误差估计。

## 离散采样点积分

```python
from scipy.integrate import simpson

x = np.linspace(0, np.pi, 101)
y = np.sin(x)
area = simpson(y, x=x)
print(area)
```

## 常微分方程：solve_ivp

考虑指数衰减：`dy/dt = -k y`。

```python
from scipy.integrate import solve_ivp

k = 0.4

def rhs(t, y):
    return [-k * y[0]]

sol = solve_ivp(
    rhs,
    t_span=(0, 10),
    y0=[100.0],
    t_eval=np.linspace(0, 10, 101),
)

print(sol.success)
print(sol.y[:, :5])
```

刚性问题可尝试 `Radau` 或 `BDF`；一般非刚性问题通常从默认 `RK45` 开始。

## 事件检测

```python
def reaches_ten(t, y):
    return y[0] - 10

reaches_ten.terminal = True
reaches_ten.direction = -1

sol = solve_ivp(rhs, (0, 20), [100], events=reaches_ten)
print(sol.t_events)
```

数值 ODE 的重点是检查误差容限、守恒量、步长敏感性和求解器成功状态，而不是只看是否“画出了一条曲线”。
