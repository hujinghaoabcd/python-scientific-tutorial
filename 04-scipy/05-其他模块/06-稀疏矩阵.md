# 稀疏矩阵与稀疏线性代数

当矩阵绝大多数元素为 0 时，稀疏结构可以显著减少内存和计算量。

```python
import numpy as np
from scipy import sparse

row = np.array([0, 0, 1, 2])
col = np.array([0, 2, 1, 2])
data = np.array([1.0, 2.0, 3.0, 4.0])

A = sparse.csr_matrix((data, (row, col)), shape=(3, 3))
print(A)
print(A.toarray())
```

## CSR 与 CSC

- CSR：行切片、矩阵向量乘法常用；
- CSC：列操作和部分分解更方便；
- COO：适合构造；
- LIL / DOK：适合逐项增量修改。

## 稀疏线性方程

```python
from scipy.sparse.linalg import spsolve

A = sparse.csr_matrix([[4.0, 1.0], [1.0, 3.0]])
b = np.array([1.0, 2.0])
x = spsolve(A, b)
print(x)
```

大规模问题还可以考虑迭代方法，例如 `cg`、`gmres`。迭代求解器的收敛性与矩阵性质、容差和预条件密切相关。
