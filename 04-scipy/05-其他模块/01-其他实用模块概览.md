# SciPy 其他核心模块概览

前面的插值、优化和统计只是 SciPy 的一部分。实际科研与工程中，还经常使用以下模块。

| 模块 | 作用 | 本教程入口 |
| --- | --- | --- |
| `scipy.integrate` | 数值积分、常微分方程 | [积分与 ODE](02-积分与常微分方程.md) |
| `scipy.linalg` | 稠密线性代数 | [线性代数](03-线性代数.md) |
| `scipy.signal` | 滤波、频谱、峰值、卷积 | [信号处理](04-信号处理.md) |
| `scipy.spatial` | 距离、KDTree、凸包、Voronoi | [空间算法](05-空间算法.md) |
| `scipy.sparse` | 稀疏矩阵 | [稀疏矩阵](06-稀疏矩阵.md) |
| `scipy.ndimage` | 多维图像与栅格处理 | [ndimage](07-ndimage图像处理.md) |

NumPy 更偏“数组基础设施”，SciPy 更偏“建立在数组上的数值算法”。判断是否该用 SciPy 的一个简单标准是：当你开始自己手写积分器、优化器、滤波器、最近邻搜索、稀疏线性方程求解器时，通常应该先查看 SciPy 是否已经提供成熟实现。
