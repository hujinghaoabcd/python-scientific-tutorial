# 信号处理

`scipy.signal` 适合一维传感器序列、音频、实验信号和数字滤波。

```python
import numpy as np
from scipy import signal

fs = 100.0
t = np.arange(0, 5, 1 / fs)
x = np.sin(2 * np.pi * 2 * t) + 0.4 * np.sin(2 * np.pi * 20 * t)
```

## Butterworth 低通滤波

```python
sos = signal.butter(4, 5, btype="low", fs=fs, output="sos")
y = signal.sosfiltfilt(sos, x)
```

使用二阶节 `sos` 通常比高阶多项式系数形式更稳定。

## 功率谱密度

```python
freq, psd = signal.welch(x, fs=fs, nperseg=256)
peak_freq = freq[np.argmax(psd)]
print(peak_freq)
```

## 峰值检测

```python
peaks, properties = signal.find_peaks(x, prominence=0.5, distance=20)
print(peaks[:10])
```

滤波前应明确采样频率、目标频段和是否允许相位偏移；`sosfiltfilt` 是离线零相位滤波，不适合严格实时处理。
