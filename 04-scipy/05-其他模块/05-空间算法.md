# 空间算法

`scipy.spatial` 提供距离、最近邻、凸包、Delaunay 与 Voronoi 等基础几何算法。

## 距离矩阵

```python
import numpy as np
from scipy.spatial.distance import cdist

A = np.array([[0, 0], [1, 1], [2, 0]])
B = np.array([[0, 1], [3, 3]])
print(cdist(A, B, metric="euclidean"))
```

## KDTree 最近邻

```python
from scipy.spatial import KDTree

rng = np.random.default_rng(42)
points = rng.random((10000, 2))
tree = KDTree(points)

distance, index = tree.query([0.5, 0.5], k=5)
print(distance)
print(index)
```

## 凸包与 Delaunay

```python
from scipy.spatial import ConvexHull, Delaunay

hull = ConvexHull(points[:100])
tri = Delaunay(points[:100])
```

注意：经纬度不是平面米制坐标。大范围地理距离不要直接把经纬度送入欧氏距离，应使用合适投影或球面/椭球距离方法。
