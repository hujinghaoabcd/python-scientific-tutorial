# 文件 I/O 基础

`scipy.io` 模块提供了读写各种科学计算文件格式的功能。

## 为什么需要 scipy.io？

科学计算中经常需要与其他软件交换数据：
- **MATLAB** - 科学计算领域的经典软件
- **IDL** - 天文学和遥感领域常用
- **音频文件** - 信号处理和语音分析
- **矩阵数据** - 稀疏矩阵和大规模数值计算

## 支持的文件格式

| 格式 | 函数 | 用途 |
|------|------|------|
| MATLAB (.mat) | `savemat`, `loadmat` | 数据交换，最常用 |
| IDL (.sav) | `readsav` | 天文和遥感数据 |
| WAV (.wav) | `wavfile.read`, `wavfile.write` | 音频数据 |
| Matrix Market | `mmread`, `mmwrite` | 稀疏矩阵 |
| ARFF | `loadarff` | 机器学习数据集 |
| NetCDF | `netcdf_file` | 科学数据（气象、海洋） |

## 模块导入

```python
from scipy.io import savemat, loadmat  # MATLAB 文件
from scipy.io import wavfile          # WAV 音频
from scipy.io import readsav           # IDL 文件
from scipy.io import mmread, mmwrite   # Matrix Market
from scipy.io import loadarff          # ARFF 文件
```

## MATLAB 文件格式 (.mat)

### 为什么 MATLAB 格式重要？

- **广泛使用**：科研和工程领域的标准格式
- **跨平台**：Windows、Linux、Mac 通用
- **高效存储**：压缩二进制格式
- **保留结构**：支持多维数组、结构体等

### 基本结构

MATLAB 文件本质上是一个字典，键是变量名，值是 NumPy 数组。

```python
# MATLAB 文件的 Python 表示
{
    'variable1': numpy_array_1,
    'variable2': numpy_array_2,
    'matrix': numpy_matrix,
    ...
}
```

## 其他常用格式简介

### WAV 音频格式

**用途**：
- 音频信号处理
- 语音识别
- 声学分析

**特点**：
- 无损格式
- 包含采样率信息
- 支持单声道和立体声

### IDL 格式

**用途**：
- 天文数据
- 遥感图像
- 科学可视化

**特点**：
- IDL (Interactive Data Language) 软件格式
- 常见于天文和地理领域

### Matrix Market 格式

**用途**：
- 稀疏矩阵存储
- 线性代数测试数据
- 大规模科学计算

**特点**：
- 文本格式，易于阅读
- 高效存储稀疏矩阵

## 什么时候使用哪种格式？

### 选择指南

```
需求：数据交换（特别是与 MATLAB）
  └─> 使用 .mat 格式

需求：音频数据
  └─> 使用 .wav 格式

需求：大规模稀疏矩阵
  └─> 使用 Matrix Market 格式

需求：机器学习数据集
  └─> 使用 .arff 或 CSV/HDF5

需求：长期存储和通用性
  └─> 考虑 HDF5 (h5py库) 或 NumPy .npz
```

## 文件 I/O 的一般原则

### 1. 数据保真性
保存数据时确保不丢失精度和结构信息。

### 2. 可移植性
选择跨平台、跨软件的格式。

### 3. 性能
考虑读写速度和文件大小。

### 4. 兼容性
确保其他软件能够读取你的数据。

## scipy.io vs 其他方法

| 需求 | scipy.io | 其他方法 |
|------|----------|----------|
| MATLAB 文件 | `savemat/loadmat` ✓ | - |
| WAV 音频 | `wavfile` ✓ | `librosa`, `soundfile` |
| CSV 表格 | - | `pandas`, `numpy` |
| Excel 文件 | - | `pandas`, `openpyxl` |
| JSON | - | `json` 标准库 |
| HDF5 | `netcdf_file` (有限) | `h5py` ✓, `tables` |
| 图像 | - | `PIL`, `imageio`, `opencv` |
| 文本数据 | - | `numpy.loadtxt` |

## 快速参考

### 保存数据

```python
# NumPy 格式（推荐用于 Python 内部）
np.save('data.npy', array)
np.savez('data.npz', arr1=array1, arr2=array2)

# MATLAB 格式（推荐用于跨软件）
from scipy.io import savemat
savemat('data.mat', {'array': array})

# CSV 格式（推荐用于表格数据）
import pandas as pd
df.to_csv('data.csv')

# WAV 格式（音频）
from scipy.io import wavfile
wavfile.write('audio.wav', sample_rate, audio_data)
```

### 读取数据

```python
# NumPy 格式
data = np.load('data.npy')
data_dict = np.load('data.npz')

# MATLAB 格式
from scipy.io import loadmat
data = loadmat('data.mat')

# CSV 格式
import pandas as pd
df = pd.read_csv('data.csv')

# WAV 格式
from scipy.io import wavfile
rate, data = wavfile.read('audio.wav')
```

## 注意事项

### 1. MATLAB 版本兼容性
- MATLAB v7.3+ 使用 HDF5 格式
- 需要使用 `h5py` 而不是 `scipy.io`

### 2. 数据类型转换
- Python 字典 → MATLAB 结构体
- NumPy 数组 → MATLAB 矩阵
- 注意整数和浮点数的精度

### 3. 内存限制
- 大文件可能耗尽内存
- 考虑分块读取或使用内存映射

### 4. 字符编码
- 文本数据注意编码问题（UTF-8, ASCII等）
