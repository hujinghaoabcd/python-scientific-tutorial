# 第10章：数组排序和搜索

在数据分析和科学计算中，排序和搜索是最基础也是最常用的操作。想象一下，你有一份学生成绩表，需要找出成绩最好的学生；或者你有一批商品数据,需要按价格从低到高排序。这些都离不开排序和搜索操作。

NumPy提供了丰富的排序和搜索函数，不仅功能强大，而且性能出色。掌握这些函数，可以让你的数据处理工作事半功倍。

---

## 为什么需要排序和搜索？

在日常数据处理中，排序和搜索无处不在：

**排序的应用场景**：
- 学生成绩排名：从高到低显示成绩
- 商品展示：按价格、销量、评分排序
- 数据分析：找出最大值、最小值、中位数
- 时间序列：按时间顺序整理数据

**搜索的应用场景**：
- 查找元素位置：某个学生的排名
- 条件筛选：找出所有及格的学生
- 二分查找：在有序数组中快速定位
- 数据统计：统计满足条件的元素个数

NumPy的排序和搜索函数经过高度优化，比Python原生的排序快很多，特别是在处理大规模数据时，性能优势更加明显。

## sort() - 数组排序

`sort()` 是最基本的排序函数，可以对数组进行排序。NumPy提供了两种排序方式：

- `numpy.sort()`：返回排序后的副本，不改变原数组
- `ndarray.sort()`：就地排序，直接修改原数组

---

### 一维数组排序

对一维数组排序非常简单，默认是升序排列。

```python
import numpy as np

# 创建一个乱序数组
scores = np.array([85, 92, 78, 95, 88, 76, 90])

# numpy.sort() - 返回排序后的副本
sorted_scores = np.sort(scores)
print("排序后:", sorted_scores)  # [76 78 85 88 90 92 95]
print("原数组:", scores)         # [85 92 78 95 88 76 90] 不变

# 就地排序 - 直接修改原数组
scores.sort()
print("就地排序后:", scores)  # [76 78 85 88 90 92 95]
```

**理解 sort() 的两种用法**：
- `np.sort(arr)`：像是复印了一份成绩单，在复印件上排序，原件保持不变
- `arr.sort()`：直接在原成绩单上排序，改变了原始数据

---

### 降序排序

NumPy的sort默认是升序，如果想降序排列，可以：

```python
# 方法1: 排序后反转
scores = np.array([85, 92, 78, 95, 88])
sorted_desc = np.sort(scores)[::-1]
print("降序:", sorted_desc)  # [95 92 88 85 78]

# 方法2: 对负值排序再取负（适用于数值）
sorted_desc = -np.sort(-scores)
print("降序:", sorted_desc)  # [95 92 88 85 78]

# 实际应用：显示成绩前三名
print("前三名成绩:", sorted_desc[:3])  # [95 92 88]
```

**小贴士**：第二种方法看起来复杂，但在某些场景下性能更好，特别是处理大数组时。

---

### 多维数组排序

对于多维数组，可以指定按哪个轴排序。这在处理表格数据时特别有用。

```python
# 学生成绩表：每行一个学生，每列一门课程
# [语文, 数学, 英语]
scores = np.array([
    [85, 92, 78],  # 张三
    [90, 88, 95],  # 李四
    [78, 85, 82],  # 王五
    [92, 90, 88]   # 赵六
])

# 按列排序(axis=0)：每门课程的成绩分别排序
sorted_by_col = np.sort(scores, axis=0)
print("按列排序（每科成绩排序）：")
print(sorted_by_col)
# [[78 85 78]  语文从低到高
#  [85 88 82]
#  [90 90 88]
#  [92 92 95]]

# 按行排序(axis=1)：每个学生的各科成绩排序
sorted_by_row = np.sort(scores, axis=1)
print("\n按行排序（每人成绩排序）：")
print(sorted_by_row)
# [[78 85 92]  张三的成绩从低到高
#  [88 90 95]  李四的成绩从低到高
#  [78 82 85]  王五的成绩从低到高
#  [88 90 92]] 赵六的成绩从低到高

# axis=None：展平后排序
sorted_all = np.sort(scores, axis=None)
print("\n全部展平排序:", sorted_all)
# [78 78 82 85 85 88 88 90 90 92 92 95]
```

**记住 axis 的含义**：
- `axis=0`：沿着行的方向（垂直方向），对每一列排序
- `axis=1`：沿着列的方向（水平方向），对每一行排序
- `axis=None`：把整个数组当成一维数组排序

### 复数排序

NumPy可以对复数排序，先按实部，实部相同再按虚部。

```python
# 复数数组
complex_arr = np.array([3+2j, 1+1j, 3+1j, 1+2j])

# 排序：先按实部，再按虚部
sorted_complex = np.sort(complex_arr)
print(sorted_complex)
# [1.+1.j 1.+2.j 3.+1.j 3.+2.j]
```

## argsort() - 返回排序索引

`argsort()` 是一个非常重要的函数，它不返回排序后的元素，而是返回排序后元素的原始索引。这在很多场景下非常有用，特别是当你需要根据一个数组的顺序来调整其他相关数组时。

---

### 基本用法

```python
scores = np.array([85, 92, 78, 95, 88])

# argsort() 返回排序后的索引
indices = np.argsort(scores)
print("排序索引:", indices)  # [2 0 4 1 3]

# 解读：
# 索引2(78)最小，排第1
# 索引0(85)第二小，排第2
# 索引4(88)第三小，排第3
# 索引1(92)第四小，排第4
# 索引3(95)最大，排第5

# 用索引获取排序后的数组
sorted_scores = scores[indices]
print("排序后:", sorted_scores)  # [78 85 88 92 95]
```

**argsort() 的价值**：它告诉你排序后的元素在原数组中的位置，这样你可以同步调整多个相关数组。

---

### 实战：成绩排名

现在我们来看一个实际的例子：给学生成绩排名。

```python
# 学生名单和成绩
names = np.array(['张三', '李四', '王五', '赵六', '孙七'])
scores = np.array([85, 92, 78, 95, 88])

# 按成绩从高到低排序
# 先argsort得到升序索引，再反转得到降序索引
indices = np.argsort(scores)[::-1]

print("成绩排名：")
for rank, idx in enumerate(indices, 1):
    print(f"第{rank}名: {names[idx]}, 成绩: {scores[idx]}")

# 输出：
# 第1名: 赵六, 成绩: 95
# 第2名: 李四, 成绩: 92
# 第3名: 孙七, 成绩: 88
# 第4名: 张三, 成绩: 85
# 第5名: 王五, 成绩: 78
```

**理解这个例子**：
1. `argsort(scores)` 得到成绩从低到高的索引：[2, 0, 4, 1, 3]
2. `[::-1]` 反转得到从高到低的索引：[3, 1, 4, 0, 2]
3. 用这个索引同时调整名字和成绩，保持对应关系

## sort() vs argsort() - 选择哪个？

理解这两个函数的区别和使用场景非常重要：

| 函数 | 返回值 | 使用场景 | 是否改变原数组 |
|------|--------|----------|---------------|
| `np.sort()` | 排序后的数组 | 只需要排序后的值 | 否 |
| `arr.sort()` | None | 就地排序，节省内存 | 是 |
| `np.argsort()` | 排序的索引 | 需要调整多个相关数组 | 否 |

```python
# 示例：电商网站按价格排序商品
names = np.array(['手机', '耳机', '充电器', '数据线'])
prices = np.array([2999, 299, 99, 29])
sales = np.array([1523, 5432, 3241, 8765])

# 场景1：只需要显示价格从低到高
sorted_prices = np.sort(prices)
print("价格排序:", sorted_prices)  # [29 99 299 2999]

# 场景2：按价格排序，同时显示商品名和销量
# 必须用argsort，保持多个数组的对应关系
indices = np.argsort(prices)
print("\n商品列表（按价格从低到高）：")
for idx in indices:
    print(f"{names[idx]}: ¥{prices[idx]}, 销量{sales[idx]}")

# 输出：
# 数据线: ¥29, 销量8765
# 充电器: ¥99, 销量3241
# 耳机: ¥299, 销量5432
# 手机: ¥2999, 销量1523
```

**经验总结**：
- 单纯排序数字，用 `sort()`
- 需要保持多个数组对应关系，用 `argsort()`
- 需要节省内存的大数组，用 `arr.sort()` 就地排序

## 稳定排序和不稳定排序

排序算法有稳定和不稳定之分。稳定排序保证相等元素的相对位置不变，这在多次排序或处理结构化数据时很重要。

---

### 什么是稳定排序？

稳定排序：相等的元素在排序后保持原来的相对位置。

```python
# 学生数据：[姓名, 分数]
students = [
    ('张三', 85),
    ('李四', 92),
    ('王五', 85),  # 和张三同分
    ('赵六', 92),  # 和李四同分
    ('孙七', 78)
]

# 稳定排序后，同分的学生顺序不变
# 85分：张三在前，王五在后（保持）
# 92分：李四在前，赵六在后（保持）
```

---

### NumPy 中的排序算法

NumPy的sort函数支持多种排序算法，通过 `kind` 参数指定：

```python
arr = np.array([3, 1, 4, 1, 5, 9, 2, 6])

# 快速排序(默认) - 不稳定，但平均最快
sorted1 = np.sort(arr, kind='quicksort')

# 归并排序 - 稳定，时间复杂度O(n log n)
sorted2 = np.sort(arr, kind='mergesort')

# 堆排序 - 不稳定，时间复杂度O(n log n)
sorted3 = np.sort(arr, kind='heapsort')

# 稳定排序 - 自动选择稳定算法
sorted4 = np.sort(arr, kind='stable')
```

**排序算法对比**：

| 算法 | 稳定性 | 平均时间 | 最坏时间 | 空间复杂度 | 适用场景 |
|------|--------|----------|----------|------------|----------|
| quicksort | 不稳定 | O(n log n) | O(n²) | O(log n) | 默认选择，通常最快 |
| mergesort | 稳定 | O(n log n) | O(n log n) | O(n) | 需要稳定排序 |
| heapsort | 不稳定 | O(n log n) | O(n log n) | O(1) | 内存受限场景 |
| stable | 稳定 | O(n log n) | O(n log n) | O(n) | 自动选择最优稳定算法 |

---

### 稳定排序的实际应用

```python
# 学生成绩：先按班级排好序，再按分数排序
# 希望同分的学生保持班级顺序
names = np.array(['张三', '李四', '王五', '赵六', '孙七', '周八'])
classes = np.array([1, 2, 1, 2, 1, 2])  # 班级
scores = np.array([85, 85, 92, 92, 78, 85])  # 分数

# 先按班级排序
class_order = np.argsort(classes, kind='stable')
names = names[class_order]
classes = classes[class_order]
scores = scores[class_order]

print("按班级排序后：")
for n, c, s in zip(names, classes, scores):
    print(f"{n} - {c}班 - {s}分")

# 再按分数排序(使用稳定排序)
score_order = np.argsort(scores, kind='stable')[::-1]
names = names[score_order]
classes = classes[score_order]
scores = scores[score_order]

print("\n按分数排序后（同分保持班级顺序）：")
for n, c, s in zip(names, classes, scores):
    print(f"{n} - {c}班 - {s}分")

# 输出会显示同分的学生，1班的在2班前面
```

### 验证稳定性

```python
# 创建带索引的数组，验证稳定性
data = np.array([3, 1, 4, 1, 5, 9, 2, 6, 5])
indices = np.arange(len(data))

# 创建结构化数组
arr = np.array(list(zip(data, indices)),
               dtype=[('value', int), ('index', int)])

# 不稳定排序
sorted_unstable = np.sort(arr, order='value', kind='quicksort')
print("快速排序(可能不稳定):")
print(sorted_unstable)

# 稳定排序
sorted_stable = np.sort(arr, order='value', kind='stable')
print("\n稳定排序:")
print(sorted_stable)
# 注意观察相同值的原始索引顺序
```

**何时需要稳定排序**：
- 多次排序：先按一个条件，再按另一个条件
- 保持原有顺序：相等元素需要保持原始位置
- 数据库式排序：类似SQL的ORDER BY多个字段

## lexsort() - 多键排序

在实际应用中，经常需要按多个条件排序。比如学生成绩，先按总分排，总分相同再按单科排。`lexsort()` 就是为此设计的。

---

### 基本用法

`lexsort()` 接受一个元组或序列，按照最后一个键排序，相等时按倒数第二个键排序，依此类推。

```python
# 学生数据
names = np.array(['张三', '李四', '王五', '赵六', '孙七'])
scores = np.array([85, 92, 85, 92, 78])  # 总分
math = np.array([90, 88, 85, 90, 80])    # 数学

# 先按总分，总分相同按数学排序
# 注意：lexsort的参数顺序是反的，主要排序键在最后
indices = np.lexsort((math, scores))

print("排序后的学生：")
for idx in indices:
    print(f"{names[idx]}: 总分{scores[idx]}, 数学{math[idx]}")

# 输出（先按总分升序，总分相同按数学升序）：
# 孙七: 总分78, 数学80
# 王五: 总分85, 数学85
# 张三: 总分85, 数学90
# 李四: 总分92, 数学88
# 赵六: 总分92, 数学90
```

**理解 lexsort 的参数顺序**：
- `lexsort((key1, key2, key3))`
- 主要排序键是 `key3`
- `key3` 相同时按 `key2`
- `key2` 也相同时按 `key1`
- 顺序是**从后往前**的

---

### 降序排序

```python
names = np.array(['张三', '李四', '王五', '赵六'])
scores = np.array([85, 92, 85, 92])
math = np.array([90, 88, 85, 90])

# 按总分降序，总分相同按数学降序
# 方法：对负值排序
indices = np.lexsort((-math, -scores))

print("成绩排名（从高到低）：")
for rank, idx in enumerate(indices, 1):
    print(f"第{rank}名 {names[idx]}: 总分{scores[idx]}, 数学{math[idx]}")

# 输出：
# 第1名 赵六: 总分92, 数学90
# 第2名 李四: 总分92, 数学88
# 第3名 张三: 总分85, 数学90
# 第4名 王五: 总分85, 数学85
```

### 实战：商品多条件排序

```python
# 电商商品数据
products = np.array(['手机A', '手机B', '耳机A', '耳机B', '充电器'])
prices = np.array([2999, 2999, 299, 199, 99])
sales = np.array([1523, 2341, 5432, 3421, 8765])

indices = np.lexsort((prices, -sales, -ratings))

print("商品推荐列表：")
print(f"{'商品':<10} {'价格':<8} {'销量':<8} {'评分'}")
print("-" * 45)
for idx in indices:
    print(f"{products[idx]:<10} ¥{prices[idx]:<7} {sales[idx]:<8} {ratings[idx]}")

# 这样的排序符合实际的推荐逻辑：
# 优先推荐评分高的
# 评分相同推荐销量大的
# 这两者都相同时推荐便宜的
```

### lexsort vs argsort

什么时候用哪个？

```python
# 单一条件排序：用 argsort
```

## partition() 和 argpartition() - 部分排序

有时候我们不需要完全排序，只需要找出最大的几个或最小的几个元素。这时用 `partition()` 比完全排序更快。

---

### partition() 基本用法

`partition()` 将数组分成两部分：小于等于某个值的元素在左边，大于的在右边。但左右两部分内部不一定有序。

```python
# 学生成绩
scores = np.array([85, 92, 78, 95, 88, 76, 90, 82])

# partition(arr, k): 第k小的元素放在索引k的位置
# 左边都 <= arr[k]，右边都 >= arr[k]
partitioned = np.partition(scores, 3)
print("partition(scores, 3):", partitioned)
# [76 78 82 85 95 92 90 88]
#  --------  --  ----------
#    前3个  第4  后面的

# 第4小的元素(索引3)在正确位置
# 前面3个都比它小（但不一定排序）
# 后面的都比它大（但不一定排序）

print(f"第4小的分数: {partitioned[3]}")  # 85
```

---

### 找出最高的N个分数

```python
scores = np.array([85, 92, 78, 95, 88, 76, 90, 82])

# 找出最高的3个分数
# partition(arr, -3) 表示第3大的在倒数第3位
top3_partition = np.partition(scores, -3)
print("partition后:", top3_partition)
# [76 78 82 85 88 90 92 95]
#  -------------  --------
#   较小的部分    最大的3个

# 取最后3个就是最高的3个(但内部不一定有序)
top3 = top3_partition[-3:]
print("最高的3个:", top3)  # [90 92 95]

# 如果需要排序，再sort一下
top3_sorted = np.sort(top3)[::-1]
print("最高的3个(排序):", top3_sorted)  # [95 92 90]
```

### 何时使用 partition？

**使用场景**：
- 找最大/最小的K个元素
- 数组很大，K相对较小
- 不需要完全排序

**不适用场景**：
- 需要完整排序结果
- K接近数组大小
- 需要中位数等统计量（用专门的函数如 `np.median()`）

## searchsorted() - 二分查找

`searchsorted()` 在有序数组中查找元素应该插入的位置，使用二分查找算法，效率很高。

---

### 基本用法

```python
# 有序数组（必须是有序的）
sorted_arr = np.array([1, 3, 5, 7, 9, 11, 13])

# 查找5应该插入的位置
pos = np.searchsorted(sorted_arr, 5)
print(f"5应该插入的位置: {pos}")  # 2

# 查找6应该插入的位置（6不在数组中）
pos = np.searchsorted(sorted_arr, 6)
print(f"6应该插入的位置: {pos}")  # 3
# 插入后数组变为 [1, 3, 5, 6, 7, 9, 11, 13]

# 查找多个值
values = np.array([2, 6, 10, 14])
positions = np.searchsorted(sorted_arr, values)
print(f"插入位置: {positions}")  # [1 3 5 7]
```

**理解 searchsorted**：
- 返回的位置保证插入后数组仍然有序
- 时间复杂度 O(log n)，比线性查找快得多
- 数组必须是有序的

---

### side 参数：左插还是右插

当查找的值已经存在时，可以选择插入到左边还是右边。

```python
arr = np.array([1, 3, 5, 5, 5, 7, 9])

# side='left'(默认): 插入到相同值的左边
left_pos = np.searchsorted(arr, 5, side='left')
print(f"左插位置: {left_pos}")  # 2（第一个5的位置）

# side='right': 插入到相同值的右边
right_pos = np.searchsorted(arr, 5, side='right')
print(f"右插位置: {right_pos}")  # 5（最后一个5的后面）

# 利用这个特性可以统计某个值的出现次数
value = 5
left = np.searchsorted(arr, value, side='left')
right = np.searchsorted(arr, side='right')
count = right - left
print(f"{value}出现了{count}次")  # 5出现了3次
```

## where() - 条件搜索

`where()` 是NumPy中最常用的条件搜索函数，可以找出满足条件的元素。

---

### 基本用法

```python
scores = np.array([85, 92, 78, 95, 88, 76, 90, 82])

# 找出所有大于等于90分的位置
indices = np.where(scores >= 90)
print("90分以上的索引:", indices)  # (array([1, 3, 6]),)
print("90分以上的分数:", scores[indices])  # [92 95 90]

# where返回的是元组，即使是一维数组
# 取出数组用 indices[0]
high_score_indices = indices[0]
print("索引数组:", high_score_indices)  # [1 3 6]
```

---

### 多个条件组合

```python
scores = np.array([85, 92, 78, 95, 88, 76, 90, 82])

# AND条件：80分以上且不到90分
indices = np.where((scores >= 80) & (scores < 90))
print("80-89分:", scores[indices])  # [85 88 82]

# OR条件：低于70或高于90
indices = np.where((scores < 70) | (scores > 90))
print("< 70 or > 90:", scores[indices])  # [92 95]

# NOT条件：不在80-89之间
indices = np.where(~((scores >= 80) & (scores < 90)))
print("不在80-89:", scores[indices])  # [92 78 95 76 90]

# 注意：必须用 & | ~ 而不是 and or not
# 并且每个条件要用括号括起来
```

---

### where() 的三元表达式用法

`where()` 还可以像三元运算符一样使用，根据条件选择不同的值。

```python
labels = np.where(scores >= 90, '优秀',
                  np.where(scores >= 60, '及格', '不及格'))
print(labels)
# ['及格' '优秀' '及格' '优秀' '及格' '不及格' '优秀' '不及格']
```

## extract() - 条件提取

`extract()` 根据条件提取数组元素，返回满足条件的元素组成的一维数组。

---

### 基本用法

```python
scores = np.array([85, 92, 78, 95, 88, 76, 90, 82])

# 提取90分以上的成绩
high_scores = np.extract(scores >= 90, scores)
print("高分:", high_scores)  # [92 95 90]

# 等价于
high_scores2 = scores[scores >= 90]
print("等价写法:", high_scores2)  # [92 95 90]
```

**extract vs 布尔索引**：
- `np.extract(condition, arr)`：函数式
- `arr[condition]`：更简洁，更常用
- 功能完全相同，选择看个人喜好

## 排序算法的选择

不同的排序场景应该选择不同的算法，理解各种算法的特点可以让你的代码更高效。

---

### 各种排序算法对比

```python
import numpy as np
import time

# 创建不同特点的数组进行测试
n = 100000

# 1. 随机数组
random_arr = np.random.randint(0, 10000, n)

# 2. 几乎有序的数组
nearly_sorted = np.arange(n)
swap_indices = np.random.choice(n, size=100, replace=False)
nearly_sorted[swap_indices] = np.random.randint(0, n, 100)

# 3. 完全逆序
reversed_arr = np.arange(n)[::-1]

def benchmark_sort(arr, kind, name):
    arr_copy = arr.copy()
    start = time.time()
    np.sort(arr_copy, kind=kind)
    elapsed = time.time() - start
    print(f"{name}: {elapsed:.4f}秒")
    return elapsed

print("=== 随机数组 ===")
t1 = benchmark_sort(random_arr, 'quicksort', 'quicksort')
t2 = benchmark_sort(random_arr, 'mergesort', 'mergesort')
t3 = benchmark_sort(random_arr, 'heapsort', 'heapsort')

print("\n=== 几乎有序 ===")
benchmark_sort(nearly_sorted, 'quicksort', 'quicksort')
benchmark_sort(nearly_sorted, 'mergesort', 'mergesort')
benchmark_sort(nearly_sorted, 'heapsort', 'heapsort')

print("\n=== 完全逆序 ===")
benchmark_sort(reversed_arr, 'quicksort', 'quicksort')
benchmark_sort(reversed_arr, 'mergesort', 'mergesort')
benchmark_sort(reversed_arr, 'heapsort', 'heapsort')
```

---

### 算法选择建议

| 场景 | 推荐算法 | 原因 |
|------|----------|------|
| 随机数据 | quicksort | 平均最快 |
| 几乎有序 | 默认(quicksort) | NumPy会自动优化 |
| 需要稳定排序 | stable 或 mergesort | 保持相等元素顺序 |
| 内存受限 | heapsort | 原地排序，空间O(1) |
| 大量重复值 | quicksort | 现代实现对此优化 |
| 最坏情况保证 | mergesort 或 heapsort | O(n log n) |

```python
# 实际使用建议

# 场景1: 一般排序（不确定数据特点）
arr = np.random.randint(0, 1000, size=10000)
sorted_arr = np.sort(arr)  # 使用默认的quicksort

# 场景2: 多次排序，需要保持相对顺序
# 先按班级，再按分数
students = np.array([...])
# 使用稳定排序
sorted_students = np.sort(students, kind='stable')

# 场景3: 超大数组，内存紧张
big_arr = np.random.rand(10000000)
big_arr.sort(kind='heapsort')  # 就地排序 + 低内存

# 场景4: 只需要前K个最大值
arr = np.random.rand(1000000)
top100 = np.partition(arr, -100)[-100:]  # 比完全排序快很多
```

---

### 自定义排序

对于复杂的排序需求，可以使用结构化数组或多键排序。

```python
# 方法1: 使用结构化数组
students = np.array([
    ('张三', 85, 1),
    ('李四', 92, 2),
    ('王五', 85, 1),
    ('赵六', 92, 1)
], dtype=[('name', 'U10'), ('score', int), ('class', int)])

# 先按班级，再按分数
sorted_students = np.sort(students, order=['class', 'score'])
print(sorted_students)

# 方法2: 使用lexsort

classes = np.array([1, 2, 1, 1])

# 先按班级，再按分数
indices = np.lexsort((scores, classes))
sorted_names = names[indices]
sorted_scores = scores[indices]
sorted_classes = classes[indices]

print("排序结果：")
for n, s, c in zip(sorted_names, sorted_scores, sorted_classes):
    print(f"{n}: {c}班, {s}分")
```

```python
import numpy as np

# 模拟商品数据
np.random.seed(100)
num_products = 50

product_ids = np.arange(1, num_products + 1)
prices = np.random.randint(10, 500, num_products)
sales = np.random.randint(0, 10000, num_products)
ratings = np.random.uniform(3.5, 5.0, num_products).round(1)
stock = np.random.randint(0, 1000, num_products)

print("=" * 70)
print("电商商品排序系统")
print("=" * 70)

def show_products(indices, title, limit=5):
    """显示商品列表"""
    print(f"\n【{title}】")
    print(f"{'ID':<6} {'价格':<10} {'销量':<10} {'评分':<10} {'库存'}")
    print("-" * 70)
    for i, idx in enumerate(indices[:limit], 1):
        print(f"{product_ids[idx]:<6} ¥{prices[idx]:<9} {sales[idx]:<10} "
              f"{ratings[idx]:<10} {stock[idx]}")

# 1. 综合排序（常用推荐算法）
# 评分 > 销量 > 价格（低）
indices = np.lexsort((prices, -sales, -ratings))
show_products(indices, "综合推荐（评分+销量+价格）")

# 2. 价格从低到高
indices = np.argsort(prices)
show_products(indices, "价格从低到高")

# 3. 价格从高到低
indices = np.argsort(prices)[::-1]
show_products(indices, "价格从高到低")

# 4. 销量最高
indices = np.argsort(sales)[::-1]
show_products(indices, "销量最高")

# 5. 评分最高（评分相同按销量）
indices = np.lexsort((-sales, -ratings))
show_products(indices, "评分最高")

# 6. 新品推荐（库存多且评分高）
# 假设库存多的是新品
new_indices = np.where(stock > 500)[0]
if len(new_indices) > 0:
    new_ratings = ratings[new_indices]
    sorted_new = new_indices[np.argsort(new_ratings)[::-1]]
    show_products(sorted_new, "新品推荐（库存充足+高评分）")

# 7. 价格区间筛选
print("\n【价格区间筛选】")
ranges = [(0, 50), (50, 100), (100, 200), (200, float('inf'))]
for low, high in ranges:
    mask = (prices >= low) & (prices < high)
    count = np.sum(mask)
    if count > 0:
        range_indices = np.where(mask)[0]
        avg_rating = np.mean(ratings[range_indices])
        print(f"¥{low}-{high}: {count}件商品, 平均评分{avg_rating:.1f}")

# 8. 性价比排序（评分/价格）
print("\n【性价比排名 TOP5】")
value_ratio = ratings / (prices / 100)  # 归一化价格
top_value = np.argsort(value_ratio)[::-1]
print(f"{'ID':<6} {'价格':<10} {'评分':<10} {'性价比'}")
print("-" * 70)
for idx in top_value[:5]:
    print(f"{product_ids[idx]:<6} ¥{prices[idx]:<9} {ratings[idx]:<10} "
          f"{value_ratio[idx]:.2f}")

# 9. 清仓商品（库存少于50）
clearance = np.where(stock < 50)[0]
if len(clearance) > 0:
    # 按价格从低到高排序
    clearance_sorted = clearance[np.argsort(prices[clearance])]
    show_products(clearance_sorted, "清仓特价（库存不足）", limit=10)

# 10. 用partition找出价格最低的10件商品（快速）
print("\n【今日特价（最低10件）】")
bottom10_indices = np.argpartition(prices, 10)[:10]
# 再排序这10件
bottom10_sorted = bottom10_indices[np.argsort(prices[bottom10_indices])]
print(f"{'ID':<6} {'价格':<10} {'评分':<10} {'销量'}")
print("-" * 70)
for idx in bottom10_sorted:
    print(f"{product_ids[idx]:<6} ¥{prices[idx]:<9} {ratings[idx]:<10} {sales[idx]}")
```

```python
print(f"最大涨幅: {np.max(daily_return):.2f}% (第{np.argmax(daily_return)+1}天)")
print(f"最大跌幅: {np.min(daily_return):.2f}% (第{np.argmin(daily_return)+1}天)")

print(f"下跌天数: {down_days}天")

# 4. 最大跌幅的5天
print("\n【最大跌幅 TOP5】")
top5_down = np.argsort(daily_return)[:5]
```

## 总结

NumPy的排序和搜索功能强大且高效，掌握这些工具可以让数据处理事半功倍。

### 核心要点

**排序相关**：
1. `sort()` - 基本排序，有就地和返回副本两种方式
2. `argsort()` - 返回排序索引，用于调整多个相关数组
3. `lexsort()` - 多键排序，类似SQL的ORDER BY
4. `partition()` - 部分排序，找TopK比完全排序快
5. 排序算法选择：默认quicksort，需要稳定性用stable

**搜索相关**：
1. `searchsorted()` - 二分查找，在有序数组中快速定位
2. `where()` - 条件搜索，最常用的筛选函数
3. `nonzero()` - 找非零元素，等价于where(arr != 0)
4. `extract()` - 条件提取，等价于布尔索引

**性能技巧**：
- 有序数组用 `searchsorted()`，比线性搜索快几百倍
- 只需TopK用 `partition()`，比完全排序快2-3倍
- 多个相关数组用 `argsort()`保持对应关系
- 需要稳定性明确指定 `kind='stable'`

**实际应用**：
- 数据分析：排名、分组、分位数
- 推荐系统：综合排序、相似度计算
- 异常检测：阈值筛选、突变检测
- 性能优化：选择合适的算法和数据结构

- 高效进行数据搜索和筛选
- 根据场景选择最优算法
- 解决实际的数据分析问题
