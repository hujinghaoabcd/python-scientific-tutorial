# 第08章：NumPy数学函数

上一章我们学习了NumPy数组的各种操作，这一章我们深入学习NumPy强大的数学函数库。NumPy提供了丰富的数学函数，让我们可以高效地进行各种科学计算。

NumPy的数学函数都是**向量化**的，这意味着它们可以直接作用于整个数组，而不需要写循环。这不仅让代码更简洁，而且运行速度快得多！

---

## 为什么要用NumPy的数学函数？

```python
import numpy as np
import math
import time

# 用Python的math模块（需要循环）
arr = list(range(1000000))
start = time.time()
result1 = [math.sin(x) for x in arr]
time1 = time.time() - start

# 用NumPy（向量化，不需要循环）
arr_np = np.arange(1000000)
start = time.time()
result2 = np.sin(arr_np)
time2 = time.time() - start

print(f"math模块用时：{time1:.4f}秒")
print(f"NumPy用时：{time2:.4f}秒")
print(f"NumPy快了：{time1/time2:.1f}倍")
```

**输出**：
```
math模块用时：0.2341秒
NumPy用时：0.0156秒
NumPy快了：15.0倍
```

**NumPy数学函数的优势**：
1. **速度快** - 用C语言实现，速度是Python的几十倍
2. **向量化** - 直接作用于数组，不需要写循环
3. **功能全** - 包含几乎所有常用数学函数
4. **广播机制** - 自动处理不同形状的数组
5. **内存高效** - 原地操作，节省内存

## 三角函数

三角函数在科学计算、信号处理、图像处理等领域应用广泛。

### 基本三角函数

```python
import numpy as np

# 创建角度数组（0到360度）
angles_deg = np.array([0, 30, 45, 60, 90, 180, 270, 360])

# 转换为弧度（NumPy的三角函数使用弧度）
angles_rad = np.radians(angles_deg)

# sin函数
sin_values = np.sin(angles_rad)
print("角度：", angles_deg)
print("sin值：", np.round(sin_values, 2))

# cos函数
cos_values = np.cos(angles_rad)
print("cos值：", np.round(cos_values, 2))

# tan函数
tan_values = np.tan(angles_rad)
print("tan值：", np.round(tan_values, 2))
```

**输出**：
```
角度： [  0  30  45  60  90 180 270 360]
sin值： [ 0.   0.5  0.71 0.87 1.   0.  -1.   0.  ]
cos值： [ 1.   0.87 0.71 0.5  0.  -1.   0.   1.  ]
tan值： [ 0.    0.58  1.    1.73  1.63e+16 -0.   -1.63e+16  0.  ]
```

**注意**：tan(90°)的值非常大（接近无穷），这是因为cos(90°) = 0，tan = sin/cos会导致除以接近0的数。

### 反三角函数

```python
import numpy as np

# sin、cos、tan的值

print("arcsin（角度）：", np.round(np.degrees(arcsin_values), 1))

arccos_values = np.arccos(values)
print("\narccos（弧度）：", np.round(arccos_values, 2))
print("arccos（角度）：", np.round(np.degrees(arccos_values), 1))

arctan_values = np.arctan(values)

print("arctan（角度）：", np.round(np.degrees(arctan_values), 1))
```

**输出**：

## 指数和对数函数

指数和对数函数在科学计算、机器学习中非常常用。

### 指数函数

```python
import numpy as np

x_small = np.array([0, 0.001, 0.01, 0.1])

```

```
2^x： [ 1.  2.  4.  8. 16.]

e^x - 1： [0.      0.001   0.01005 0.10517]

e = 2.7182818285
```

### 换底公式

```python
import numpy as np

# 计算log₃(27)
# 换底公式：logₐ(b) = ln(b) / ln(a)
a = 3
b = 27
result = np.log(b) / np.log(a)
print(f"log₃(27) = {result}")  # 3.0

# 计算任意底的对数
def logbase(x, base):
    """计算以base为底的x的对数"""
    return np.log(x) / np.log(base)

# 测试
print(f"log₅(125) = {logbase(125, 5)}")  # 3.0
print(f"log₇(343) = {logbase(343, 7)}")  # 3.0
```

## 四舍五入函数

NumPy提供了多种取整方式，适用于不同场景。

### round - 四舍五入

```python
import numpy as np

# 小数数组
arr = np.array([1.2, 1.5, 1.8, 2.3, 2.5, 2.7, -1.5, -2.5])

# 四舍五入到整数
rounded = np.round(arr)
print("原数组：", arr)
print("四舍五入：", rounded)

# 四舍五入到指定小数位
arr2 = np.array([3.14159, 2.71828, 1.41421])
print("\n保留2位小数：", np.round(arr2, 2))
print("保留3位小数：", np.round(arr2, 3))

# 四舍五入到十位、百位
arr3 = np.array([123, 456, 789])
print("\n原数组：", arr3)
print("四舍五入到十位：", np.round(arr3, -1))
print("四舍五入到百位：", np.round(arr3, -2))
```

**输出**：
```
原数组： [ 1.2  1.5  1.8  2.3  2.5  2.7 -1.5 -2.5]
四舍五入： [ 1.  2.  2.  2.  2.  3. -2. -2.]

保留2位小数： [3.14 2.72 1.41]
保留3位小数： [3.142 2.718 1.414]

原数组： [123 456 789]
四舍五入到十位： [120. 460. 790.]
四舍五入到百位： [100. 500. 800.]
```

**注意**：NumPy的round采用"银行家舍入"（四舍六入五取偶），即当小数部分恰好是0.5时，取最近的偶数。

---

### floor - 向下取整

```python
import numpy as np

# 向下取整（朝负无穷方向）
arr = np.array([1.2, 1.5, 1.8, -1.2, -1.5, -1.8])
floored = np.floor(arr)

print("原数组：", arr)
print("向下取整：", floored)

# 实战：计算整数倍
prices = np.array([19.9, 29.5, 39.7, 49.2])
discounted = np.floor(prices)  # 只取整数部分
print("\n原价：", prices)
print("打折后（只取整数）：", discounted)
```

**输出**：
```
原数组： [ 1.2  1.5  1.8 -1.2 -1.5 -1.8]
向下取整： [ 1.  1.  1. -2. -2. -2.]

原价： [19.9 29.5 39.7 49.2]
打折后（只取整数）： [19. 29. 39. 49.]
```

**注意**：floor是向负无穷方向取整，所以-1.2的floor是-2，不是-1。

### trunc - 截断取整

```python
import numpy as np

# 截断（朝零方向取整，去掉小数部分）
arr = np.array([1.2, 1.5, 1.8, -1.2, -1.5, -1.8])
truncated = np.trunc(arr)

print("原数组：", arr)
print("截断取整：", truncated)

# 对比不同取整方式
print("\n对比不同取整方式：")
print("round：", np.round(arr))
print("floor：", np.floor(arr))
print("ceil： ", np.ceil(arr))
print("trunc：", np.trunc(arr))
```

**输出**：
```
原数组： [ 1.2  1.5  1.8 -1.2 -1.5 -1.8]
截断取整： [ 1.  1.  1. -1. -1. -1.]

对比不同取整方式：
round： [ 1.  2.  2. -1. -2. -2.]
floor： [ 1.  1.  1. -2. -2. -2.]
ceil：  [ 2.  2.  2. -1. -1. -1.]
trunc： [ 1.  1.  1. -1. -1. -1.]
```

```python
import numpy as np

# 基本幂运算

result = np.power(base, exponent)

print(f"底数：{base}")
```

## 向量化应用

向量化是NumPy的核心优势，让我们的代码更简洁、更快。

### 什么是向量化？

```python
import numpy as np
import time

# 创建大数组
n = 1000000
arr = np.random.rand(n)

# 方法1：用Python循环（慢）
start = time.time()
result1 = []
for x in arr:
    result1.append(x ** 2 + 2 * x + 1)
result1 = np.array(result1)
time1 = time.time() - start

# 方法2：向量化（快）
start = time.time()
result2 = arr ** 2 + 2 * arr + 1
time2 = time.time() - start

print(f"Python循环用时：{time1:.4f}秒")
print(f"向量化用时：{time2:.4f}秒")
print(f"向量化快了：{time1/time2:.1f}倍")
print(f"结果相同：{np.allclose(result1, result2)}")
```

```python
print("\n归一化后范围：", images_normalized.min(), "到", images_normalized.max())

# 中心化（减去均值）
mean = np.mean(images_normalized, axis=(1, 2), keepdims=True)
images_centered = images_normalized - mean
print("中心化后均值：", np.mean(images_centered, axis=(1, 2)))

# 添加噪声
noise = np.random.normal(0, 0.1, images.shape)
images_noisy = images_normalized + noise
images_noisy = np.clip(images_noisy, 0, 1)  # 裁剪到有效范围

# 批量应用滤波器（简单平均滤波）
def simple_blur(image, kernel_size=3):
    """简单的平均滤波"""
    pad = kernel_size // 2
    padded = np.pad(image, pad, mode='edge')
    result = np.zeros_like(image)

    for i in range(image.shape[0]):
        for j in range(image.shape[1]):
            result[i, j] = np.mean(padded[i:i+kernel_size, j:j+kernel_size])

    return result

# 对第一张图像应用滤波
blurred = simple_blur(images_normalized[0])
print("\n滤波前后对比：")
print("原图平均值：", np.mean(images_normalized[0]))
print("滤波后平均值：", np.mean(blurred))
```

## 性能优化技巧

### 使用合适的数据类型

```python
import numpy as np

# 使用较小的数据类型节省内存
arr_int64 = np.array([1, 2, 3, 4, 5], dtype=np.int64)
arr_int8 = np.array([1, 2, 3, 4, 5], dtype=np.int8)

print("int64内存：", arr_int64.nbytes, "字节")
print("int8内存：", arr_int8.nbytes, "字节")

# 大数组时内存差异明显
large_int64 = np.ones(1000000, dtype=np.int64)
large_int8 = np.ones(1000000, dtype=np.int8)

print("\n百万元素数组：")
print("int64内存：", large_int64.nbytes / 1024, "KB")
print("int8内存：", large_int8.nbytes / 1024, "KB")
```

---

### 避免不必要的复制

```python
import numpy as np

arr = np.arange(1000000)

# 视图（不复制数据）
view = arr[::2]  # 每隔一个取一个
print("是视图：", view.base is arr)

# 副本（复制数据）
copy = arr[::2].copy()
print("是副本：", copy.base is None)

# 原地操作（节省内存）
arr += 1  # 原地加1
# 等价于 arr = arr + 1（会创建新数组）
```

---

### 使用out参数

```python
import numpy as np

# 不使用out参数（创建新数组）
arr = np.arange(1000000, dtype=float)
result = np.sin(arr)

# 使用out参数（原地操作）
arr2 = np.arange(1000000, dtype=float)
np.sin(arr2, out=arr2)  # 结果存回arr2

print("使用out参数可以节省内存")
```

### 使用einsum（高级）

```python
import numpy as np

# 矩阵乘法
A = np.random.rand(100, 100)
B = np.random.rand(100, 100)

# 传统方法
C1 = np.dot(A, B)

# 使用einsum（更灵活）
C2 = np.einsum('ij,jk->ik', A, B)

print("结果相同：", np.allclose(C1, C2))

# einsum的其他用途
arr = np.random.rand(10, 10)

# 对角线求和
trace = np.einsum('ii->', arr)
print("\n矩阵的迹：", trace)
print("验证：", np.trace(arr))

# 逐元素乘法后求和
arr1 = np.random.rand(5, 5)
arr2 = np.random.rand(5, 5)
result = np.einsum('ij,ij->', arr1, arr2)
print("\n点积：", result)
print("验证：", np.sum(arr1 * arr2))
```

## 常见陷阱和注意事项

### 陷阱1：整数除法

```python
import numpy as np

# 整数数组除法
arr = np.array([1, 2, 3, 4, 5])
result = arr / 2

print("整数除法结果：", result)
print("结果类型：", result.dtype)  # float64

# 如果想要整数结果
result_int = arr // 2
print("整除结果：", result_int)
print("结果类型：", result_int.dtype)  # int64
```

---

### 陷阱2：浮点数精度

```python
import numpy as np

# 浮点数精度问题
a = np.array([0.1, 0.2, 0.3])
b = np.array([0.3, 0.3, 0.3])

print("0.1 + 0.2 == 0.3:", a[0] + a[1] == b[0])  # False

# 正确的比较方式
print("近似相等：", np.allclose(a[0] + a[1], b[0]))  # True

# 或者指定容差
print("近似相等：", np.abs(a[0] + a[1] - b[0]) < 1e-10)
```

---

### 陷阱3：数组形状

```python
import numpy as np

# 一维数组和行向量不同
arr_1d = np.array([1, 2, 3])
arr_row = np.array([[1, 2, 3]])
arr_col = np.array([[1], [2], [3]])

print("一维形状：", arr_1d.shape)  # (3,)
print("行向量形状：", arr_row.shape)  # (1, 3)
print("列向量形状：", arr_col.shape)  # (3, 1)

# 影响运算结果
print("\n一维 × 一维：", arr_1d * arr_1d)
print("行向量 × 列向量：\n", arr_row.T @ arr_col)
```

---

### 陷阱4：就地修改

```python
import numpy as np

# 小心就地修改
arr = np.array([1, 2, 3, 4, 5])
arr2 = arr  # 不是复制，是引用

arr2[0] = 999
print("arr：", arr)  # [999, 2, 3, 4, 5]，被修改了！

# 正确的复制
arr = np.array([1, 2, 3, 4, 5])
arr2 = arr.copy()

arr2[0] = 999
print("arr：", arr)  # [1, 2, 3, 4, 5]，没有被修改
print("arr2：", arr2)  # [999, 2, 3, 4, 5]
```
