# 第09章：NumPy统计函数

数据分析离不开统计。想象一下，你拿到一份班级成绩单，想知道平均分、最高分、有多少人及格，这些都需要统计函数来完成。NumPy提供了一整套强大的统计函数，让数据分析变得简单高效。

这一章我们将学习NumPy的统计函数，从基本的求平均值、求和，到复杂的分位数、相关系数，再到处理缺失数据。学完这一章，你就能像专业数据分析师一样处理各种统计问题了！

---

## 为什么需要统计函数？

在日常工作中，我们经常需要从数据中提取有用的信息：

- **学生成绩分析**：计算平均分、最高分、标准差，了解整体水平和波动情况
- **销售数据分析**：统计总销售额、月均销售额、销售趋势
- **气温数据分析**：计算平均气温、最高最低温、温度波动
- **股票分析**：计算收益率、波动率、相关性

NumPy的统计函数可以高效地完成这些任务，而且代码简洁易懂。

## 基本统计函数

让我们从最基础、最常用的统计函数开始。这些函数是数据分析的基础，几乎每次分析都会用到。

---

### 平均值（mean）

平均值是最常用的统计指标，表示数据的集中趋势。就像班级的平均分，能反映整体水平。

```python
import numpy as np

# 一维数组的平均值
scores = np.array([85, 92, 78, 96, 88])
average = np.mean(scores)
print(f"平均分：{average}")  # 87.8

# 也可以用数组的方法
print(scores.mean())  # 87.8

# 二维数组
class_scores = np.array([
    [85, 92, 78],  # 第一个学生的三科成绩
    [88, 95, 82],  # 第二个学生
    [92, 89, 90]   # 第三个学生
])

# 整体平均值
print(np.mean(class_scores))  # 87.66...

# 按列求平均（每科的平均分）
print(np.mean(class_scores, axis=0))  # [88.33 92.   83.33]

# 按行求平均（每个学生的平均分）
print(np.mean(class_scores, axis=1))  # [85.  88.33 90.33]
```

**实际应用 - 分析班级成绩**：
```python
# 三个班级的数学成绩
math_scores = np.array([
    [85, 92, 78, 88, 95],  # 一班
    [82, 88, 90, 85, 87],  # 二班
    [90, 85, 88, 92, 89]   # 三班
])

# 每个班的平均分
class_avg = np.mean(math_scores, axis=1)
print("各班平均分：", class_avg)  # [87.6 86.4 88.8]

# 每个学生位置的平均分（同一位置学生的平均）
position_avg = np.mean(math_scores, axis=0)
print("各位置平均分：", position_avg)  # [85.67 88.33 85.33 88.33 90.33]

# 全年级平均分
total_avg = np.mean(math_scores)
print(f"全年级平均分：{total_avg:.2f}")  # 87.60
```

### 中位数（median）

中位数是排序后位于中间位置的数，不受极端值影响。比如工资统计，中位数比平均值更能反映真实水平。

```python
# 工资数据（有极端高值）
salaries = np.array([5000, 5500, 6000, 5800, 6200, 50000])

# 平均工资（被高薪拉高了）
print(f"平均工资：{np.mean(salaries):.0f}")  # 13083元

# 中位数工资（更能反映真实水平）
print(f"中位数工资：{np.median(salaries):.0f}")  # 5900元

# 二维数组的中位数
data = np.array([
    [10, 20, 30],
    [15, 25, 35],
    [12, 22, 32]
])

print(np.median(data))  # 22.0（整体中位数）
print(np.median(data, axis=0))  # [12. 22. 32.]（每列的中位数）
print(np.median(data, axis=1))  # [20. 25. 22.]（每行的中位数）
```

**平均值 vs 中位数**：
```python
# 正常分布的数据
normal_data = np.array([10, 12, 11, 13, 12, 11, 10])
print(f"平均值：{np.mean(normal_data):.2f}")  # 11.29
print(f"中位数：{np.median(normal_data):.2f}")  # 11.00
# 两者接近

# 有极端值的数据
skewed_data = np.array([10, 12, 11, 13, 12, 11, 100])
print(f"平均值：{np.mean(skewed_data):.2f}")  # 24.14（被拉高）
print(f"中位数：{np.median(skewed_data):.2f}")  # 12.00（不受影响）
# 中位数更能反映大部分数据的水平
```

### 标准差和方差

标准差和方差用来衡量数据的波动程度。标准差越大，说明数据越分散；标准差越小，说明数据越集中。

**理解标准差**：
- 两个班级平均分都是80分，但一班学生成绩集中在75-85分，二班学生成绩从60-100分都有
- 一班标准差小（成绩稳定），二班标准差大（成绩波动大）

**方差和标准差的关系**：
- 标准差 = √方差
- 方差 = 标准差²
- 标准差更直观（单位和原数据一致），方差用于数学计算

```python
# 两个班级的成绩
class_a = np.array([78, 79, 80, 81, 82])  # 成绩集中
class_b = np.array([60, 70, 80, 90, 100])  # 成绩分散

print(f"一班平均分：{np.mean(class_a)}")  # 80.0
print(f"二班平均分：{np.mean(class_b)}")  # 80.0

# 标准差
print(f"一班标准差：{np.std(class_a):.2f}")  # 1.41（小，成绩稳定）
print(f"二班标准差：{np.std(class_b):.2f}")  # 14.14（大，成绩波动）

# 方差
print(f"一班方差：{np.var(class_a):.2f}")  # 2.00
print(f"二班方差：{np.var(class_b):.2f}")  # 200.00

# 验证：标准差 = √方差
print(f"二班方差的平方根：{np.sqrt(np.var(class_b)):.2f}")  # 14.14
```

**无偏估计 vs 有偏估计**：
```python
data = np.array([10, 12, 15, 18, 20])

# 总体标准差（分母是n，默认）
print(np.std(data))  # 3.416...

# 样本标准差（分母是n-1，无偏估计）
print(np.std(data, ddof=1))  # 3.807...

# ddof = Delta Degrees of Freedom（自由度修正）
# ddof=0：除以n（总体标准差，默认）
# ddof=1：除以n-1（样本标准差，统计学常用）
```

**实际应用 - 分析考试成绩稳定性**：
```python
# 小明和小红三次考试成绩
xiaoming = np.array([85, 88, 87])  # 成绩稳定
xiaohong = np.array([70, 90, 85])  # 成绩波动大

print(f"小明平均分：{np.mean(xiaoming):.1f}")  # 86.7
print(f"小红平均分：{np.mean(xiaohong):.1f}")  # 81.7

print(f"小明标准差：{np.std(xiaoming):.2f}")  # 1.25（稳定）
print(f"小红标准差：{np.std(xiaohong):.2f}")  # 8.16（不稳定）

# 结论：小明平均分更高且更稳定，小红波动大
```

## 最值函数

找出数据中的最大值、最小值，以及它们的位置，是数据分析的常见需求。

---

### 最大值和最小值（max、min）

```python
scores = np.array([85, 92, 78, 96, 88])

# 最大值
print(np.max(scores))  # 96
print(scores.max())    # 96（数组方法）

# 最小值
print(np.min(scores))  # 78
print(scores.min())    # 78

# 二维数组
data = np.array([
    [10, 20, 30],
    [15, 25, 35],
    [12, 22, 32]
])

print(np.max(data))  # 35（整体最大值）
print(np.max(data, axis=0))  # [15 25 35]（每列最大值）
print(np.max(data, axis=1))  # [30 35 32]（每行最大值）
```

**实际应用 - 找出温度极值**：
```python
# 一周每天的最高温和最低温
temperatures = np.array([
    [25, 15],  # 周一：最高25°C，最低15°C
    [28, 18],  # 周二
    [26, 16],  # 周三
    [30, 20],  # 周四
    [27, 17],  # 周五
    [29, 19],  # 周六
    [26, 16]   # 周日
])

# 本周最高温
print(f"本周最高温：{np.max(temperatures[:, 0])}°C")  # 30

# 本周最低温
print(f"本周最低温：{np.min(temperatures[:, 1])}°C")  # 15

# 每天的温差
daily_range = temperatures[:, 0] - temperatures[:, 1]
print(f"最大温差：{np.max(daily_range)}°C")  # 10
```

### 最值位置（argmax、argmin）

有时我们不仅想知道最大值是多少，还想知道它在哪个位置。

```python
scores = np.array([85, 92, 78, 96, 88])

# 最大值的索引
max_index = np.argmax(scores)
print(f"最高分的索引：{max_index}")  # 3
print(f"最高分：{scores[max_index]}")  # 96

# 最小值的索引
min_index = np.argmin(scores)
print(f"最低分的索引：{min_index}")  # 2
print(f"最低分：{scores[min_index]}")  # 78

# 二维数组（展平后的索引）
data = np.array([
    [10, 20, 30],
    [15, 25, 35],
    [12, 22, 32]
])

print(np.argmax(data))  # 5（展平后的索引，对应35）
print(np.argmax(data, axis=0))  # [1 1 1]（每列最大值的行索引）
print(np.argmax(data, axis=1))  # [2 2 2]（每行最大值的列索引）
```

**实际应用 - 找出最佳销售员和最差销售员**：
```python
# 销售员姓名
names = np.array(['张三', '李四', '王五', '赵六', '钱七'])

# 销售额（万元）
sales = np.array([120, 95, 150, 88, 135])

# 找出销售冠军
best_index = np.argmax(sales)
print(f"销售冠军：{names[best_index]}，销售额：{sales[best_index]}万元")
# 销售冠军：王五，销售额：150万元

# 找出最差销售
worst_index = np.argmin(sales)
print(f"最差销售：{names[worst_index]}，销售额：{sales[worst_index]}万元")
# 最差销售：赵六，销售额：88万元
```

**多维数组的argmax/argmin**：
```python
# 三个月，每个月四周的销售数据
sales = np.array([
    [100, 120, 110, 130],  # 第一个月
    [150, 140, 160, 155],  # 第二个月
    [120, 125, 118, 135]   # 第三个月
])

# 哪周销售最好（展平后的索引）
best_week_flat = np.argmax(sales)
print(f"最佳销售周（展平索引）：{best_week_flat}")  # 6

# 转换成二维索引
best_month = best_week_flat // 4
best_week = best_week_flat % 4
print(f"最佳销售是第{best_month+1}月第{best_week+1}周")
# 最佳销售是第2月第3周

# 每个月哪周销售最好
best_weeks = np.argmax(sales, axis=1)
print("每月最佳周：", best_weeks)  # [3 2 3]（从0开始计数）
```

## 求和函数

求和是最基本的统计操作，NumPy提供了多种求和函数。

---

### 基本求和（sum）

```python
# 一维数组求和
sales = np.array([100, 120, 95, 110, 130])
total = np.sum(sales)
print(f"总销售额：{total}")  # 555

# 二维数组求和
monthly_sales = np.array([
    [100, 120, 110],  # 第一个季度
    [150, 140, 160],  # 第二个季度
    [120, 125, 135]   # 第三个季度
])

# 整体求和
print(f"总销售额：{np.sum(monthly_sales)}")  # 1260

# 按列求和（每个位置的总和）
print("各月总和：", np.sum(monthly_sales, axis=0))  # [370 385 405]

# 按行求和（每个季度的总和）
print("各季度总和：", np.sum(monthly_sales, axis=1))  # [330 450 380]
```

**实际应用 - 计算季度和年度销售额**：
```python
# 四个季度，每季度三个月的销售额（万元）
sales = np.array([
    [100, 120, 110],  # Q1
    [150, 140, 160],  # Q2
    [120, 125, 135],  # Q3
    [180, 170, 190]   # Q4
])

# 每个季度的总销售额
quarterly_total = np.sum(sales, axis=1)
print("季度销售额：", quarterly_total)  # [330 450 380 540]

# 全年总销售额
annual_total = np.sum(sales)
print(f"全年销售额：{annual_total}万元")  # 1700万元

# 每个月份位置的总销售（比如所有第一个月）
monthly_position = np.sum(sales, axis=0)
print("月份位置总和：", monthly_position)  # [550 555 595]
```

### 累积求和（cumsum）

累积求和返回到每个位置为止的累计和，对分析累计趋势很有用。

```python
# 每月新增用户
new_users = np.array([100, 150, 120, 180, 200])

# 累计用户数
cumulative_users = np.cumsum(new_users)
print("累计用户数：", cumulative_users)
# [100 250 370 550 750]

# 二维数组
data = np.array([
    [10, 20, 30],
    [15, 25, 35]
])

# 展平后累积求和
print(np.cumsum(data))  # [10 30 60 75 100 135]

# 按行累积（每行内部累加）
print(np.cumsum(data, axis=1))
# [[10 30 60]
#  [15 40 75]]

# 按列累积（每列内部累加）
print(np.cumsum(data, axis=0))
# [[10 20 30]
#  [25 45 65]]
```

**实际应用 - 分析累计收入**：
```python
# 每月收入（万元）
monthly_income = np.array([50, 60, 55, 70, 65, 75, 80, 85, 90, 95, 100, 110])

# 累计收入
cumulative_income = np.cumsum(monthly_income)
print("累计收入（万元）：")
for month, cum in enumerate(cumulative_income, 1):
    print(f"第{month:2d}月：{cum:4d}")

# 输出：
# 第 1月：  50
# 第 2月： 110
# 第 3月： 165
# ...
# 第12月： 935
```

### 处理NaN值的求和（nansum）

真实数据中常有缺失值（NaN），普通的sum会返回NaN，nansum会忽略NaN。

```python
# 包含缺失值的数据
data = np.array([10, 20, np.nan, 30, 40])

# 普通求和（结果是NaN）
print(np.sum(data))  # nan

# 忽略NaN的求和
print(np.nansum(data))  # 100.0

# 二维数组
scores = np.array([
    [85, 92, np.nan],
    [88, np.nan, 82],
    [92, 89, 90]
])

# 每列的和（忽略NaN）
print(np.nansum(scores, axis=0))  # [265. 181.  172.]

# 每行的和（忽略NaN）
print(np.nansum(scores, axis=1))  # [177. 170. 271.]
```

## 分位数和百分位数

分位数把数据分成几等份，百分位数则更精确地定位数据的位置。

---

### 什么是分位数和百分位数？

**理解分位数**：
- 中位数 = 50%分位数（把数据分成两半）
- 四分位数：把数据分成四份
  - Q1（25%分位数）：有25%的数据小于它
  - Q2（50%分位数）：就是中位数
  - Q3（75%分位数）：有75%的数据小于它

**理解百分位数**：
- 90%分位数：有90%的数据小于或等于这个值
- 比如考试成绩90%分位数是85分，说明你超过了90%的人

```python
# 考试成绩
scores = np.array([60, 65, 70, 75, 80, 85, 90, 95, 100])

# 中位数（50%分位数）
print(f"中位数：{np.percentile(scores, 50)}")  # 80.0

# 四分位数
q1 = np.percentile(scores, 25)  # 第一四分位数
q2 = np.percentile(scores, 50)  # 第二四分位数（中位数）
q3 = np.percentile(scores, 75)  # 第三四分位数

print(f"Q1（25%）：{q1}")  # 70.0
print(f"Q2（50%）：{q2}")  # 80.0
print(f"Q3（75%）：{q3}")  # 90.0

# 一次计算多个分位数
quartiles = np.percentile(scores, [25, 50, 75])
print("四分位数：", quartiles)  # [70. 80. 90.]
```

**实际应用 - 分析工资水平**：
```python
# 公司员工工资（元）
salaries = np.array([
    5000, 5500, 6000, 6200, 6500, 7000, 7500, 8000,
    8500, 9000, 10000, 12000, 15000, 20000, 50000
])

# 基本统计
print(f"平均工资：{np.mean(salaries):.0f}元")  # 11380（被高薪拉高）
print(f"中位数工资：{np.median(salaries):.0f}元")  # 8000（更真实）

# 分位数分析
p25 = np.percentile(salaries, 25)
p50 = np.percentile(salaries, 50)
p75 = np.percentile(salaries, 75)
p90 = np.percentile(salaries, 90)

print(f"25%的人工资低于：{p25:.0f}元")  # 6050
print(f"50%的人工资低于：{p50:.0f}元")  # 8000
print(f"75%的人工资低于：{p75:.0f}元")  # 10500
print(f"90%的人工资低于：{p90:.0f}元")  # 16000

# 结论：你的工资8500元，超过了50-75%的员工
```

### quantile vs percentile

NumPy提供了两个函数：`quantile`和`percentile`，它们的区别只是参数范围不同。

```python
data = np.array([10, 20, 30, 40, 50])

# percentile：参数范围0-100
print(np.percentile(data, 50))  # 30.0（50%分位数）

# quantile：参数范围0-1
print(np.quantile(data, 0.5))  # 30.0（0.5分位数，相当于50%）

# 它们本质上是一样的
print(np.percentile(data, 25))  # 20.0
print(np.quantile(data, 0.25))  # 20.0

# percentile更直观（百分比），quantile更数学化
```

## 相关系数和协方差

相关系数和协方差用来衡量两组数据之间的关系。

---

### 相关系数（corrcoef）

相关系数衡量两组数据的线性相关程度，范围在-1到1之间。

**理解相关系数**：
- **1**：完全正相关（一个增加，另一个也增加）
- **0**：不相关
- **-1**：完全负相关（一个增加，另一个减少）

**例子**：
- 学习时间和成绩：正相关（学得越多，分越高）
- 气温和空调销量：正相关
- 气温和羽绒服销量：负相关

```python
# 学习时间（小时）和考试成绩
study_hours = np.array([2, 3, 4, 5, 6, 7, 8])
scores = np.array([60, 65, 70, 75, 80, 85, 90])

# 计算相关系数矩阵
correlation = np.corrcoef(study_hours, scores)
print("相关系数矩阵：")
print(correlation)
# [[1.  1.]    # 学习时间与自己的相关系数是1
#  [1.  1.]]   # 成绩与学习时间的相关系数接近1

# 提取相关系数（非对角线元素）
r = correlation[0, 1]
print(f"学习时间和成绩的相关系数：{r:.3f}")  # 1.000（完全正相关）
```

**实际应用 - 分析温度和销量的关系**：
```python
# 气温（摄氏度）
temperature = np.array([15, 18, 22, 25, 28, 32, 35, 38])

# 冰淇淋销量（份）
ice_cream = np.array([50, 60, 80, 100, 120, 150, 180, 200])

# 羽绒服销量（件）
down_jacket = np.array([100, 90, 70, 50, 30, 20, 10, 5])

# 温度和冰淇淋的相关系数
r_ice = np.corrcoef(temperature, ice_cream)[0, 1]
print(f"温度和冰淇淋销量相关系数：{r_ice:.3f}")  # 0.996（强正相关）

# 温度和羽绒服的相关系数
r_jacket = np.corrcoef(temperature, down_jacket)[0, 1]
print(f"温度和羽绒服销量相关系数：{r_jacket:.3f}")  # -0.992（强负相关）

# 结论：
# 温度越高，冰淇淋卖得越好（正相关）
# 温度越高，羽绒服卖得越少（负相关）
```

**多变量相关矩阵**：
```python
# 三个科目的成绩
math = np.array([85, 90, 78, 92, 88])
physics = np.array([82, 88, 75, 90, 85])  # 和数学相关
english = np.array([70, 75, 90, 68, 72])  # 和数学不太相关

# 计算相关矩阵
corr_matrix = np.corrcoef([math, physics, english])
print("相关系数矩阵：")
print(corr_matrix)
# [[1.    0.998 -0.816]  # 数学与各科
#  [0.998 1.    -0.781]  # 物理与各科
#  [-0.816 -0.781 1.]]   # 英语与各科

# 解读：
# 数学和物理高度正相关（0.998）
# 数学和英语负相关（-0.816）
```

### 协方差（cov）

协方差也用来衡量两组数据的相关性，但它不像相关系数那样标准化。

**协方差 vs 相关系数**：
- 协方差：衡量相关性，但受量纲影响
- 相关系数：标准化的协方差，范围在[-1, 1]，更好理解

```python
# 学习时间和成绩
study_hours = np.array([2, 3, 4, 5, 6])
scores = np.array([60, 70, 75, 80, 90])

# 计算协方差矩阵
cov_matrix = np.cov(study_hours, scores)
print("协方差矩阵：")
print(cov_matrix)
# [[2.5  25. ]     # study_hours的方差和协方差
#  [25.  125.]]    # scores的方差和协方差

# 提取协方差（非对角线元素）
cov = cov_matrix[0, 1]
print(f"协方差：{cov}")  # 25.0

# 对角线是方差
print(f"学习时间的方差：{cov_matrix[0, 0]}")  # 2.5
print(f"成绩的方差：{cov_matrix[1, 1]}")  # 125.0

# 协方差是正数，说明正相关
# 协方差是负数，说明负相关
# 但具体数值不好解释，所以更常用相关系数
```

### histogram - 计算直方图

histogram函数把数据分成若干区间（bins），统计每个区间的数据个数。

```python
print("每个区间的个数：", counts)
# [3 3 5 5 4]

# 解读：
# [55, 64)：3人
# [64, 73)：3人
# [73, 82)：5人
# [82, 91)：5人
# [91, 100]：4人
```

## axis参数详解

axis参数在NumPy中非常重要，但也是初学者最容易困惑的地方。让我们彻底搞清楚它！

---

### 理解axis

**axis的含义**：
- **axis=0**：沿着第0维操作（按列操作，对行进行运算）
- **axis=1**：沿着第1维操作（按行操作，对列进行运算）
- **axis=None**：对所有元素操作（默认）

**记忆技巧**：
- axis=0：想象数据"竖着看"，对每一列进行操作
- axis=1：想象数据"横着看"，对每一行进行操作

```python
# 创建一个示例数组
data = np.array([
    [10, 20, 30],  # 第一行
    [40, 50, 60]   # 第二行
])

print("原数组：")
print(data)

# axis=None（默认）：对所有元素操作
print(f"\n所有元素的和：{np.sum(data)}")  # 210

# axis=0：沿着行的方向，对每一列求和
print(f"\n每列的和（axis=0）：{np.sum(data, axis=0)}")
# [50 70 90]
# 第一列：10+40=50
# 第二列：20+50=70
# 第三列：30+60=90

# axis=1：沿着列的方向，对每一行求和
print(f"\n每行的和（axis=1）：{np.sum(data, axis=1)}")
# [60 150]
# 第一行：10+20+30=60
# 第二行：40+50+60=150
```

**另一个理解角度**：
```python
# axis指的是"沿着哪个维度折叠"
data = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

# axis=0：把第0维（行）折叠掉，剩下列
print(np.sum(data, axis=0))  # [5 7 9]（2行变成1行）

# axis=1：把第1维（列）折叠掉，剩下行
print(np.sum(data, axis=1))  # [6 15]（3列变成1列）
```

### 三维数组的axis

当数组维度更高时，axis的理解变得更重要。

```python
# 3个班级，5个学生，4次考试成绩
# shape: (3, 5, 4) = (班级, 学生, 考试)
scores_3d = np.random.randint(60, 100, size=(3, 5, 4))

print(f"数组形状：{scores_3d.shape}")  # (3, 5, 4)
print()

# axis=0：对班级求平均（跨班级，得到每个学生每次考试的平均）
avg_axis0 = np.mean(scores_3d, axis=0)
print(f"axis=0结果形状：{avg_axis0.shape}")  # (5, 4)
# 3个班级的平均 -> 剩下5个学生，4次考试

# axis=1：对学生求平均（班级内，每次考试的平均分）
avg_axis1 = np.mean(scores_3d, axis=1)
print(f"axis=1结果形状：{avg_axis1.shape}")  # (3, 4)
# 5个学生的平均 -> 剩下3个班级，4次考试

# axis=2：对考试求平均（每个学生的4次考试平均）
avg_axis2 = np.mean(scores_3d, axis=2)
print(f"axis=2结果形状：{avg_axis2.shape}")  # (3, 5)
# 4次考试的平均 -> 剩下3个班级，5个学生

# 多个axis：同时对多个维度操作
avg_axis_01 = np.mean(scores_3d, axis=(0, 1))
print(f"axis=(0,1)结果形状：{avg_axis_01.shape}")  # (4,)
# 对班级和学生求平均 -> 只剩4次考试
```

**记住**：axis指定的维度会被"折叠"掉，其他维度保留。

## 处理NaN值

真实数据中经常有缺失值（NaN），NumPy提供了专门的函数来处理。

---

### 什么是NaN？

NaN（Not a Number）表示缺失或无效的数据。

```python
# 创建包含NaN的数组
data = np.array([10, 20, np.nan, 30, 40, np.nan, 50])

print(data)  # [10. 20. nan 30. 40. nan 50.]

# NaN有特殊性质
print(np.nan == np.nan)  # False（NaN不等于自己）
print(np.isnan(np.nan))  # True（判断NaN要用isnan）

# 检查数组中的NaN
print(np.isnan(data))  # [False False True False False True False]

# 统计NaN个数
nan_count = np.sum(np.isnan(data))
print(f"NaN个数：{nan_count}")  # 2
```

---

### 普通函数遇到NaN

普通的统计函数遇到NaN会返回NaN。

```python
# 包含NaN的数据
data = np.array([10, 20, np.nan, 30, 40])

# 普通函数返回NaN
print(np.sum(data))   # nan
print(np.mean(data))  # nan
print(np.max(data))   # nan
print(np.std(data))   # nan

# 一个NaN，整个结果都是NaN
```

---

### nan系列函数

NumPy提供了忽略NaN的版本。

```python
# 包含NaN的数据
data = np.array([10, 20, np.nan, 30, 40])

# nan系列函数忽略NaN
print(np.nansum(data))   # 100.0（忽略NaN求和）
print(np.nanmean(data))  # 25.0（忽略NaN求平均）
print(np.nanmax(data))   # 40.0
print(np.nanmin(data))   # 10.0
print(np.nanstd(data))   # 11.18...
print(np.nanvar(data))   # 125.0
```

**完整的nan系列函数**：
- `np.nansum()`：忽略NaN的求和
- `np.nanmean()`：忽略NaN的平均值
- `np.nanmedian()`：忽略NaN的中位数
- `np.nanstd()`：忽略NaN的标准差
- `np.nanvar()`：忽略NaN的方差
- `np.nanmin()`：忽略NaN的最小值
- `np.nanmax()`：忽略NaN的最大值
- `np.nanargmin()`：忽略NaN的最小值索引
- `np.nanargmax()`：忽略NaN的最大值索引
- `np.nanpercentile()`：忽略NaN的百分位数
- `np.nanquantile()`：忽略NaN的分位数

---

### 实际应用 - 处理缺失的成绩数据

```python
# 学生成绩（有缺考的情况）
scores = np.array([
    [85, 92, np.nan],  # 学生1，第三次缺考

# 学生3：90.3分
# 学生4：86.5分

print("每次考试的平均分（忽略缺考）：")

    print(f"第{i}次：{avg:.1f}分")

# 统计缺考情况
```

### 填充NaN值

有时我们需要把NaN替换成某个值。

```python
# 包含NaN的数据
data = np.array([10, 20, np.nan, 30, np.nan, 40])

# 方法1：用0填充
filled_with_0 = np.nan_to_num(data, nan=0)
print("用0填充：", filled_with_0)  # [10. 20.  0. 30.  0. 40.]

# 方法2：用平均值填充
mean_value = np.nanmean(data)
filled_with_mean = np.where(np.isnan(data), mean_value, data)
print("用平均值填充：", filled_with_mean)
# [10. 20. 25. 30. 25. 40.]

# 方法3：用前一个值填充（前向填充）
def forward_fill(arr):
    result = arr.copy()
    for i in range(1, len(result)):
        if np.isnan(result[i]):
            result[i] = result[i-1]
    return result

data2 = np.array([10, 20, np.nan, np.nan, 30, np.nan])
filled_forward = forward_fill(data2)
print("前向填充：", filled_forward)  # [10. 20. 20. 20. 30. 30.]
```

```python
print("【收益统计】")

print(f"总收益率：{total_return:+.2f}%")

daily_returns = np.diff(prices) / prices[:-1] * 100

print(f"年化波动率：{annual_volatility:.2f}%")

drawdown = (prices - cummax) / cummax * 100
max_drawdown = np.min(drawdown)
print(f"最大回撤：{max_drawdown:.2f}%")
print()

# 4. 收益分布
print("【收益分布】")
positive_days = np.sum(daily_returns > 0)
negative_days = np.sum(daily_returns < 0)
win_rate = positive_days / len(daily_returns) * 100

print(f"上涨天数：{positive_days}天")
print(f"下跌天数：{negative_days}天")

print(f"50%：{p50:+.2f}%")
print(f"75%：{p75:+.2f}%")
print(f"90%：{p90:+.2f}%")
```

## 常见陷阱和注意事项

统计分析中有一些常见的陷阱，了解它们可以避免错误。

---

### 陷阱1：axis参数搞反

这是最常见的错误！

```python
data = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

# 想求每行的和，但用错了axis
wrong = np.sum(data, axis=0)  # [50 70 90]，这是每列的和！
correct = np.sum(data, axis=1)  # [60 150]，这才是每行的和

# 记住：axis=0是"沿着行"，对列操作
#       axis=1是"沿着列"，对行操作
```

---

### 陷阱2：忘记处理NaN

```python
data = np.array([10, 20, np.nan, 30, 40])

# 错误：用普通函数，结果全是NaN
wrong = np.mean(data)  # nan

# 正确：用nan系列函数
correct = np.nanmean(data)  # 25.0

# 记住：有NaN的数据一定要用nan系列函数
```

---

### 陷阱3：样本标准差 vs 总体标准差

```python
data = np.array([10, 12, 15, 18, 20])

# 总体标准差（除以n）
population_std = np.std(data)  # 3.416...

# 样本标准差（除以n-1）
sample_std = np.std(data, ddof=1)  # 3.807...

# 在统计学中，通常用样本标准差（ddof=1）
# 在机器学习中，通常用总体标准差（ddof=0）
```

---

### 陷阱4：被平均值误导

```python
# 工资数据
salaries = np.array([5000, 5500, 6000, 6500, 7000, 50000])

# 平均工资（被高薪拉高）
mean_salary = np.mean(salaries)  # 13333元
print(f"平均工资：{mean_salary:.0f}元")  # 不能真实反映大多数人

# 中位数工资（更真实）
median_salary = np.median(salaries)  # 6250元
print(f"中位数工资：{median_salary:.0f}元")  # 更能反映中间水平

# 记住：有极端值时，中位数比平均值更可靠
```

---

### 陷阱5：相关性不等于因果性

```python
# 冰淇淋销量和溺水人数
ice_cream = np.array([10, 20, 30, 40, 50])
drowning = np.array([2, 4, 6, 8, 10])

# 计算相关系数
correlation = np.corrcoef(ice_cream, drowning)[0, 1]
print(f"相关系数：{correlation:.3f}")  # 1.000（完全正相关）

# 错误理解：吃冰淇淋导致溺水？
# 正确理解：都是因为天气热（第三个变量）

# 记住：相关性不代表因果关系！
```

## 性能优化技巧

处理大数据时，性能很重要。

```python
# 1. 避免循环，用向量化
import time

data = np.random.rand(1000000)

# 慢：用循环
start = time.time()
result1 = 0
for x in data:
    result1 += x
time1 = time.time() - start

# 快：用NumPy函数
start = time.time()
result2 = np.sum(data)
time2 = time.time() - start

print(f"循环耗时：{time1:.4f}秒")
print(f"NumPy耗时：{time2:.4f}秒")
print(f"加速比：{time1/time2:.1f}倍")

# 2. 指定axis比多次调用快
data = np.random.rand(1000, 1000)

# 慢：多次调用
start = time.time()
means = [np.mean(row) for row in data]
time1 = time.time() - start

# 快：一次调用，指定axis
start = time.time()
means = np.mean(data, axis=1)
time2 = time.time() - start

print(f"多次调用：{time1:.4f}秒")
print(f"指定axis：{time2:.4f}秒")

# 3. 对于大数组，考虑使用dtype=float32而不是float64
data_f64 = np.random.rand(10000000)  # float64
data_f32 = data_f64.astype(np.float32)  # float32

print(f"float64内存：{data_f64.nbytes / 1024 / 1024:.1f}MB")
print(f"float32内存：{data_f32.nbytes / 1024 / 1024:.1f}MB")
# float32节省一半内存，计算也更快（精度略有损失）
```

## 本章重点总结

学完这一章，你应该掌握：

### 基本统计函数
- **平均值**：`np.mean()` - 数据集中趋势
- **中位数**：`np.median()` - 不受极端值影响的中心
- **标准差**：`np.std()` - 数据波动程度
- **方差**：`np.var()` - 标准差的平方

### 最值函数
- **最大最小**：`np.max()`, `np.min()`
- **位置索引**：`np.argmax()`, `np.argmin()`

### 求和函数
- **基本求和**：`np.sum()` - 累加所有元素
- **累积求和**：`np.cumsum()` - 记录累加过程
- **处理NaN**：`np.nansum()` - 忽略缺失值

### 分位数
- **百分位数**：`np.percentile()` - 参数0-100
- **分位数**：`np.quantile()` - 参数0-1
- **四分位数**：25%, 50%, 75%

### 相关性分析
- **相关系数**：`np.corrcoef()` - 范围[-1, 1]
- **协方差**：`np.cov()` - 衡量变化关系

### 直方图统计
- **histogram**：统计分布
- **bincount**：统计整数频次

### axis参数
- **axis=0**：沿第0维（通常是"按列"）
- **axis=1**：沿第1维（通常是"按行"）
- **axis=None**：所有元素（默认）

### NaN值处理
- **nan系列函数**：`nanmean`, `nanstd`, `nansum`等
- **检测NaN**：`np.isnan()`
- **填充NaN**：`np.nan_to_num()`, `np.where()`

### 重要概念
- **平均值 vs 中位数**：有极端值时用中位数
- **标准差 vs 方差**：标准差更直观
- **样本 vs 总体**：ddof参数的选择
- **相关性 ≠ 因果性**：不要混淆

### 实用技巧
- 有缺失值一定用nan系列函数
- 理解axis的含义很重要
- 向量化操作比循环快得多
- 选择合适的统计指标（平均值、中位数等）
