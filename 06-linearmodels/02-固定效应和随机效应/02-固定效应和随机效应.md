# 第02章：固定效应和随机效应

固定效应（Fixed Effects）和随机效应（Random Effects）是面板数据分析的核心！这一章我们深入理解两者的区别、如何选择，以及Hausman检验。

## 固定效应 vs 随机效应

### 从直觉理解

```python
print("=" * 70)
print("固定效应 vs 随机效应：直觉理解")
print("=" * 70)

直觉对比 = """
【场景：分析学生成绩】

数据：100个学生，5次考试成绩
目标：研究"学习时间"对"成绩"的影响

问题：学生有不同的"天赋"（不可观测）

【固定效应（Fixed Effects, FE）】

思路：给每个学生一个"专属基准线"

模型：
score_it = α_i + β × study_hours_it + ε_it
           ↑
     每个学生有自己的α_i

比喻：
- 每个学生有不同的"起跑线"
- 我们比较的是：每个学生"相对自己"的进步
- "学生A从80分提高到85分" vs "学生B从60分提高到65分"

优点：
✅ 控制所有时间不变的个体特征（天赋、家庭背景）
✅ 不需要假设这些特征与学习时间无关
✅ 因果推断的黄金标准

缺点：
❌ 不能估计时间不变的变量（如性别、出生地）
❌ 参数多（N个学生 = N个α_i）
❌ 需要每个个体有多期观测

【随机效应（Random Effects, RE）】

思路：假设个体差异是"随机抽取"的

模型：
score_it = α + β × study_hours_it + (μ_i + ε_it)
                                      ↑
                            随机抽取的个体效应

比喻：
- 学生是从总体中随机抽取的
- 个体差异μ_i是随机变量
- 就像抽奖，每个人抽到不同的"天赋值"

优点：
✅ 可以估计时间不变的变量
✅ 参数少，估计更有效率
✅ 可以预测新个体

缺点：
❌ 需要强假设：μ_i与自变量无关
❌ 如果假设不成立 → 估计有偏
❌ 通常不如固定效应可信

【关键区别】

固定效应：
- 个体差异 = 待估计的参数
- N个学生 → N个参数
- 不做任何分布假设

随机效应：
- 个体差异 = 随机变量
- 假设 μ_i ~ N(0, σ_μ²)
- 只估计一个方差 σ_μ²

【何时用哪个？】

用固定效应（推荐）：
✅ 样本 = 关注的全部个体（如50个州、G7国家）
✅ 担心内生性问题
✅ 想做因果推断
✅ 有足够的时间变化

用随机效应：
✅ 样本 = 从总体随机抽取（如1000个居民）
✅ 需要估计时间不变的变量
✅ 确信个体差异与自变量无关
✅ 个体数量非常大（固定效应参数太多）

【经验法则】

"如有疑问，用固定效应"
— 经济计量学家的经验法则
"""

print(直觉对比)
```

## 案例1：工人工资分析（FE vs RE对比）

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from linearmodels import PanelOLS, RandomEffects
from linearmodels.panel import compare
import warnings
warnings.filterwarnings('ignore')

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

print("\n" + "=" * 70)
print("案例1：工人工资分析 - FE vs RE")
print("=" * 70)

print("""
场景：
分析400名工人的工资，跟踪6年（2017-2022）。

变量：
- log_wage: 对数工资（因变量）
- exper: 工作经验（年）
- union: 是否加入工会（0或1）
- married: 是否已婚（0或1）
- educ: 教育年限（时间不变）
- ability: 能力（不可观测，时间不变）

问题：
1. 固定效应和随机效应的估计有何不同？
2. 如何选择模型？
""")

# ===== 1. 生成数据 =====
np.random.seed(789)
n_workers = 400
n_years = 6
years = range(2017, 2023)

data_list = []
for worker_id in range(1, n_workers + 1):
    # 时间不变的特征
    educ = np.random.normal(12, 2).clip(8, 18)
    ability = np.random.normal(0, 1)  # 能力（不可观测！）

    # 个体固定效应 = 教育 + 能力
    individual_effect = 0.08 * educ + 0.15 * ability

    for t, year in enumerate(years):
        exper = 5 + t + np.random.normal(0, 0.5)
        exper = max(0, exper)
        union = np.random.binomial(1, 0.3 + 0.01 * educ)
        married = np.random.binomial(1, 0.4 + 0.08 * t / n_years)

        # 工资模型
        # 关键：ability和educ都在个体效应中，且与exper、union相关
        log_wage = (
            1.5 +
            0.05 * exper +
            0.10 * union +
            0.08 * married +
            individual_effect +  # 包含educ和ability
            0.02 * t +
            np.random.normal(0, 0.15)
        )

        data_list.append({
            'worker_id': worker_id,
            'year': year,
            'log_wage': log_wage,
            'exper': exper,
            'union': union,
            'married': married,
            'educ': educ,
            'ability': ability  # 现实中不可观测
        })

df_wage = pd.DataFrame(data_list)
df_wage = df_wage.set_index(['worker_id', 'year'])

print(f"\n数据概览：")
print(df_wage.head(10))

print(f"\n数据维度：")
print(f"  工人数量: {n_workers}")
print(f"  时间跨度: {n_years} 年")
print(f"  总观测值: {len(df_wage)}")

# ===== 2. 混合OLS（基准）=====
from linearmodels import PooledOLS

print("\n" + "=" * 70)
print("模型1：混合OLS（基准模型）")
print("=" * 70)

pooled = PooledOLS.from_formula(
    'log_wage ~ exper + union + married + educ',
    data=df_wage
)
pooled_result = pooled.fit(cov_type='clustered', cluster_entity=True)

print(pooled_result.summary.tables[1])

print("\n问题：")
print("  ⚠️ 忽略了个体固定效应（ability）")
print("  ⚠️ ability与educ、union相关 → 估计有偏")

# ===== 3. 固定效应模型 =====
print("\n" + "=" * 70)
print("模型2：固定效应（Fixed Effects）")
print("=" * 70)

fe = PanelOLS.from_formula(
    'log_wage ~ exper + union + married + EntityEffects',
    data=df_wage
)
fe_result = fe.fit(cov_type='clustered', cluster_entity=True)

print(fe_result.summary.tables[1])

print("\n关键发现：")
print(f"  1. 教育（educ）消失了！")
print(f"     原因：时间不变，被个体固定效应吸收")
print(f"\n  2. 经验系数：{fe_result.params['exper']:.4f}")
print(f"     解释：经验每增加1年，工资提高{fe_result.params['exper']*100:.2f}%")
print(f"\n  3. 工会系数：{fe_result.params['union']:.4f}")
print(f"     解释：加入工会使工资提高{fe_result.params['union']*100:.2f}%")

# ===== 4. 随机效应模型 =====
print("\n" + "=" * 70)
print("模型3：随机效应（Random Effects）")
print("=" * 70)

re = RandomEffects.from_formula(
    'log_wage ~ exper + union + married + educ',
    data=df_wage
)
re_result = re.fit(cov_type='clustered', cluster_entity=True)

print(re_result.summary.tables[1])

print("\n关键发现：")
print(f"  1. 可以估计教育！")
print(f"     教育系数：{re_result.params['educ']:.4f}")
print(f"     解释：教育每增加1年，工资提高{re_result.params['educ']*100:.2f}%")
print(f"\n  2. 其他系数与固定效应不同")
print(f"     原因：随机效应做了不同的假设")

# ===== 5. 模型比较 =====
print("\n" + "=" * 70)
print("三个模型的系数对比")
print("=" * 70)

comparison = pd.DataFrame({
    '真实值': [0.05, 0.10, 0.08, 0.08],
    '混合OLS': [
        pooled_result.params['exper'],
        pooled_result.params['union'],
        pooled_result.params['married'],
        pooled_result.params['educ']
    ],
    '固定效应': [
        fe_result.params['exper'],
        fe_result.params['union'],
        fe_result.params['married'],
        np.nan  # 无法估计
    ],
    '随机效应': [
        re_result.params['exper'],
        re_result.params['union'],
        re_result.params['married'],
        re_result.params['educ']
    ]
}, index=['exper', 'union', 'married', 'educ'])

print("\n")
print(comparison.round(4))

print("\n解读：")
print("  - 混合OLS：所有系数都有偏（因为忽略了ability）")
print("  - 固定效应：exper、union、married更接近真实值")
print("  - 随机效应：介于混合OLS和固定效应之间")
print("  - 固定效应无法估计educ（时间不变）")

# ===== 6. Hausman检验 =====
print("\n" + "=" * 70)
print("Hausman检验：FE vs RE")
print("=" * 70)

print("""
Hausman检验：
- H0: 随机效应模型是一致的（个体效应与自变量无关）
- H1: 只有固定效应是一致的（个体效应与自变量相关）

决策规则：
- p < 0.05: 拒绝H0，用固定效应 ✅
- p ≥ 0.05: 不拒绝H0，可用随机效应

原理：
比较FE和RE的系数差异
- 如果差异显著 → 个体效应与自变量相关 → 用FE
- 如果差异不显著 → 可以用RE（更有效率）
""")

# 手动实现Hausman检验
fe_params = fe_result.params[['exper', 'union', 'married']]
re_params = re_result.params[['exper', 'union', 'married']]

fe_cov = fe_result.cov[['exper', 'union', 'married']].loc[['exper', 'union', 'married']]
re_cov = re_result.cov[['exper', 'union', 'married']].loc[['exper', 'union', 'married']]

diff = fe_params - re_params
cov_diff = fe_cov - re_cov

# Hausman统计量
try:
    hausman_stat = diff.T @ np.linalg.inv(cov_diff) @ diff
    from scipy import stats
    p_value = 1 - stats.chi2.cdf(hausman_stat, df=len(diff))

    print(f"\nHausman检验结果：")
    print(f"  检验统计量: {hausman_stat:.4f}")
    print(f"  自由度: {len(diff)}")
    print(f"  p值: {p_value:.4f}")

    if p_value < 0.05:
        print(f"\n✅ 结论：拒绝H0（p={p_value:.4f} < 0.05）")
        print(f"   个体效应与自变量相关")
        print(f"   → 应该使用固定效应模型")
    else:
        print(f"\n⚠️ 结论：不拒绝H0（p={p_value:.4f} ≥ 0.05）")
        print(f"   没有足够证据表明个体效应与自变量相关")
        print(f"   → 可以使用随机效应模型（更有效率）")
except:
    print("\n⚠️ 无法计算Hausman统计量（协方差矩阵奇异）")

# ===== 7. 可视化 =====
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 7.1 系数对比
variables = ['exper', 'union', 'married']
x_pos = np.arange(len(variables))
width = 0.25

true_vals = [0.05, 0.10, 0.08]
pooled_vals = [pooled_result.params[v] for v in variables]
fe_vals = [fe_result.params[v] for v in variables]
re_vals = [re_result.params[v] for v in variables]

axes[0, 0].bar(x_pos - 1.5*width, true_vals, width, label='真实值', color='green', alpha=0.7)
axes[0, 0].bar(x_pos - 0.5*width, pooled_vals, width, label='混合OLS', color='orange', alpha=0.7)
axes[0, 0].bar(x_pos + 0.5*width, fe_vals, width, label='固定效应', color='steelblue', alpha=0.7)
axes[0, 0].bar(x_pos + 1.5*width, re_vals, width, label='随机效应', color='purple', alpha=0.7)

axes[0, 0].set_xticks(x_pos)
axes[0, 0].set_xticklabels(variables)
axes[0, 0].set_ylabel('系数估计', fontsize=11)
axes[0, 0].set_title('三个模型的系数对比', fontsize=13, fontweight='bold')
axes[0, 0].legend(fontsize=9)
axes[0, 0].grid(axis='y', alpha=0.3)

# 7.2 教育分布
df_reset = df_wage.reset_index()
unique_educ = df_reset.groupby('worker_id')['educ'].first()
axes[0, 1].hist(unique_educ, bins=20, color='coral', alpha=0.7, edgecolor='black')
axes[0, 1].set_xlabel('教育年限', fontsize=11)
axes[0, 1].set_ylabel('工人数量', fontsize=11)
axes[0, 1].set_title('教育年限分布', fontsize=13, fontweight='bold')
axes[0, 1].grid(axis='y', alpha=0.3)

# 7.3 工资增长轨迹（前20个工人）
for worker in range(1, 21):
    worker_data = df_reset[df_reset['worker_id'] == worker]
    axes[1, 0].plot(worker_data['year'], worker_data['log_wage'], alpha=0.5, linewidth=1)

axes[1, 0].set_xlabel('年份', fontsize=11)
axes[1, 0].set_ylabel('对数工资', fontsize=11)
axes[1, 0].set_title('工资轨迹（前20名工人）', fontsize=13, fontweight='bold')
axes[1, 0].grid(True, alpha=0.3)

# 7.4 FE vs RE系数差异
fe_re_diff = fe_params - re_params
axes[1, 1].bar(variables, fe_re_diff, color=['steelblue', 'coral', 'green'], alpha=0.7)
axes[1, 1].axhline(y=0, color='red', linestyle='--')
axes[1, 1].set_ylabel('系数差异 (FE - RE)', fontsize=11)
axes[1, 1].set_title('固定效应 vs 随机效应：系数差异', fontsize=13, fontweight='bold')
axes[1, 1].grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.savefig('02-固定效应和随机效应-01-FE-vs-RE.png', dpi=300, bbox_inches='tight')
plt.show()

print("\n" + "=" * 70)
print("案例1 完成！")
print("=" * 70)
```

## 固定效应的数学原理

```python
print("\n" + "=" * 70)
print("固定效应的数学原理：within变换")
print("=" * 70)

数学原理 = """
【固定效应模型】

原始模型：
y_it = α_i + β'X_it + ε_it

其中：
- α_i: 个体固定效应
- i = 1, ..., N（个体）
- t = 1, ..., T（时间）

【Within变换（组内变换）】

步骤1：对每个个体，计算时间均值
ȳ_i = (1/T) Σ_t y_it
X̄_i = (1/T) Σ_t X_it

步骤2：原始值减去时间均值
ỹ_it = y_it - ȳ_i
X̃_it = X_it - X̄_i

步骤3：对变换后的数据做OLS
ỹ_it = β'X̃_it + ε̃_it

结果：
✅ α_i被消除（因为α_i - ᾱ_i = 0）
✅ β的估计是一致的
✅ 只利用"个体内部的时间变化"

【直觉理解】

固定效应 = 只看每个个体"相对自己"的变化

例子：
学生A: 考试1=80分, 考试2=85分, 考试3=90分
- 均值 = 85分
- 去均值化 = [-5, 0, +5]
- 只看"相对自己均值"的变化

好处：
- 消除了个体间的"水平差异"
- 专注个体内部的"变化"
- 控制所有时间不变的特征

【为什么时间不变的变量被吸收？】

如果 X_it = X_i（时间不变）

则：X̃_it = X_i - X̄_i = X_i - X_i = 0

所以：
✅ 时间不变的变量在within变换后全为0
✅ 无法估计其系数
✅ 这不是bug，是feature！控制了所有时间不变的混杂因素
"""

print(数学原理)

# ===== 演示within变换 =====
print("\n" + "=" * 70)
print("演示：within变换的实际操作")
print("=" * 70)

# 使用简化数据演示
demo_data = pd.DataFrame({
    'worker': [1, 1, 1, 2, 2, 2],
    'time': [1, 2, 3, 1, 2, 3],
    'wage': [10, 12, 14, 8, 9, 10],
    'exper': [1, 2, 3, 1, 2, 3],
    'educ': [12, 12, 12, 10, 10, 10]  # 时间不变
})

print("\n原始数据：")
print(demo_data)

# 计算时间均值
demo_data['wage_mean'] = demo_data.groupby('worker')['wage'].transform('mean')
demo_data['exper_mean'] = demo_data.groupby('worker')['exper'].transform('mean')
demo_data['educ_mean'] = demo_data.groupby('worker')['educ'].transform('mean')

# within变换
demo_data['wage_demean'] = demo_data['wage'] - demo_data['wage_mean']
demo_data['exper_demean'] = demo_data['exper'] - demo_data['exper_mean']
demo_data['educ_demean'] = demo_data['educ'] - demo_data['educ_mean']

print("\nwithin变换后：")
print(demo_data[['worker', 'time', 'wage_demean', 'exper_demean', 'educ_demean']])

print("\n观察：")
print("  ✅ wage和exper去均值化后有变化")
print("  ✅ educ去均值化后全为0（因为时间不变）")
print("  ✅ 这就是为什么固定效应不能估计教育系数！")
```

## 案例2：企业出口决策（200企业×8年）

```python
print("\n" + "=" * 70)
print("案例2：企业出口决策 - 双向固定效应")
print("=" * 70)

print("""
场景：
分析200家企业的出口决策，2015-2022年（8年）。

变量：
- export: 是否出口（因变量，0或1）
- log_size: 对数企业规模
- rd_ratio: 研发强度
- fdi_policy: 外商直接投资政策（0或1）
- exchange_rate: 汇率指数

问题：
1. 企业规模如何影响出口？
2. FDI政策有效吗？
3. 时间固定效应重要吗？
""")

# ===== 1. 生成数据 =====
np.random.seed(101112)
n_firms_export = 200
years_export = range(2015, 2023)
n_years_export = len(years_export)

data_list_export = []
for firm_id in range(1, n_firms_export + 1):
    firm_effect = np.random.normal(0, 0.5)
    base_size = np.random.uniform(3, 7)

    for t, year in enumerate(years_export):
        log_size = base_size + 0.05 * t + np.random.normal(0, 0.2)
        rd_ratio = np.random.beta(2, 8)
        fdi_policy = 1 if year >= 2019 else 0
        exchange_rate = 100 + 2 * t + np.random.normal(0, 5)

        # Logit模型（但我们用线性概率模型近似）
        export_prob = (
            0.2 +
            0.08 * log_size +
            0.15 * rd_ratio +
            0.10 * fdi_policy +
            0.001 * exchange_rate +
            firm_effect +
            0.05 * (t - n_years_export/2)  # 时间趋势
        )
        export_prob = np.clip(export_prob, 0, 1)
        export = int(np.random.rand() < export_prob)

        data_list_export.append({
            'firm_id': firm_id,
            'year': year,
            'export': export,
            'log_size': log_size,
            'rd_ratio': rd_ratio,
            'fdi_policy': fdi_policy,
            'exchange_rate': exchange_rate
        })

df_export = pd.DataFrame(data_list_export)
df_export = df_export.set_index(['firm_id', 'year'])

print(f"\n数据概览：")
print(df_export.head(10))

print(f"\n出口企业比例：")
export_rate_by_year = df_export.reset_index().groupby('year')['export'].mean()
for year, rate in export_rate_by_year.items():
    print(f"  {year}: {rate*100:.1f}%")

# ===== 2. 单向固定效应（仅个体）=====
print("\n" + "=" * 70)
print("模型1：单向固定效应（仅EntityEffects）")
print("=" * 70)

fe_oneway = PanelOLS.from_formula(
    'export ~ log_size + rd_ratio + fdi_policy + exchange_rate + EntityEffects',
    data=df_export
)
fe_oneway_result = fe_oneway.fit(cov_type='clustered', cluster_entity=True)

print(fe_oneway_result.summary.tables[1])

# ===== 3. 双向固定效应（个体 + 时间）=====
print("\n" + "=" * 70)
print("模型2：双向固定效应（EntityEffects + TimeEffects）")
print("=" * 70)

fe_twoway = PanelOLS.from_formula(
    'export ~ log_size + rd_ratio + fdi_policy + exchange_rate + EntityEffects + TimeEffects',
    data=df_export
)
fe_twoway_result = fe_twoway.fit(cov_type='clustered', cluster_entity=True)

print(fe_twoway_result.summary.tables[1])

print("\n关键差异：")
print(f"  FDI政策系数（单向FE）: {fe_oneway_result.params['fdi_policy']:.4f}")
```

## 聚类标准误（Clustered Standard Errors）

```python
print("\n" + "=" * 70)
print("聚类标准误的重要性")
print("=" * 70)

聚类标准误 = """
【为什么需要聚类标准误？】

问题：面板数据违反OLS假设
- 同一个体的观测可能相关（序列相关）
- 例如：学生A的2020年和2021年成绩可能相关
- 标准OLS标准误会过小 → t统计量过大 → 假显著

解决：聚类标准误（Clustered Standard Errors）
- 允许同一聚类内的观测相关
- 跨聚类的观测仍然独立
- 稳健地估计标准误

【三种聚类方式】

1. 按个体聚类（Entity Clustering）
   cov_type='clustered', cluster_entity=True

   - 允许同一个体、不同时间的观测相关
   - 最常用！
   - 例如：学生A的多次考试成绩相关

2. 按时间聚类（Time Clustering）
   cov_type='clustered', cluster_time=True

   - 允许不同个体、同一时间的观测相关
   - 用于存在"时间冲击"的情况
   - 例如：所有企业在2020年都受疫情影响

3. 双向聚类（Two-Way Clustering）
   cov_type='clustered', cluster_entity=True, cluster_time=True

   - 同时允许个体内和时间内相关
   - 最保守（标准误最大）
   - 推荐：当不确定时使用

【经验法则】

✅ 永远使用聚类标准误（至少按个体聚类）
✅ 默认选择：cluster_entity=True
✅ 如有时间冲击（如政策、危机）：考虑双向聚类
✅ 个体数<50：聚类标准误可能不准，考虑bootstrap
"""

print(聚类标准误)

# ===== 演示不同标准误的差异 =====
print("\n" + "=" * 70)
print("演示：不同标准误的对比")
print("=" * 70)

# 使用案例1的数据
print("\n使用工资数据，比较不同标准误：")

# 同质标准误（错误！）
fe_homo = PanelOLS.from_formula(
    'log_wage ~ exper + union + married + EntityEffects',
    data=df_wage
)
result_homo = fe_homo.fit(cov_type='unadjusted')

# 稳健标准误（仍不够）
result_robust = fe_homo.fit(cov_type='robust')

# 按个体聚类（推荐）
result_cluster_entity = fe_homo.fit(cov_type='clustered', cluster_entity=True)

# 双向聚类（最保守）
result_cluster_twoway = fe_homo.fit(cov_type='clustered',
                                     cluster_entity=True, cluster_time=True)

# 比较标准误
comparison_se = pd.DataFrame({
    '同质SE': result_homo.std_errors[['exper', 'union', 'married']],
    '稳健SE': result_robust.std_errors[['exper', 'union', 'married']],
    '个体聚类SE': result_cluster_entity.std_errors[['exper', 'union', 'married']],
    '双向聚类SE': result_cluster_twoway.std_errors[['exper', 'union', 'married']]
})

print("\n标准误对比：")
print(comparison_se.round(4))

print("\n关键观察：")
print("  - 同质SE最小（错误！低估了不确定性）")
print("  - 个体聚类SE更大（正确考虑了序列相关）")
print("  - 双向聚类SE最大（最保守）")
print("  - 教训：必须使用聚类标准误，否则t统计量过大！")
```

## 模型选择总结

```python
print("\n" + "=" * 70)
print("固定效应 vs 随机效应：选择指南")
print("=" * 70)

选择指南 = """
【决策树】

问题1：样本是全部个体还是随机抽取？
├─ 全部个体（如50个州、G7国家） → 固定效应
└─ 随机抽取（如1000个居民） → 可能随机效应

问题2：个体效应可能与自变量相关吗？
├─ 可能相关（通常是！） → 固定效应
└─ 确信无关 → 可能随机效应

问题3：需要估计时间不变的变量吗？
├─ 是（如性别、种族） → 随机效应或其他方法
└─ 否 → 固定效应

问题4：Hausman检验结果？
├─ p < 0.05 → 固定效应
└─ p ≥ 0.05 → 随机效应

【经验法则】

✅ 默认选择：固定效应 + 双向固定效应
✅ 标准误：至少按个体聚类
✅ 有政策分析：必须加时间固定效应
✅ 如有疑问：固定效应更安全

【何时用随机效应？】

✅ 确实是随机抽样
✅ 个体数量非常大（>1000）
✅ Hausman检验不拒绝H0
✅ 必须估计时间不变的变量
✅ 预测新个体

【现代实践】

大多数经济学实证研究使用：
PanelOLS + EntityEffects + TimeEffects + cluster_entity

原因：
- 最稳健的因果推断
- 不需要强假设
- 控制遗漏变量
"""

print(选择指南)
```
