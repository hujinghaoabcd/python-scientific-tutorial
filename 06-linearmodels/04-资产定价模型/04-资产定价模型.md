# 第04章：资产定价模型

资产定价研究的是"为什么某些资产有更高的回报"？LinearModels提供了专门的工具来检验CAPM、Fama-French等经典模型。

## 资产定价基础

### 从生活场景理解

```python
print("=" * 70)
print("资产定价：从生活场景理解")
print("=" * 70)

资产定价直觉 = """
【场景：为什么不同股票收益率不同？】

观察：
- 股票A：年回报10%
- 股票B：年回报15%
- 股票C：年回报20%

问题：
为什么C比A高10%？是C的公司更好吗？

【资产定价的核心问题】

不是问"哪个股票好"，而是问：
"为什么某些股票有风险溢价？"

答案：因为承担了风险！
- 高风险 → 高预期回报（补偿投资者）
- 低风险 → 低预期回报

【风险的度量】

不是单个股票的波动率！
而是：对"系统性风险"的暴露

系统性风险 = 无法分散的风险
- 市场整体下跌
- 经济衰退
- 利率上升

【因子模型的逻辑】

假设：回报率由"风险因子"驱动

R_i = α_i + β₁ × Factor1 + β₂ × Factor2 + ... + ε_i

因子 = 系统性风险来源
- 市场因子（CAPM）
- 规模因子（小公司 vs 大公司）
- 价值因子（价值股 vs 成长股）

β = 对该因子的暴露（factor loading）
- β大 → 对该风险敏感
- β大 → 预期回报高（风险补偿）

α = 异常收益（alpha）
- α = 0: 回报完全被因子解释
- α > 0: 跑赢市场！
- α < 0: 跑输市场
"""

print(资产定价直觉)
```

## CAPM：资本资产定价模型

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from linearmodels.panel import PooledOLS, PanelOLS, FamaMacBeth
from linearmodels.asset_pricing import LinearFactorModel, TradedFactorModel
import warnings
warnings.filterwarnings('ignore')

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

print("\n" + "=" * 70)
print("CAPM：资本资产定价模型")
print("=" * 70)

CAPM解释 = """
【CAPM模型】

R_i - R_f = α_i + β_i × (R_m - R_f) + ε_i

其中：
- R_i: 资产i的回报率
- R_f: 无风险利率
- R_m: 市场组合回报率
- R_i - R_f: 超额回报（excess return）
- R_m - R_f: 市场超额回报（market premium）

【参数解释】

β_i（Beta）：
- 度量资产对市场的敏感度
- β = 1: 与市场同步波动
- β > 1: 比市场更激进（高风险）
- β < 1: 比市场更保守（低风险）
- β < 0: 与市场反向（对冲工具）

α_i（Alpha）：
- 无法被市场因子解释的收益
- α = 0: CAPM成立，风险溢价完全被β解释
- α > 0: 正alpha，跑赢市场！（选股能力）
- α < 0: 负alpha，跑输市场

【CAPM的预测】

如果CAPM成立：
✅ α_i = 0（所有资产）
✅ 预期回报完全由β决定：E[R_i - R_f] = β_i × E[R_m - R_f]

现实：
- CAPM经常被拒绝（很多α≠0）
- 促使发展了多因子模型（Fama-French等）
"""

print(CAPM解释)
```

## 案例1：CAPM检验（100只股票×60个月）

```python
print("\n" + "=" * 70)
print("案例1：CAPM检验")
print("=" * 70)

print("""
场景：
检验CAPM模型，使用100只股票，60个月数据。

变量：
- ret: 股票回报率
- mkt_rf: 市场超额回报（R_m - R_f）

问题：
1. 每只股票的Beta是多少？
2. Alpha显著不为0吗？
3. CAPM能解释多少回报变异？
""")

# ===== 1. 生成数据 =====
np.random.seed(12345)
n_stocks = 100
n_months = 60
dates = pd.date_range('2019-01-31', periods=n_months, freq='ME')

# 市场超额回报（所有股票共同的）
mkt_rf = np.random.normal(0.008, 0.05, n_months)  # 月均0.8%, 波动5%

data_list_capm = []
true_betas = []
true_alphas = []

for stock_id in range(1, n_stocks + 1):
    # 每只股票的真实beta和alpha
    true_beta = np.random.normal(1.0, 0.5).clip(0.2, 2.0)
    true_alpha = np.random.normal(0, 0.003)  # 大部分alpha接近0

    true_betas.append(true_beta)
    true_alphas.append(true_alpha)

    for t, date in enumerate(dates):
        # CAPM模型
        ret = (
            true_alpha +                           # alpha
            true_beta * mkt_rf[t] +               # beta × 市场因子
            np.random.normal(0, 0.03)             # 特质风险
        )

        data_list_capm.append({
            'stock_id': stock_id,
            'date': date,
            'ret': ret,
            'mkt_rf': mkt_rf[t]
        })

df_capm = pd.DataFrame(data_list_capm)

print(f"\n数据概览：")
print(df_capm.head(10))

print(f"\n数据维度：")
print(f"  股票数量: {n_stocks}")
print(f"  时间跨度: {n_months} 个月")
print(f"  总观测值: {len(df_capm)}")

print(f"\n市场回报统计：")
print(pd.Series(mkt_rf).describe())

# ===== 2. 时间序列回归（每只股票单独回归）=====
print("\n" + "=" * 70)
print("方法1：时间序列回归（Time-Series Regression）")
print("=" * 70)

print("""
思路：
对每只股票i，单独跑回归：
R_i,t = α_i + β_i × MKT_t + ε_i,t

得到每只股票的alpha和beta
""")

# 对前5只股票做演示
sample_stocks = [1, 2, 3, 4, 5]
ts_results = []

for stock in sample_stocks:
    stock_data = df_capm[df_capm['stock_id'] == stock].copy()
    stock_data = stock_data.set_index('date')

    # OLS回归
    from statsmodels.formula.api import ols
    model = ols('ret ~ mkt_rf', data=stock_data)
    result = model.fit()

    ts_results.append({
        'stock_id': stock,
        'alpha': result.params['Intercept'],
        'beta': result.params['mkt_rf'],
        'alpha_tstat': result.tvalues['Intercept'],
        'beta_tstat': result.tvalues['mkt_rf'],
        'r_squared': result.rsquared
    })

ts_results_df = pd.DataFrame(ts_results)

print("\n前5只股票的CAPM回归结果：")
print(ts_results_df.round(4))

print("\n解释：")
print("  - beta：股票对市场的敏感度")
print("  - alpha：无法被市场解释的收益")
print("  - R²：市场因子能解释多少股票回报变异")

# ===== 3. 面板回归（所有股票一起）=====
print("\n" + "=" * 70)
print("方法2：面板回归（Panel Regression）")
print("=" * 70)

print("""
思路：
假设所有股票有相同的beta（限制性假设）
R_i,t = α + β × MKT_t + ε_i,t
""")

df_capm_panel = df_capm.set_index(['stock_id', 'date'])

pooled_capm = PooledOLS.from_formula(
    'ret ~ mkt_rf',
    data=df_capm_panel
)
pooled_capm_result = pooled_capm.fit(cov_type='clustered', cluster_entity=True)

print(pooled_capm_result.summary.tables[1])

print(f"\n平均beta: {pooled_capm_result.params['mkt_rf']:.4f}")
print(f"解释：市场上涨1%, 平均股票上涨{pooled_capm_result.params['mkt_rf']:.2%}")

# ===== 4. 固定效应面板回归（允许不同alpha）=====
print("\n" + "=" * 70)
print("方法3：固定效应面板回归")
print("=" * 70)

print("""
思路：
允许每只股票有不同的alpha（EntityEffects）
但假设所有股票有相同的beta

R_i,t = α_i + β × MKT_t + ε_i,t
""")

fe_capm = PanelOLS.from_formula(
    'ret ~ mkt_rf + EntityEffects',
    data=df_capm_panel
)
fe_capm_result = fe_capm.fit(cov_type='clustered', cluster_entity=True)

print(fe_capm_result.summary.tables[1])

# ===== 5. Fama-MacBeth回归（推荐！）=====
print("\n" + "=" * 70)
print("方法4：Fama-MacBeth回归（金融研究标准方法）")
print("=" * 70)

print("""
【Fama-MacBeth两步法】

第一步：时间序列回归
- 对每只股票i，回归：R_i,t = α_i + β_i × MKT_t + ε_i,t
- 得到每只股票的beta估计：β̂_i

第二步：横截面回归（每个时期t）
- 回归：R_i,t = λ₀,t + λ₁,t × β̂_i + η_i,t
- 得到每个时期的风险价格：λ₁,t

最终：
- 对所有时期的λ₁,t求平均：λ̄₁
- λ̄₁ = 市场风险的价格
- 如果CAPM成立：λ̄₁ = E[R_m - R_f]

优点：
✅ 考虑横截面和时间序列信息
✅ 允许每只股票不同的beta
✅ 自动调整标准误（Shanken修正）
✅ 金融研究的标准方法

LinearModels自动完成两步：
fm = FamaMacBeth.from_formula('ret ~ mkt_rf', data)
""")

fm_capm = FamaMacBeth.from_formula(
    'ret ~ mkt_rf',
    data=df_capm_panel
)
fm_capm_result = fm_capm.fit()

print("\n" + "="*70)
print(fm_capm_result.summary)

print(f"\n市场风险价格（λ_mkt）: {fm_capm_result.params['mkt_rf']:.6f}")
print(f"解释：beta增加1，月回报增加{fm_capm_result.params['mkt_rf']:.4%}")

# ===== 6. 可视化 =====
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 6.1 市场回报时间序列
axes[0, 0].plot(dates, mkt_rf, linewidth=2, color='steelblue')
axes[0, 0].axhline(y=0, color='red', linestyle='--', alpha=0.5)
axes[0, 0].set_xlabel('日期', fontsize=11)
axes[0, 0].set_ylabel('市场超额回报', fontsize=11)
axes[0, 0].set_title('市场超额回报时间序列', fontsize=13, fontweight='bold')
axes[0, 0].grid(True, alpha=0.3)

# 6.2 Beta分布
axes[0, 1].hist(ts_results_df['beta'], bins=15, color='coral', alpha=0.7, edgecolor='black')
axes[0, 1].axvline(x=1.0, color='red', linestyle='--', label='Beta=1')
axes[0, 1].set_xlabel('Beta', fontsize=11)
axes[0, 1].set_ylabel('股票数量', fontsize=11)
axes[0, 1].set_title('Beta分布（前5只股票）', fontsize=13, fontweight='bold')
axes[0, 1].legend()
axes[0, 1].grid(axis='y', alpha=0.3)

# 6.3 Alpha分布
axes[1, 0].hist(ts_results_df['alpha'], bins=15, color='green', alpha=0.7, edgecolor='black')
axes[1, 0].axvline(x=0, color='red', linestyle='--', label='Alpha=0')
axes[1, 0].set_xlabel('Alpha', fontsize=11)
axes[1, 0].set_ylabel('股票数量', fontsize=11)
axes[1, 0].set_title('Alpha分布（前5只股票）', fontsize=13, fontweight='bold')
axes[1, 0].legend()
axes[1, 0].grid(axis='y', alpha=0.3)

# 6.4 R²分布
axes[1, 1].hist(ts_results_df['r_squared'], bins=15, color='purple', alpha=0.7, edgecolor='black')
axes[1, 1].set_xlabel('R²', fontsize=11)
axes[1, 1].set_ylabel('股票数量', fontsize=11)
axes[1, 1].set_title('R²分布（市场因子解释力）', fontsize=13, fontweight='bold')
axes[1, 1].grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.savefig('04-资产定价模型-01-CAPM.png', dpi=300, bbox_inches='tight')
plt.show()

print("\n" + "=" * 70)
print("案例1 完成！")
print("=" * 70)
```

## Fama-French三因子模型

```python
print("\n" + "=" * 70)
print("Fama-French三因子模型")
print("=" * 70)

FF3说明 = """
【Fama-French三因子模型】

R_i - R_f = α_i + β_mkt × MKT + β_smb × SMB + β_hml × HML + ε_i

三个因子：

1. MKT（市场因子）
   - 市场超额回报
   - 与CAPM相同

2. SMB（Small Minus Big）
   - 小市值股票组合 - 大市值股票组合
   - 捕捉"规模效应"
   - 小公司回报通常更高

3. HML（High Minus Low）
   - 高账面市值比 - 低账面市值比
   - 捕捉"价值效应"
   - 价值股回报通常高于成长股

【为什么需要多因子？】

CAPM的问题：
- 很多α显著不为0
- 市场因子无法完全解释回报差异

Fama-French发现：
- 小公司、价值股有更高回报
- 不是因为它们beta高
- 而是因为它们承担了其他风险

【检验模型】

如果FF3成立：
✅ α_i = 0（所有资产）
✅ 回报被三个因子完全解释

现实：
- FF3比CAPM好很多
- 但仍有一些α≠0
- 后续发展了5因子、6因子模型
"""

print(FF3说明)
```

## 案例2：Fama-French三因子（50只股票×60个月）

```python
print("\n" + "=" * 70)
print("案例2：Fama-French三因子模型")
print("=" * 70)

print("""
场景：
检验Fama-French三因子模型，50只股票，60个月。

因子：
- mkt_rf: 市场超额回报
- smb: 规模因子（小 - 大）
- hml: 价值因子（高BM - 低BM）

问题：
1. FF3比CAPM解释力更强吗？
2. SMB和HML的风险价格是多少？
3. Alpha还显著吗？
""")

# ===== 1. 生成数据 =====
np.random.seed(67890)
n_stocks_ff = 50
n_months_ff = 60
dates_ff = pd.date_range('2019-01-31', periods=n_months_ff, freq='ME')

# 三个因子（所有股票共同的）
mkt_rf_ff = np.random.normal(0.008, 0.05, n_months_ff)
smb_ff = np.random.normal(0.002, 0.03, n_months_ff)  # 小公司溢价
hml_ff = np.random.normal(0.003, 0.03, n_months_ff)  # 价值溢价

data_list_ff = []

for stock_id in range(1, n_stocks_ff + 1):
    # 每只股票对三个因子的暴露
    beta_mkt = np.random.normal(1.0, 0.4).clip(0.3, 1.8)
    beta_smb = np.random.normal(0, 0.6).clip(-1, 1)
    beta_hml = np.random.normal(0, 0.6).clip(-1, 1)

    # Alpha（大部分应该接近0）
    alpha = np.random.normal(0, 0.002)

    for t, date in enumerate(dates_ff):
        # FF3模型
        ret = (
            alpha +
            beta_mkt * mkt_rf_ff[t] +
            beta_smb * smb_ff[t] +
            beta_hml * hml_ff[t] +
            np.random.normal(0, 0.025)
        )

        data_list_ff.append({
            'stock_id': stock_id,
            'date': date,
            'ret': ret,
            'mkt_rf': mkt_rf_ff[t],
            'smb': smb_ff[t],
            'hml': hml_ff[t]
        })

df_ff = pd.DataFrame(data_list_ff)
df_ff = df_ff.set_index(['stock_id', 'date'])

print(f"\n数据概览：")
print(df_ff.head(10))

print(f"\n因子相关性：")
print(df_ff[['mkt_rf', 'smb', 'hml']].corr().round(3))

# ===== 2. CAPM（基准）=====
print("\n" + "=" * 70)
print("模型1：CAPM（单因子）")
print("=" * 70)

fm_capm_ff = FamaMacBeth.from_formula(
    'ret ~ mkt_rf',
    data=df_ff
)
fm_capm_ff_result = fm_capm_ff.fit()

print(fm_capm_ff_result.summary.tables[1])

capm_r2 = fm_capm_ff_result.rsquared
print(f"\n平均R²: {capm_r2:.4f}")

# ===== 3. Fama-French三因子 =====
print("\n" + "=" * 70)
print("模型2：Fama-French三因子")
print("=" * 70)

fm_ff3 = FamaMacBeth.from_formula(
    'ret ~ mkt_rf + smb + hml',
    data=df_ff
)
fm_ff3_result = fm_ff3.fit()

print("\n" + "="*70)
print(fm_ff3_result.summary)

ff3_r2 = fm_ff3_result.rsquared
print(f"\n平均R²: {ff3_r2:.4f}")
print(f"相比CAPM提升: {ff3_r2 - capm_r2:.4f}")

print("\n因子风险价格：")
print(f"  MKT: {fm_ff3_result.params['mkt_rf']:.6f}")
print(f"  SMB: {fm_ff3_result.params['smb']:.6f}")
print(f"  HML: {fm_ff3_result.params['hml']:.6f}")

print("\n解释：")
print(f"  - beta_MKT增加1，月回报增加{fm_ff3_result.params['mkt_rf']:.4%}")
print(f"  - beta_SMB增加1，月回报增加{fm_ff3_result.params['smb']:.4%}")
print(f"  - beta_HML增加1，月回报增加{fm_ff3_result.params['hml']:.4%}")

# ===== 4. 模型比较 =====
print("\n" + "=" * 70)
print("模型对比")
print("=" * 70)

comparison_ff = pd.DataFrame({
    'CAPM': [
        fm_capm_ff_result.params['mkt_rf'],
        np.nan,
        np.nan,
        capm_r2
    ],
    'FF3': [
        fm_ff3_result.params['mkt_rf'],
        fm_ff3_result.params['smb'],
        fm_ff3_result.params['hml'],
        ff3_r2
    ]
}, index=['MKT', 'SMB', 'HML', 'R²'])

print("\n")
print(comparison_ff.round(6))

print("\n关键发现：")
print(f"  1. FF3的R²更高：{ff3_r2:.4f} vs CAPM的{capm_r2:.4f}")
print(f"  2. SMB和HML都有显著的风险价格")
print(f"  3. FF3能更好地解释股票回报")

# ===== 5. 可视化 =====
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 5.1 三个因子的时间序列
axes[0, 0].plot(dates_ff, mkt_rf_ff, label='MKT', linewidth=1.5, alpha=0.7)
axes[0, 0].plot(dates_ff, smb_ff, label='SMB', linewidth=1.5, alpha=0.7)
axes[0, 0].plot(dates_ff, hml_ff, label='HML', linewidth=1.5, alpha=0.7)
axes[0, 0].axhline(y=0, color='red', linestyle='--', alpha=0.3)
axes[0, 0].set_xlabel('日期', fontsize=11)
axes[0, 0].set_ylabel('因子回报', fontsize=11)
axes[0, 0].set_title('Fama-French三因子时间序列', fontsize=13, fontweight='bold')
axes[0, 0].legend(fontsize=10)
axes[0, 0].grid(True, alpha=0.3)

# 5.2 因子风险价格
factors = ['MKT', 'SMB', 'HML']
risk_prices = [
    fm_ff3_result.params['mkt_rf'],
    fm_ff3_result.params['smb'],
    fm_ff3_result.params['hml']
]
colors_ff = ['steelblue', 'coral', 'green']

axes[0, 1].bar(factors, risk_prices, color=colors_ff, alpha=0.7)
axes[0, 1].axhline(y=0, color='red', linestyle='--')
axes[0, 1].set_ylabel('风险价格', fontsize=11)
axes[0, 1].set_title('Fama-French因子风险价格', fontsize=13, fontweight='bold')
axes[0, 1].grid(axis='y', alpha=0.3)

# 5.3 R²对比
models = ['CAPM', 'FF3']
r2_values = [capm_r2, ff3_r2]
axes[1, 0].bar(models, r2_values, color=['orange', 'steelblue'], alpha=0.7)
axes[1, 0].set_ylabel('平均R²', fontsize=11)
axes[1, 0].set_title('模型解释力对比', fontsize=13, fontweight='bold')
axes[1, 0].grid(axis='y', alpha=0.3)

# 5.4 因子累计回报
cum_mkt = (1 + pd.Series(mkt_rf_ff)).cumprod() - 1
cum_smb = (1 + pd.Series(smb_ff)).cumprod() - 1
cum_hml = (1 + pd.Series(hml_ff)).cumprod() - 1

axes[1, 1].plot(dates_ff, cum_mkt * 100, label='MKT', linewidth=2, alpha=0.7)
axes[1, 1].plot(dates_ff, cum_smb * 100, label='SMB', linewidth=2, alpha=0.7)
axes[1, 1].plot(dates_ff, cum_hml * 100, label='HML', linewidth=2, alpha=0.7)
axes[1, 1].set_xlabel('日期', fontsize=11)
axes[1, 1].set_ylabel('累计回报 (%)', fontsize=11)
axes[1, 1].set_title('三因子累计回报', fontsize=13, fontweight='bold')
axes[1, 1].legend(fontsize=10)
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('04-资产定价模型-02-FF3.png', dpi=300, bbox_inches='tight')
```

## 资产定价方法总结

```python
print("\n" + "=" * 70)
print("资产定价方法总结")
print("=" * 70)

方法总结 = """
【三种回归方法】

1. 时间序列回归（Time-Series Regression）
   对每只股票i单独回归：
   R_i,t = α_i + β_i × Factor_t + ε_i,t

   优点：
   ✅ 允许每只股票不同的alpha和beta
   ✅ 易于理解

   缺点：
   ❌ 不能直接估计因子的风险价格
   ❌ 需要对每只股票单独回归

2. 横截面回归（Cross-Sectional Regression）
   对每个时期t回归：
   R_i,t = λ₀,t + λ₁,t × β̂_i + η_i,t

   优点：
   ✅ 直接估计风险价格λ

   缺点：
   ❌ 需要先估计beta（两步法）
   ❌ beta估计误差会影响结果

3. Fama-MacBeth回归（推荐！）
   结合时间序列和横截面：
   - 第一步：每只股票时间序列回归 → β̂_i
   - 第二步：每期横截面回归 → λ_t
   - 第三步：对λ_t求平均 → λ̄

   优点：
   ✅ 自动处理两步法
   ✅ Shanken修正标准误
   ✅ 金融研究标准方法
   ✅ LinearModels自动完成

【LinearModels实现】

from linearmodels.panel import FamaMacBeth

# Fama-MacBeth回归
fm = FamaMacBeth.from_formula(
    'ret ~ mkt_rf + smb + hml',
    data=df
)
result = fm.fit()

# 结果解释
- params: 因子风险价格（λ）
- tvalues: t统计量
- rsquared: 平均R²

【常见模型】

✅ CAPM：R_i = α + β_mkt × MKT + ε
✅ FF3：R_i = α + β_mkt×MKT + β_smb×SMB + β_hml×HML + ε
✅ Carhart 4因子：FF3 + MOM（动量）
✅ FF5：FF3 + RMW（盈利） + CMA（投资）
"""

print(方法总结)
```
