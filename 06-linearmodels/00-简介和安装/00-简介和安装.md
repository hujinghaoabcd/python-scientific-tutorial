## 什么是面板数据？

### 从生活场景理解

```python
# 场景1：学生成绩追踪
普通数据（横截面）：
  学生A: 数学90分
  学生B: 数学85分
  学生C: 数学95分
  → 只看一次考试，像"快照"

面板数据（Panel Data）：
  学生A: 一年级80分, 二年级85分, 三年级90分
  学生B: 一年级75分, 二年级80分, 三年级85分
  学生C: 一年级90分, 二年级92分, 三年级95分
  → 追踪多次考试，像"纪录片"

优势：
✅ 能看到每个学生的进步轨迹
✅ 能控制"学生个人天赋"这种不变的因素
✅ 能分析"学习方法改变"的真实效果
```

### 面板数据的结构

```python
面板数据 = 横截面数据 + 时间维度

结构：
- 个体维度（entity）：学生、企业、城市、国家...
- 时间维度（time）：年份、季度、月份...
- 观测值：每个(个体, 时间)组合的数据

例子：
┌─────────┬──────┬──────┬────────┐
│ 企业ID  │ 年份 │ 销售额│ 广告费 │
├─────────┼──────┼──────┼────────┤
│ 企业A   │ 2020 │ 100  │ 10     │
│ 企业A   │ 2021 │ 120  │ 15     │
│ 企业A   │ 2022 │ 140  │ 20     │
│ 企业B   │ 2020 │ 80   │ 5      │
│ 企业B   │ 2021 │ 90   │ 8      │
│ 企业B   │ 2022 │ 100  │ 12     │
└─────────┴──────┴──────┴────────┘

特点：
- 200个企业 × 10年 = 2000个观测值
- 比单纯的横截面数据信息量大得多
```

优势对比 = {

## 什么是工具变量？

### 内生性问题

```python
# 场景：教育对收入的影响
简单回归：收入 = β₀ + β₁×教育年限 + ε

问题：教育年限可能是内生的！

内生性来源：
1. 遗漏变量
   - "能力"既影响教育，又影响收入
   - 但"能力"无法直接测量

2. 反向因果
   - 教育 → 收入（我们想要的）
   - 收入 → 教育（有钱才能上学，反向因果）

3. 测量误差
   - 教育年限可能记录不准确

结果：
❌ β₁ 估计有偏差
❌ 无法知道教育的"真实"因果效应
```

### 工具变量的解决方案

```python
工具变量（Instrumental Variable, IV）= 找一个"替身"

要求：
1. 相关性（Relevance）
   - 工具变量要和教育年限相关

2. 外生性（Exogeneity）
   - 工具变量不能直接影响收入
   - 只能通过教育间接影响收入

例子：义务教育改革
- 某年政府延长义务教育年限（从9年到12年）
- 出生在改革后的人，教育年限更长（相关性 ✅）
- 出生年份不影响"能力"（外生性 ✅）
- 完美的工具变量！

比喻：
工具变量就像"自然实验"
- 找到一个外部冲击（如政策改革）
- 这个冲击只影响教育，不直接影响收入
- 利用这个冲击，识别教育的因果效应
```

## 第一个例子：工资面板数据分析

让我们通过一个完整的例子，快速体验 LinearModels 的威力！

### 场景描述

```python
"""
场景：分析工会对工资的影响

数据：
- 545个工人
- 7年时间（1980-1987）
- 总共 545 × 7 = 3815 个观测值

变量：
- lwage: 对数工资（因变量）
- union: 是否加入工会（0或1）
- exper: 工作经验（年）
- married: 是否已婚（0或1）
- educ: 教育年限

问题：
加入工会能提高工资吗？提高多少？
"""
```

### 代码实现

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from linearmodels import PooledOLS, PanelOLS, RandomEffects
import warnings
warnings.filterwarnings('ignore')

# 设置中文显示
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False
plt.style.use('seaborn-v0_8-darkgrid')

print("=" * 70)
print("LinearModels 第一个例子：工会对工资的影响")
print("=" * 70)

# ===== 1. 生成模拟数据 =====
np.random.seed(42)

n_workers = 545  # 工人数量
n_years = 7      # 年数
years = range(1980, 1987)

# 生成个体ID和年份
data_list = []
for worker_id in range(1, n_workers + 1):
    for year in years:
        data_list.append({
            'worker_id': worker_id,
            'year': year
        })

df = pd.DataFrame(data_list)

# 生成个体固定效应（每个工人的"基础能力"）
np.random.seed(42)
individual_effects = np.random.normal(0, 0.3, n_workers)
df['individual_effect'] = df['worker_id'].map(
    dict(zip(range(1, n_workers + 1), individual_effects))
)

# 生成时间不变的特征
worker_characteristics = pd.DataFrame({
    'worker_id': range(1, n_workers + 1),
    'educ': np.random.normal(12, 2, n_workers).clip(8, 18),  # 教育年限
    'ability': np.random.normal(0, 1, n_workers)  # 能力（不可观测）
})

df = df.merge(worker_characteristics, on='worker_id')

# 生成时间变化的特征
df['time_trend'] = df['year'] - 1980  # 时间趋势
df['exper'] = 5 + df['time_trend'] + np.random.normal(0, 1, len(df))  # 工作经验
df['exper'] = df['exper'].clip(0, 30)

# 婚姻状况（随时间可能变化）
df['married'] = np.random.binomial(1, 0.5 + 0.05 * df['time_trend'], len(df))

# 工会状态（随时间可能变化，受教育和经验影响）
union_prob = 0.2 + 0.02 * df['educ'] + 0.01 * df['exper']
union_prob = union_prob.clip(0, 0.8)
df['union'] = np.random.binomial(1, union_prob, len(df))

# 生成工资（真实模型）
# lwage = 1.0 + 0.1*union + 0.05*exper + 0.08*educ + 0.1*married
#         + 0.02*time_trend + individual_effect + 0.3*ability + noise

df['lwage'] = (
    1.0 +                                    # 截距
    0.10 * df['union'] +                     # 工会效应（真实值）
    0.05 * df['exper'] +                     # 经验效应
    0.08 * df['educ'] +                      # 教育效应
    0.10 * df['married'] +                   # 婚姻效应
    0.02 * df['time_trend'] +               # 时间趋势
    df['individual_effect'] +                # 个体固定效应
    0.3 * df['ability'] +                    # 能力（不可观测！）
    np.random.normal(0, 0.2, len(df))       # 随机误差
)

# 设置面板数据索引
df = df.set_index(['worker_id', 'year'])

print(f"\n数据概览：")
print(df.head(10))

print(f"\n数据维度：")
print(f"  工人数量: {n_workers}")
print(f"  时间跨度: {n_years} 年 (1980-1987)")
print(f"  总观测值: {len(df)}")

print(f"\n描述性统计：")
print(df[['lwage', 'union', 'exper', 'educ', 'married']].describe())

# ===== 2. 混合OLS（Pooled OLS）- 不考虑面板结构 =====
print("\n" + "=" * 70)
print("模型1：混合OLS（Pooled OLS）")
print("=" * 70)
print("特点：把所有数据混在一起，当作普通横截面数据")
print("问题：忽略了个体差异（能力、个体效应）")

pooled_model = PooledOLS.from_formula(
    'lwage ~ union + exper + educ + married + time_trend',
    data=df
)
pooled_result = pooled_model.fit(cov_type='clustered', cluster_entity=True)

print("\n混合OLS结果：")
print(pooled_result)

pooled_union_coef = pooled_result.params['union']
print(f"\n工会系数（混合OLS）: {pooled_union_coef:.4f}")
print(f"解释：加入工会使工资提高 {pooled_union_coef*100:.2f}%")
print(f"⚠️ 问题：这个估计可能有偏差（因为忽略了个体能力）")

# ===== 3. 固定效应模型（Fixed Effects）=====
print("\n" + "=" * 70)
print("模型2：固定效应模型（Fixed Effects）")
print("=" * 70)
print("特点：给每个工人一个'专属截距'，控制个体差异")
print("方法：EntityEffects自动为每个worker_id创建虚拟变量")

fe_model = PanelOLS.from_formula(
    'lwage ~ union + exper + married + time_trend + EntityEffects',
    data=df
)
fe_result = fe_model.fit(cov_type='clustered', cluster_entity=True)

print("\n固定效应模型结果：")
print(fe_result)

fe_union_coef = fe_result.params['union']
print(f"\n工会系数（固定效应）: {fe_union_coef:.4f}")
print(f"解释：加入工会使工资提高 {fe_union_coef*100:.2f}%")
print(f"✅ 优势：控制了个体固定效应（能力、个人特质）")
print(f"✅ 更接近真实值 0.10")

print("\n注意：")
print("  - educ（教育年限）消失了！")
print("  - 原因：教育不随时间变化，被个体固定效应吸收")
print("  - 固定效应只能估计'时间变化的'变量")

# ===== 4. 模型比较 =====
print("\n" + "=" * 70)
print("模型比较")
print("=" * 70)

comparison = pd.DataFrame({
    '真实值': [0.10, 0.05, 0.08, 0.10, 0.02],
    '混合OLS': [
        pooled_result.params['union'],
        pooled_result.params['exper'],
        pooled_result.params['educ'],
        pooled_result.params['married'],
        pooled_result.params['time_trend']
    ],
    '固定效应': [
        fe_result.params['union'],
        fe_result.params['exper'],
        np.nan,  # educ被吸收
        fe_result.params['married'],
        fe_result.params['time_trend']
    ]
}, index=['union', 'exper', 'educ', 'married', 'time_trend'])

print("\n系数对比：")
print(comparison.round(4))

print("\n关键发现：")
print(f"  1. 混合OLS高估了工会效应：{pooled_union_coef:.4f} vs 真实值0.10")
print(f"     原因：能力高的人更容易加入工会，混合OLS把能力效应算成了工会效应")
print(f"\n  2. 固定效应更准确：{fe_union_coef:.4f} vs 真实值0.10")
print(f"     原因：控制了个体固定效应，消除了能力的影响")
print(f"\n  3. 教育系数在固定效应中消失")
print(f"     原因：教育不随时间变化，无法在固定效应模型中识别")

# ===== 5. 可视化 =====
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 5.1 工会vs工资（原始数据）
df_reset = df.reset_index()
sns.boxplot(data=df_reset, x='union', y='lwage', ax=axes[0, 0])
axes[0, 0].set_xlabel('工会状态', fontsize=11)
axes[0, 0].set_ylabel('对数工资', fontsize=11)
axes[0, 0].set_title('工会 vs 工资（原始数据）', fontsize=13, fontweight='bold')
axes[0, 0].set_xticklabels(['非工会', '工会'])

# 5.2 系数比较
models = ['真实值', '混合OLS', '固定效应']
union_coefs = [0.10, pooled_union_coef, fe_union_coef]
colors = ['green', 'orange', 'steelblue']

axes[0, 1].bar(models, union_coefs, color=colors, alpha=0.7)
axes[0, 1].axhline(y=0.10, color='red', linestyle='--', label='真实值')
axes[0, 1].set_ylabel('工会系数', fontsize=11)
axes[0, 1].set_title('不同模型的工会系数估计', fontsize=13, fontweight='bold')
axes[0, 1].legend()
axes[0, 1].grid(axis='y', alpha=0.3)

# 5.3 时间趋势
avg_wage_by_year = df_reset.groupby('year')['lwage'].mean()
axes[1, 0].plot(avg_wage_by_year.index, avg_wage_by_year.values,
                marker='o', linewidth=2, markersize=8, color='steelblue')
axes[1, 0].set_xlabel('年份', fontsize=11)
axes[1, 0].set_ylabel('平均对数工资', fontsize=11)
axes[1, 0].set_title('工资随时间的变化', fontsize=13, fontweight='bold')
axes[1, 0].grid(True, alpha=0.3)

# 5.4 工会比例随时间的变化
union_rate = df_reset.groupby('year')['union'].mean()
axes[1, 1].plot(union_rate.index, union_rate.values * 100,
                marker='s', linewidth=2, markersize=8, color='coral')
axes[1, 1].set_xlabel('年份', fontsize=11)
axes[1, 1].set_ylabel('工会加入率 (%)', fontsize=11)
axes[1, 1].set_title('工会加入率随时间的变化', fontsize=13, fontweight='bold')
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('00-简介和安装-01-工资面板分析.png', dpi=300, bbox_inches='tight')
plt.show()

print("\n" + "=" * 70)
print("第一个例子完成！")
print("=" * 70)

print("\n关键要点：")
print("  ✅ 面板数据 = 多个个体 × 多个时期")
print("  ✅ 混合OLS：忽略个体差异，可能有偏")
print("  ✅ 固定效应：控制个体差异，更准确")
print("  ✅ 固定效应不能估计时间不变的变量")
print("  ✅ LinearModels让面板数据分析变得简单！")
```

## LinearModels 核心API

```python
"""
LinearModels 最常用的模型和语法
"""

from linearmodels import PooledOLS, PanelOLS, RandomEffects
from linearmodels import IV2SLS, IVGMM
from linearmodels.panel import FamaMacBeth
from linearmodels.system import SUR, IV3SLS

# ===== 1. 面板数据模型 =====

# 数据准备：设置MultiIndex
df = df.set_index(['entity_id', 'time_id'])

# 混合OLS
pooled = PooledOLS.from_formula('y ~ x1 + x2', data=df)
result = pooled.fit(cov_type='clustered', cluster_entity=True)

# 固定效应（个体固定效应）
fe = PanelOLS.from_formula('y ~ x1 + x2 + EntityEffects', data=df)
result = fe.fit(cov_type='clustered', cluster_entity=True)

# 固定效应（个体 + 时间固定效应）
fe_twoway = PanelOLS.from_formula('y ~ x1 + x2 + EntityEffects + TimeEffects', data=df)
result = fe_twoway.fit(cov_type='clustered', cluster_entity=True)

# 随机效应
re = RandomEffects.from_formula('y ~ x1 + x2', data=df)
result = re.fit(cov_type='clustered', cluster_entity=True)

# ===== 2. 工具变量回归 =====

# 2SLS（两阶段最小二乘）
# 格式：'因变量 ~ 外生变量 [内生变量 ~ 工具变量]'
iv = IV2SLS.from_formula('y ~ exog1 + exog2 + [endog ~ iv1 + iv2]', data=df)
result = iv.fit(cov_type='robust')

# GMM
ivgmm = IVGMM.from_formula('y ~ exog1 + exog2 + [endog ~ iv1 + iv2]', data=df)
result = ivgmm.fit(cov_type='robust')

# ===== 3. 资产定价模型 =====

# Fama-MacBeth两步回归
fm = FamaMacBeth.from_formula('ret ~ mkt + smb + hml', data=df)
result = fm.fit()

# ===== 4. 标准误类型 =====

# 稳健标准误
result = model.fit(cov_type='robust')

# 聚类标准误（按个体）
result = model.fit(cov_type='clustered', cluster_entity=True)

# 聚类标准误（按时间）
result = model.fit(cov_type='clustered', cluster_time=True)

# 双向聚类标准误
result = model.fit(cov_type='clustered', cluster_entity=True, cluster_time=True)
```
