# 第03章：工具变量回归

工具变量（Instrumental Variables, IV）是解决内生性问题的利器！这一章我们深入理解内生性、工具变量的选择、两阶段最小二乘（2SLS）以及各种检验。

## 内生性问题

### 什么是内生性？

```python
print("=" * 70)
print("内生性问题：从生活场景理解")
print("=" * 70)

内生性解释 = """
【内生性（Endogeneity）= 自变量与误差项相关】

简单回归：y = β₀ + β₁x + ε

理想情况（外生性）：
Cov(x, ε) = 0
→ x和ε独立
→ OLS估计无偏且一致

问题（内生性）：
Cov(x, ε) ≠ 0
→ x和ε相关
→ OLS估计有偏且不一致

【场景1：教育收益率】

想研究：收入 = β₀ + β₁×教育年限 + ε

内生性来源：
1. 遗漏变量（能力）
   - 能力高 → 教育多
   - 能力高 → 收入高
   - 能力在误差项ε中
   - Cov(教育, ε) > 0
   - β₁被高估

2. 测量误差
   - 教育年限可能记录不准
   - 测量误差 → 向零偏差

3. 反向因果
   - 教育 → 收入（想要的）
   - 收入 → 教育（有钱才能上学）
   - 双向因果

【场景2：价格弹性】

想研究：需求量 = β₀ + β₁×价格 + ε

内生性来源：联立方程偏差
- 需求：Q_d = α - β₁P + ε_d
- 供给：Q_s = γ + β₂P + ε_s
- 均衡：Q_d = Q_s

问题：
- 观测到的(P, Q)同时由需求和供给决定
- 价格P与需求误差ε_d相关
- 直接回归无法识别需求曲线

【场景3：政策效应】

想研究：经济增长 = β₀ + β₁×基础设施投资 + ε

内生性来源：
- 政府把钱投到经济好的地方（反向因果）
- 或者投到经济差的地方（扶贫）
- 投资决策与ε相关
"""

print(内生性解释)
```

## 什么是工具变量？

```python
print("\n" + "=" * 70)
print("工具变量：解决内生性的灵丹妙药")
print("=" * 70)

工具变量概念 = """
【工具变量（Instrumental Variable, IV）】

定义：找一个变量Z，满足

1. 相关性（Relevance）
   Cov(Z, X) ≠ 0
   → Z与内生变量X相关
   → Z能"预测"X

2. 外生性（Exogeneity）
   Cov(Z, ε) = 0
   → Z与误差项ε无关
   → Z只通过X影响Y，没有"直接"效应

【比喻：找一个"替身"】

问题：X是"坏演员"（与ε勾结）
解决：找Z作为X的"替身"
- Z要能代表X（相关性）
- 但Z是"好演员"（外生性）

【例子1：教育收益率】

问题：教育与能力相关（内生）
工具变量：义务教育改革
- 出生在改革后 → 教育年限更长（相关性 ✅）
- 出生年份不影响能力（外生性 ✅）

逻辑：
- 改革"强制"提高教育（外生冲击）
- 利用这个外生变化，识别教育对收入的因果效应

【例子2：价格弹性】

问题：价格同时由需求和供给决定（内生）
工具变量：供给冲击（如天气、原材料价格）
- 供给冲击影响价格（相关性 ✅）
- 供给冲击不直接影响需求（外生性 ✅）

逻辑：
- 利用供给曲线的移动
- 追踪需求曲线的形状

【例子3：股票收益与波动率】

问题：波动率可能与收益同时被宏观因素影响（内生）
工具变量：期权市场的交易量
- 交易量与波动率相关（相关性 ✅）
- 交易量不直接影响收益（外生性 ✅）

【好的工具变量特征】

✅ 强相关：F统计量 > 10（弱IV检验）
✅ 外生可信：有理论支持或"自然实验"
✅ 排他性：只通过X影响Y

❌ 坏的工具变量：
- 弱工具变量（F < 10）
- 不满足外生性
- 无法通过过度识别检验
"""

print(工具变量概念)
```

## 两阶段最小二乘法（2SLS）

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from linearmodels.iv import IV2SLS, IVGMM
import warnings
warnings.filterwarnings('ignore')

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

print("\n" + "=" * 70)
print("两阶段最小二乘法（2SLS）")
print("=" * 70)

两阶段解释 = """
【2SLS原理】

目标：估计 y = β₀ + β₁x + ε
问题：x是内生的 Cov(x, ε) ≠ 0
工具：有工具变量z，满足相关性和外生性

【第一阶段（First Stage）】

用工具变量预测内生变量：
x = π₀ + π₁z + ν

得到拟合值：x̂ = π̂₀ + π̂₁z

检验：
- F统计量 > 10 → 强工具变量 ✅
- F统计量 < 10 → 弱工具变量 ⚠️

【第二阶段（Second Stage）】

用拟合值代替原变量：
y = β₀ + β₁x̂ + ε

得到2SLS估计β̂₁

直觉：
- x̂是x的"纯净部分"（被z解释的部分）
- x̂与ε无关（因为z与ε无关）
- β̂₁是一致估计

【标准误】

注意：不能直接用第二阶段的标准误！
- 因为x̂是估计出来的（有误差）
- 需要调整标准误

LinearModels自动处理：
- IV2SLS自动计算正确的标准误
- 支持稳健和聚类标准误
"""

print(两阶段解释)
```

## 案例1：教育收益率（单个内生变量）

```python
print("\n" + "=" * 70)
print("案例1：教育收益率 - 2SLS估计")
print("=" * 70)

print("""
场景：
估计教育对收入的因果效应。

数据：500名工人，跟踪5年（2018-2022）。

变量：
- log_wage: 对数工资（因变量）
- educ: 教育年限（内生变量）
- exper: 工作经验（外生）
- compulsory: 义务教育年限（工具变量）
  → 不同出生年份的人面临不同的义务教育政策

问题：
1. 教育是内生的（与能力相关）
2. 如何用义务教育改革作为工具变量？
3. 2SLS估计 vs OLS估计有何不同？
""")

# ===== 1. 生成数据 =====
np.random.seed(20241)
n_workers_iv = 500
years_iv = range(2018, 2023)

data_list_iv = []
for worker_id in range(1, n_workers_iv + 1):
    # 能力（不可观测）
    ability = np.random.normal(0, 1)

    # 义务教育年限（工具变量，取决于出生年份）
    birth_year = np.random.randint(1975, 1990)
    compulsory = 9 if birth_year < 1982 else 12  # 1982年改革

    # 教育年限（受义务教育和能力影响）
    educ = (
        compulsory +
        2 * ability +  # 能力高 → 多读书
        np.random.normal(0, 1.5)
    )
    educ = np.clip(educ, compulsory, 20)

    for t, year in enumerate(years_iv):
        exper = (year - birth_year - educ) + np.random.normal(0, 1)
        exper = max(0, exper)

        # 工资（真实因果效应：教育系数=0.08）
        log_wage = (
            1.2 +
            0.08 * educ +      # 真实教育效应
            0.05 * exper +
            0.20 * ability +   # 能力效应（不可观测！）
            np.random.normal(0, 0.15)
        )

        data_list_iv.append({
            'worker_id': worker_id,
            'year': year,
            'log_wage': log_wage,
            'educ': educ,
            'exper': exper,
            'compulsory': compulsory,
            'ability': ability  # 现实中不可观测
        })

df_educ = pd.DataFrame(data_list_iv)
df_educ = df_educ.set_index(['worker_id', 'year'])

print(f"\n数据概览：")
print(df_educ.head(10))

print(f"\n义务教育分布：")
print(df_educ.reset_index().groupby('worker_id')['compulsory'].first().value_counts())

# ===== 2. OLS估计（有偏！）=====
from linearmodels import PooledOLS

print("\n" + "=" * 70)
print("OLS估计（基准，有偏）")
print("=" * 70)

ols_model = PooledOLS.from_formula(
    'log_wage ~ educ + exper',
    data=df_educ
)
ols_result = ols_model.fit(cov_type='clustered', cluster_entity=True)

print(ols_result.summary.tables[1])

ols_educ_coef = ols_result.params['educ']
print(f"\nOLS教育系数: {ols_educ_coef:.4f}")
print(f"真实值: 0.08")
print(f"偏差: {ols_educ_coef - 0.08:.4f}")
print(f"⚠️ OLS高估了教育效应（因为混入了能力）")

# ===== 3. 第一阶段：检验工具变量强度 =====
print("\n" + "=" * 70)
print("第一阶段：工具变量强度检验")
print("=" * 70)

first_stage = PooledOLS.from_formula(
    'educ ~ compulsory + exper',
    data=df_educ
)
first_stage_result = first_stage.fit(cov_type='clustered', cluster_entity=True)

print(first_stage_result.summary.tables[1])

# F统计量
f_stat = first_stage_result.f_statistic.stat
print(f"\n第一阶段F统计量: {f_stat:.2f}")

if f_stat > 10:
    print(f"✅ 强工具变量（F={f_stat:.1f} > 10）")
else:
    print(f"⚠️ 弱工具变量（F={f_stat:.1f} < 10）")

compulsory_coef = first_stage_result.params['compulsory']
print(f"\n义务教育对实际教育的影响: {compulsory_coef:.3f}")
print(f"解释：义务教育每增加1年，实际教育增加{compulsory_coef:.2f}年")

# ===== 4. 2SLS估计 =====
print("\n" + "=" * 70)
print("2SLS估计（工具变量回归）")
print("=" * 70)

print("\nLinearModels公式语法：")
print("'因变量 ~ 外生变量 [内生变量 ~ 工具变量]'")

iv_model = IV2SLS.from_formula(
    'log_wage ~ exper [educ ~ compulsory]',
    data=df_educ
)
iv_result = iv_model.fit(cov_type='clustered', cluster_entity=True)

print("\n" + "="*70)
print(iv_result.summary)

iv_educ_coef = iv_result.params['educ']
print(f"\n2SLS教育系数: {iv_educ_coef:.4f}")
print(f"真实值: 0.08")
print(f"偏差: {iv_educ_coef - 0.08:.4f}")
print(f"✅ 2SLS更接近真实值！")

# ===== 5. 模型比较 =====
print("\n" + "=" * 70)
print("OLS vs 2SLS 对比")
print("=" * 70)

comparison_iv = pd.DataFrame({
    '真实值': [0.08, 0.05],
    'OLS': [
        ols_result.params['educ'],
        ols_result.params['exper']
    ],
    '2SLS': [
        iv_result.params['educ'],
        iv_result.params['exper']
    ],
    'OLS标准误': [
        ols_result.std_errors['educ'],
        ols_result.std_errors['exper']
    ],
    '2SLS标准误': [
        iv_result.std_errors['educ'],
        iv_result.std_errors['exper']
    ]
}, index=['educ', 'exper'])

print("\n")
print(comparison_iv.round(4))

print("\n关键发现：")
print(f"  1. OLS高估教育效应：{ols_educ_coef:.3f} vs 真实0.08")
print(f"     原因：能力高的人教育多，OLS把能力效应算成了教育效应")
print(f"\n  2. 2SLS更准确：{iv_educ_coef:.3f} vs 真实0.08")
print(f"     原因：利用义务教育改革的外生变化")
print(f"\n  3. 2SLS标准误更大")
print(f"     原因：工具变量丢失了一些信息")

# ===== 6. 可视化 =====
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

df_educ_reset = df_educ.reset_index()

# 6.1 教育 vs 工资（原始数据）
axes[0, 0].scatter(df_educ_reset['educ'], df_educ_reset['log_wage'],
                   alpha=0.3, s=10, color='gray', label='数据点')
# OLS拟合线
x_range = np.linspace(df_educ_reset['educ'].min(), df_educ_reset['educ'].max(), 100)
ols_line = ols_result.params['Intercept'] + ols_result.params['educ'] * x_range
axes[0, 0].plot(x_range, ols_line, 'r-', linewidth=2, label=f'OLS (β={ols_educ_coef:.3f})')
# 真实线
true_line = 1.2 + 0.08 * x_range
axes[0, 0].plot(x_range, true_line, 'g--', linewidth=2, label='真实 (β=0.08)')
axes[0, 0].set_xlabel('教育年限', fontsize=11)
axes[0, 0].set_ylabel('对数工资', fontsize=11)
axes[0, 0].set_title('教育 vs 工资', fontsize=13, fontweight='bold')
axes[0, 0].legend(fontsize=9)
axes[0, 0].grid(True, alpha=0.3)

# 6.2 第一阶段：义务教育 vs 实际教育
educ_by_compulsory = df_educ_reset.groupby('compulsory')['educ'].apply(list)
axes[0, 1].boxplot([educ_by_compulsory[9], educ_by_compulsory[12]],
                    labels=['9年', '12年'])
axes[0, 1].set_xlabel('义务教育年限', fontsize=11)
axes[0, 1].set_ylabel('实际教育年限', fontsize=11)
axes[0, 1].set_title('第一阶段：义务教育 → 实际教育', fontsize=13, fontweight='bold')
axes[0, 1].grid(axis='y', alpha=0.3)

# 6.3 系数对比
methods = ['真实值', 'OLS', '2SLS']
educ_coefs = [0.08, ols_educ_coef, iv_educ_coef]
colors = ['green', 'red', 'steelblue']

axes[1, 0].bar(methods, educ_coefs, color=colors, alpha=0.7)
axes[1, 0].axhline(y=0.08, color='black', linestyle='--', alpha=0.5)
axes[1, 0].set_ylabel('教育系数', fontsize=11)
axes[1, 0].set_title('OLS vs 2SLS：教育系数估计', fontsize=13, fontweight='bold')
axes[1, 0].grid(axis='y', alpha=0.3)

# 6.4 标准误对比
se_comparison = [ols_result.std_errors['educ'], iv_result.std_errors['educ']]
axes[1, 1].bar(['OLS', '2SLS'], se_comparison, color=['red', 'steelblue'], alpha=0.7)
axes[1, 1].set_ylabel('标准误', fontsize=11)
axes[1, 1].set_title('标准误对比', fontsize=13, fontweight='bold')
axes[1, 1].grid(axis='y', alpha=0.3)

plt.tight_layout()
plt.savefig('03-工具变量回归-01-教育收益率.png', dpi=300, bbox_inches='tight')
plt.show()

print("\n" + "=" * 70)
print("案例1 完成！")
print("=" * 70)
```

```python
print("\n" + "=" * 70)

print("=" * 70)

弱工具变量 = """
【什么是弱工具变量？】

定义：工具变量与内生变量相关性太弱
- 第一阶段F统计量 < 10
- 工具变量"预测能力"不足

【为什么是问题？】

1. 有限样本偏差
   - 2SLS在小样本中有偏
   - 弱IV时偏差更大
   - 可能比OLS还差！

2. 推断不准确
   - t统计量过大（假显著）
   - 置信区间覆盖率不足

3. 对违反外生性敏感
   - 弱IV时，即使轻微违反外生性
   - 也会导致严重偏差

【检验弱工具变量】

经验法则：
✅ F > 10: 强工具变量
⚠️ 5 < F < 10: 弱工具变量
❌ F < 5: 太弱，不要用

Stock-Yogo临界值：
- 更精确的弱IV检验
- 考虑容忍的最大偏差/size扭曲
- LinearModels自动报告

【解决方案】

1. 寻找更强的工具变量
2. 使用多个工具变量
3. 使用LIML或Fuller-k估计量（对弱IV更稳健）
4. 如果实在找不到强IV → 承认问题，报告OLS
"""
```

## 案例2：价格弹性（多个工具变量 + 过度识别检验）

```python
print("\n" + "=" * 70)
print("案例2：需求价格弹性 - 多个工具变量")
print("=" * 70)

print("""
场景：
估计产品需求的价格弹性。

数据：100个市场，10个时期。

变量：
- quantity: 需求量（因变量）
- price: 价格（内生变量）
- income: 收入（外生）
- weather: 天气指数（工具变量1）
- input_cost: 投入成本（工具变量2）

工具变量逻辑：
- 天气和成本影响供给 → 价格变化
- 但不直接影响需求

问题：
1. 价格是内生的（供需同时决定）
2. 有多个工具变量（过度识别）
3. 如何检验工具变量的有效性？
""")

# ===== 1. 生成数据 =====
np.random.seed(30303)
n_markets = 100
n_periods = 10

data_list_demand = []
for market_id in range(1, n_markets + 1):
    market_effect = np.random.normal(0, 0.5)

    for t in range(n_periods):
        income = np.random.normal(50, 10)
        weather = np.random.normal(20, 5)  # IV1: 天气
        input_cost = np.random.normal(10, 2)  # IV2: 投入成本

        # 供给冲击（影响价格）
        supply_shock = 0.3 * weather - 0.5 * input_cost + np.random.normal(0, 1)

        # 需求冲击（影响价格和数量）
        demand_shock = np.random.normal(0, 1)

        # 价格（内生！由供需共同决定）
        price = (
            15 +
            0.002 * income +
            -0.5 * supply_shock +  # 供给冲击
            0.3 * demand_shock +   # 需求冲击
            market_effect
        )

        # 需求量（真实价格弹性 = -1.5）
        quantity = (
            100 +
            -1.5 * price +         # 真实价格弹性
            0.8 * income +
            demand_shock +
            market_effect +
            np.random.normal(0, 2)
        )

        data_list_demand.append({
            'market_id': market_id,
            'period': t,
            'quantity': quantity,
            'price': price,
            'income': income,
            'weather': weather,
            'input_cost': input_cost
        })

df_demand = pd.DataFrame(data_list_demand)
df_demand = df_demand.set_index(['market_id', 'period'])

print(f"\n数据概览：")
print(df_demand.head(10))

# ===== 2. OLS估计（有偏！）=====
print("\n" + "=" * 70)
print("OLS估计（有偏）")
print("=" * 70)

ols_demand = PooledOLS.from_formula(
    'quantity ~ price + income',
    data=df_demand
)
ols_demand_result = ols_demand.fit(cov_type='clustered', cluster_entity=True)

print(ols_demand_result.summary.tables[1])

ols_price_coef = ols_demand_result.params['price']
print(f"\nOLS价格系数: {ols_price_coef:.4f}")
print(f"真实值: -1.5")
print(f"⚠️ OLS低估了价格弹性的绝对值（内生性偏差）")

# ===== 3. 第一阶段：检验工具变量 =====
print("\n" + "=" * 70)
print("第一阶段：两个工具变量的强度")
print("=" * 70)

first_stage_demand = PooledOLS.from_formula(
    'price ~ weather + input_cost + income',
    data=df_demand
)
first_stage_demand_result = first_stage_demand.fit(cov_type='clustered', cluster_entity=True)

print(first_stage_demand_result.summary.tables[1])

f_stat_demand = first_stage_demand_result.f_statistic.stat
print(f"\n第一阶段F统计量: {f_stat_demand:.2f}")

if f_stat_demand > 10:
    print(f"✅ 强工具变量（F={f_stat_demand:.1f} > 10）")
else:
    print(f"⚠️ 弱工具变量（F={f_stat_demand:.1f} < 10）")

# ===== 4. 2SLS：恰好识别（1个IV）=====
print("\n" + "=" * 70)
print("2SLS：恰好识别（仅用天气作为IV）")
print("=" * 70)

iv_just = IV2SLS.from_formula(
    'quantity ~ income [price ~ weather]',
    data=df_demand
)
iv_just_result = iv_just.fit(cov_type='clustered', cluster_entity=True)

print(iv_just_result.summary.tables[1])

# ===== 5. 2SLS：过度识别（2个IV）=====
print("\n" + "=" * 70)
print("2SLS：过度识别（用天气和成本作为IV）")
print("=" * 70)

iv_over = IV2SLS.from_formula(
    'quantity ~ income [price ~ weather + input_cost]',
    data=df_demand
)
iv_over_result = iv_over.fit(cov_type='clustered', cluster_entity=True)

print(iv_over_result.summary.tables[1])

print("\n过度识别的好处：")
print("  ✅ 更有效率（标准误更小）")
print("  ✅ 可以检验工具变量的有效性（Sargan/Hansen J检验）")

# ===== 6. Sargan过度识别检验 =====
print("\n" + "=" * 70)
print("Sargan过度识别检验")
print("=" * 70)

print("""
Sargan/Hansen J检验：
- H0: 所有工具变量都是外生的
- H1: 至少有一个工具变量不外生

条件：
- 需要过度识别（工具变量数 > 内生变量数）
- 至少有一个IV是外生的

决策：
- p > 0.05: 不拒绝H0，工具变量有效 ✅
- p < 0.05: 拒绝H0，至少有一个IV有问题 ⚠️
""")

# Sargan统计量
if hasattr(iv_over_result, 'sargan'):
    print(f"\nSargan统计量: {iv_over_result.sargan.stat:.4f}")
    print(f"p值: {iv_over_result.sargan.pval:.4f}")

    if iv_over_result.sargan.pval > 0.05:
        print(f"✅ 不拒绝H0（p={iv_over_result.sargan.pval:.4f} > 0.05）")
        print(f"   工具变量通过外生性检验")
    else:
        print(f"⚠️ 拒绝H0（p={iv_over_result.sargan.pval:.4f} < 0.05）")
        print(f"   至少有一个工具变量可能不外生")
```

## 工具变量回归总结

```python
print("\n" + "=" * 70)
print("工具变量回归：完整流程")
print("=" * 70)

完整流程 = """
【步骤1：识别内生性】

问题：X可能与ε相关？
- 遗漏变量
- 测量误差
- 反向因果
- 联立方程

【步骤2：寻找工具变量Z】

要求：
✅ 相关性：Z与X相关
✅ 外生性：Z与ε无关
✅ 排他性：Z只通过X影响Y

来源：
- 自然实验（政策改革、地理变化）
- 制度特征
- 历史事件
- 随机分配

【步骤3：检验工具变量强度】

第一阶段回归：X ~ Z
- F统计量 > 10 → 强IV ✅
- F统计量 < 10 → 弱IV ⚠️

【步骤4：2SLS或GMM估计】

恰好识别（#IV = #内生变量）：
- 用2SLS

过度识别（#IV > #内生变量）：
- 用2SLS或GMM
- GMM略微更有效率

【步骤5：过度识别检验】

Sargan/Hansen J检验：
- H0：所有IV都外生
- p > 0.05 → 通过 ✅
- p < 0.05 → 至少一个IV有问题 ⚠️

【步骤6：报告】

必须报告：
□ 第一阶段F统计量
□ 2SLS/GMM系数和标准误
□ 过度识别检验结果（如适用）
□ 与OLS对比

【常见错误】

❌ 弱工具变量（F < 10）
❌ 不报告第一阶段
❌ 工具变量不满足外生性
❌ 过度识别检验失败但仍使用
❌ 不使用聚类/稳健标准误
"""

print(完整流程)
```
