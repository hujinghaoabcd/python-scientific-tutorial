## 什么是统计建模？

### 从生活中理解统计建模

**场景1：医生看病**

想象你去医院看病：

```python
# 医生的工作流程（统计建模的流程）
症状 = ["头痛", "发烧", "咳嗽"]  # 数据收集
经验 = "根据多年行医经验"        # 建立模型
诊断 = 医生(症状, 经验)          # 预测结果
print(诊断)  # "可能是感冒"

# 统计建模做的就是这个！
# 输入：数据（症状）
# 模型：经验规律（模型）
# 输出：预测（诊断）
```

医生是怎么诊断的？
1. **收集数据**：询问症状、测体温、听诊
2. **经验判断**：根据多年经验和医学知识
3. **得出结论**：诊断病因、开药方

统计建模也是这样：
1. **收集数据**：历史销售数据、用户行为数据
2. **建立模型**：用数学方法找规律
3. **预测未来**：预测销售额、用户流失

**场景2：天气预报**

气象局怎么预测天气？

```python
# 天气预报系统
历史天气数据 = {
    "温度": [20, 22, 25, 23, 21],
    "湿度": [60, 65, 70, 68, 63],
    "气压": [1013, 1015, 1012, 1010, 1014],
    "第二天是否下雨": [False, False, True, True, False]
}

# 建立模型：学习规律
# "气压低于1012、湿度高于68 → 很可能下雨"

# 今天的数据
今天 = {"温度": 22, "湿度": 70, "气压": 1011}
预测 = 天气预报模型(今天)
print(预测)  # "明天下雨概率：85%"
```

这就是统计建模的本质：
- **从历史数据中学习规律**
- **用规律预测未来**
- **用数字量化不确定性**

**场景3：房价评估**

你想买房，怎么判断价格合理？

```python
# 房价评估模型
历史成交数据 = [
    {"面积": 50, "楼层": 3, "地段": "市中心", "价格": 300万},
    {"面积": 80, "楼层": 10, "地段": "市中心", "价格": 500万},
    {"面积": 100, "楼层": 5, "地段": "郊区", "价格": 350万},
    # ... 1000条数据
]

# 统计建模发现规律：
# 价格 = 5万/平米 × 面积 + 楼层加成 + 地段溢价

# 现在有个新房子
新房 = {"面积": 70, "楼层": 8, "地段": "市中心"}
预估价格 = 房价模型(新房)
print(f"合理价格约：{预估价格}万")  # 约420万

# 实际标价450万 → 可能偏贵
```

### 统计建模的核心概念

**1. 变量（Variables）**

就像做菜的食材：

```python
# 预测房价的"食材"
自变量 = ["面积", "楼层", "地段", "房龄"]  # 用来预测的特征（输入）
因变量 = "价格"                            # 要预测的目标（输出）

# 在 Statsmodels 中：
exog = 自变量  # exogenous（外生变量）= 特征 X
endog = 因变量  # endogenous（内生变量）= 目标 y

# 就像炒鸡蛋：
# exog = ["鸡蛋", "油", "盐"]  # 原料（输入）
# endog = "炒鸡蛋"             # 成品（输出）
```

**2. 模型（Model）**

就像做菜的食谱：

```python
# 线性回归模型（最简单的食谱）
价格 = 5万/平米 × 面积 + 10万/层 × 楼层 + 地段加成

# 就像：
# 炒鸡蛋 = 鸡蛋2个 + 油10ml + 盐3g
```

**3. 拟合（Fitting）**

就像学做菜：

```python
# 新手学炒鸡蛋
第1次：鸡蛋3个 + 油5ml → 太干了！
第2次：鸡蛋2个 + 油20ml → 太油了！
第3次：鸡蛋2个 + 油10ml → 刚刚好！✓

# 统计模型的"学习"过程
# 不断调整参数，让预测越来越准确
```

**4. 预测（Prediction）**

就像用学会的菜谱做新菜：

```python
# 学会了炒鸡蛋的配方
# 现在可以预测：炒5个鸡蛋需要多少油？
# 答案：25ml（因为学到了 鸡蛋:油 = 1:5 的规律）
```


**类型3：分类问题**

```python
# 问题：这个客户会不会流失？
客户特征 = {"消费频率": 低, "投诉次数": 多, "会员等级": 普通}
模型 = Logistic回归模型

# 实际应用：
# - 客户流失预测
```

**类型4：关系发现**

```python
# 问题：哪些因素对房价影响最大？
数据 = {"面积": ..., "楼层": ..., "地段": ..., "房龄": ...}
模型 = 多元回归模型
重要性 = 模型.feature_importance()
print(重要性)
# 输出："地段(60%) > 面积(25%) > 楼层(10%) > 房龄(5%)"

# 实际应用：
# - 找出业绩关键因素
# - 分析用户留存原因
# - 发现疾病风险因素
```

## 什么是 Statsmodels？

### Statsmodels 的定位

想象你要组装家具：

```python
# 方法1：自己做（从头编程）
锯木头、钻孔、上螺丝... （写复杂的数学公式和算法）
↓
费时费力，容易出错

# 方法2：用宜家（Scikit-learn）
提供标准化的家具套件（机器学习模型）
↓
快速方便，但不够灵活

# 方法3：用专业工具（Statsmodels）
提供专业的统计工具箱（统计模型）
↓
专业、灵活、可解释性强
```

**Statsmodels vs Scikit-learn**

| 特性 | Statsmodels | Scikit-learn |
|------|-------------|--------------|
| **定位** | 统计分析师的工具 | 机器学习工程师的工具 |
| **目标** | 理解数据关系 | 提高预测准确率 |
| **输出** | 详细的统计报告 | 预测结果 |
| **适用场景** | 因果推断、假设检验 | 预测、分类 |

```python
# Statsmodels 的风格
import statsmodels.api as sm

model = sm.OLS(y, X)
results = model.fit()
print(results.summary())
# 输出：
# - R方：0.85（模型解释了85%的变化）
# - p值：0.001（结果非常显著）
# - 系数：3.5（X每增加1，y增加3.5）
# - 置信区间：[3.2, 3.8]（95%把握系数在这个范围）

# Scikit-learn 的风格
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)
predictions = model.predict(X_test)
# 输出：预测结果
# 没有详细的统计信息
```

### Statsmodels 能做什么？

**1. 回归分析（Regression）**

```python
# 线性回归：最基础但最常用
销售额 = a × 广告费 + b × 价格 + c

# 实际代码
import statsmodels.api as sm

# 数据
X = df[['广告费', '价格']]  # 特征
y = df['销售额']             # 目标

# 建模
model = sm.OLS(y, sm.add_constant(X))
results = model.fit()
print(results.summary())
```

**2. 时间序列分析（Time Series）**

```python
# ARIMA：预测未来趋势
from statsmodels.tsa.arima.model import ARIMA

# 数据：过去3年的每日销售额
sales_data = df['销售额']

# 建模
model = ARIMA(sales_data, order=(1, 1, 1))
results = model.fit()

# 预测未来30天
forecast = results.forecast(steps=30)
print(f"未来30天预测：\n{forecast}")
```

**3. 离散选择模型（Discrete Choice）**

```python
# Logistic回归：预测是/否
from statsmodels.formula.api import logit

# 问题：客户会不会购买？
formula = '购买 ~ 价格 + 优惠力度 + 浏览时长'
model = logit(formula, data=df)
results = model.fit()

# 预测某个客户的购买概率
prob = results.predict(new_customer)
print(f"购买概率：{prob}%")
```

**4. 假设检验（Statistical Tests）**

```python
# t检验：两组数据有没有显著差异？
from statsmodels.stats.weightstats import ttest_ind

# A组用户（看了广告）的购买率
group_a = [0.15, 0.18, 0.16, 0.17, 0.19]
# B组用户（没看广告）的购买率
group_b = [0.10, 0.12, 0.11, 0.10, 0.13]

# 检验差异是否显著
t_stat, p_value, df = ttest_ind(group_a, group_b)
if p_value < 0.05:
    print("广告效果显著！")
else:
    print("广告效果不明显")
```

## 第一个例子：简单线性回归

让我们从一个实际例子开始！

### 场景：预测房价

假设你是房产中介，想预测房价：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm

# ===== 1. 准备数据 =====
# 10套房子的数据
data = {
    '面积': [50, 60, 70, 80, 90, 100, 110, 120, 130, 140],  # 平方米
    '价格': [150, 180, 210, 240, 270, 300, 330, 360, 390, 420]  # 万元
}
df = pd.DataFrame(data)

print("数据预览：")
print(df.head())
#    面积  价格
# 0  50  150
# 1  60  180
# 2  70  210

# ===== 2. 可视化数据 =====
plt.figure(figsize=(10, 6))
plt.scatter(df['面积'], df['价格'], s=100, alpha=0.6)
plt.xlabel('面积（平方米）', fontsize=12)
plt.ylabel('价格（万元）', fontsize=12)
plt.title('房价与面积的关系', fontsize=14)
plt.grid(True, alpha=0.3)
plt.show()

# ===== 3. 建立模型 =====
# 准备数据
X = df['面积']  # 自变量（特征）
y = df['价格']  # 因变量（目标）

# 添加常数项（截距）
X = sm.add_constant(X)

# 创建模型
model = sm.OLS(y, X)  # OLS = Ordinary Least Squares 普通最小二乘法

# 拟合模型（让模型学习数据）
results = model.fit()

# ===== 4. 查看结果 =====
print("\n模型摘要：")
print(results.summary())

# 简化输出
print("\n=== 关键结果 ===")
print(f"R²（拟合优度）: {results.rsquared:.4f}")
print(f"截距: {results.params['const']:.2f} 万元")
print(f"斜率: {results.params['面积']:.2f} 万元/平米")

# 解读：
# - R² = 1.0：模型完美拟合数据（实际中很少见）
# - 截距 = 0：面积为0时的基础价格
# - 斜率 = 3.0：面积每增加1平米，价格增加3万元

# ===== 5. 预测新房价格 =====
# 现在有一套150平米的房子，预测价格
new_area = pd.DataFrame({'const': [1], '面积': [150]})
predicted_price = results.predict(new_area)

print(f"\n预测结果：")
print(f"150平米的房子预计价格：{predicted_price[0]:.2f} 万元")

# ===== 6. 可视化拟合结果 =====
plt.figure(figsize=(10, 6))

# 原始数据点
plt.scatter(df['面积'], df['价格'], s=100, alpha=0.6, label='实际数据')

# 拟合直线
x_range = np.linspace(df['面积'].min(), df['面积'].max(), 100)
x_range_const = sm.add_constant(pd.DataFrame({'面积': x_range}))
y_pred = results.predict(x_range_const)
plt.plot(x_range, y_pred, 'r-', linewidth=2, label='拟合直线')

# 预测点
plt.scatter([150], predicted_price, s=200, c='green',
           marker='*', label='预测（150m²）')

plt.xlabel('面积（平方米）', fontsize=12)
plt.ylabel('价格（万元）', fontsize=12)
plt.title('线性回归：房价预测模型', fontsize=14)
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# ===== 7. 模型诊断 =====
# 检查残差（实际值 - 预测值）
residuals = results.resid

plt.figure(figsize=(12, 4))

# 残差图
plt.subplot(1, 2, 1)
plt.scatter(df['面积'], residuals)
plt.axhline(y=0, color='r', linestyle='--')
plt.xlabel('面积')
plt.ylabel('残差')
plt.title('残差图')
plt.grid(True, alpha=0.3)

# 残差分布
plt.subplot(1, 2, 2)
plt.hist(residuals, bins=5, edgecolor='black')
plt.xlabel('残差')
plt.ylabel('频数')
plt.title('残差分布')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### 代码详解

**1. 数据准备**

```python
# 为什么用字典创建DataFrame？
data = {
    '面积': [50, 60, ...],  # 列名 : 数据
    '价格': [150, 180, ...]
}
df = pd.DataFrame(data)

# 就像Excel表格：
# | 面积 | 价格 |
# |------|------|
# |  50  | 150  |
# |  60  | 180  |
```

**2. 添加常数项**

```python
X = sm.add_constant(X)

# 为什么要加常数项？
# 回归方程：y = a + b*x
#           ↑   ↑
#         常数  系数
#
# 没有常数项：y = b*x（直线过原点）
# 有常数项：y = a + b*x（直线可以不过原点）
```

**3. 创建和拟合模型**

```python
model = sm.OLS(y, X)  # 创建模型（还没学习）
results = model.fit()  # 拟合模型（开始学习）

# 就像：
# 1. 买了一本菜谱（创建模型）
# 2. 按菜谱练习做菜（拟合模型）
```

**4. 理解输出**

```python
print(results.summary())

# 重点看这几个：
# - R-squared: 0.xxx     # 模型好不好（0-1，越大越好）
# - coef（系数）: 3.0    # 面积的影响力
# - P>|t|（p值）: 0.000  # 结果可不可信（<0.05就可信）
```

## 基本概念速查

### 1. 常用术语

```python
# 中文术语对照表
{
    "endog": "因变量/目标变量/y",
    "exog": "自变量/特征变量/X",
    "OLS": "普通最小二乘法（一种回归方法）",
    "R-squared": "R方/拟合优度（模型好坏的指标）",
    "p-value": "p值（统计显著性）",
    "coefficient": "系数（变量的影响力）",
    "residual": "残差（预测误差）",
    "intercept": "截距（常数项）"
}
```

### 2. 典型工作流程

```python
# 统计建模的标准流程
1. 加载数据     → df = pd.read_csv('data.csv')
2. 探索数据     → df.describe(), df.plot()
3. 准备数据     → X, y = df[['特征']], df['目标']
4. 建立模型     → model = sm.OLS(y, X)
5. 拟合模型     → results = model.fit()
6. 查看结果     → print(results.summary())
7. 模型诊断     → 检查残差、假设
8. 预测应用     → results.predict(new_data)
```

### 3. 导入路径

```python
# Statsmodels 有两个主要API

# 方式1：标准API（用 NumPy/Pandas 数据）
import statsmodels.api as sm
model = sm.OLS(y, X)

# 方式2：公式API（用 R 风格公式）
import statsmodels.formula.api as smf
model = smf.ols('价格 ~ 面积 + 楼层', data=df)

# 推荐：
# - 简单模型用公式API（更直观）
# - 复杂模型用标准API（更灵活）
```

## 常见问题

### Q1: Statsmodels 和 Scikit-learn 选哪个？

```python
# 选择指南

✓ 详细的统计报告（p值、置信区间）

✓ 写研究报告或论文

# 用 Scikit-learn 如果你需要：
✓ 高预测准确率
✓ 复杂的机器学习模型

✓ 生产环境部署

# 实际中：两者结合使用最好！
```

### Q2: 为什么要加 add_constant()？

```python
# 不加常数项
model = sm.OLS(y, X)  # y = b*X（直线过原点）

# 加常数项
X = sm.add_constant(X)
model = sm.OLS(y, X)  # y = a + b*X（直线可以不过原点）

# 举例：
# 房价 = 3万/平米 × 面积 + 50万基础价
#        ↑系数          ↑常数项
# 即使面积为0，也有50万的基础价（土地、装修等）
```

### Q3: R-squared 多少算好？

```python
# R² (R-squared) 的解读
```
