## endog 和 exog：它们是什么？

### 从生活中理解

**场景：考试成绩**

老师想知道：学习时间对成绩的影响

```python
# 学生数据
学习时间 = [1, 2, 3, 4, 5]  # 小时/天（你能控制的）
考试成绩 = [60, 70, 80, 90, 95]  # 分数（结果）

# 在统计学中：
exog = 学习时间  # 外生变量（你能控制的因素）
endog = 考试成绩  # 内生变量（你想预测的结果）

# 就像：
# exog = 原因（输入）
# endog = 结果（输出）
```

### 专业术语解释

**endog = endogenous variable（内生变量）**

```python
# 英文直译："内部产生的变量"
# 通俗理解："你想预测的东西"

# 别名：
endog = 因变量 = 目标变量 = y = 响应变量 = 输出

# 例子：
# - 房价（想预测）
# - 销售额（想预测）
# - 是否购买（想预测）
# - 股票价格（想预测）
```

**exog = exogenous variable（外生变量）**

```python
# 英文直译："外部给定的变量"
# 通俗理解："用来预测的东西"

# 别名：
exog = 自变量 = 特征变量 = X = 解释变量 = 输入

# 例子：
# - 房子面积、楼层（用来预测房价）
# - 广告费、价格（用来预测销售额）
# - 用户行为、消费（用来预测是否购买）
# - 历史价格、交易量（用来预测股票价格）
```

### 在 Statsmodels 中的使用

```python
import statsmodels.api as sm
import pandas as pd

# 示例数据：广告费 vs 销售额
data = {
    '广告费': [10, 20, 30, 40, 50],  # exog（特征）
    '销售额': [100, 150, 200, 250, 300]  # endog（目标）
}
df = pd.DataFrame(data)

# ===== 方法1：标准API =====
# 准备数据
X = df['广告费']  # exog
y = df['销售额']  # endog

# 添加常数项
X = sm.add_constant(X)

# 建模（注意参数顺序！）
model = sm.OLS(endog=y, exog=X)
#              ↑目标   ↑特征
# 或者简写：
model = sm.OLS(y, X)  # endog 在前，exog 在后

results = model.fit()
print(results.summary())

# ===== 方法2：公式API =====
import statsmodels.formula.api as smf

# 用公式指定关系（更直观！）
model = smf.ols('销售额 ~ 广告费', data=df)
#                ↑endog  ↑exog
#                目标  ~  特征
results = model.fit()
print(results.summary())
```

### 常见疑问

**Q1: 为什么叫"内生"和"外生"？**

```python
# 想象一个系统：

公司销售系统 = {
    输入（外部因素）: ["广告费", "价格", "季节"],  # exog（外生）
    输出（内部产生）: ["销售额"]                    # endog（内生）
}

# 销售额是系统"内部产生"的结果 → endogenous
# 广告费是"外部给定"的输入 → exogenous
```

**Q2: 能不能有多个 exog？**

```python
# 可以！大多数情况都是多个 exog

# 单个 exog
销售额 = f(广告费)

# 多个 exog（更常见）
销售额 = f(广告费, 价格, 促销, 季节, 竞品)

# 代码示例
X = df[['广告费', '价格', '促销力度']]  # 多个特征
y = df['销售额']                        # 单个目标

model = sm.OLS(y, sm.add_constant(X))
```

**Q3: 能不能有多个 endog？**

```python
# 也可以！但比较少见，需要特殊模型

# 单个 endog（最常见）
房价 = f(面积, 楼层, 地段)

# 多个 endog（特殊情况）
同时预测 = {
    "语文成绩": f(学习时间, IQ, 家庭背景),
    "数学成绩": f(学习时间, IQ, 家庭背景)
}

# 需要用多元回归或向量自回归（VAR）
```

## Statsmodels 的导入路径

### 两种主要 API

Statsmodels 提供两套 API，就像两种不同的"语言"：

**1. 标准 API（sm.）- 数组风格**

```python
import statsmodels.api as sm

# 特点：
# - 用 NumPy 数组或 Pandas DataFrame
# - 需要手动添加常数项
# - 更灵活，适合复杂模型

# 示例
X = df[['特征1', '特征2']]
y = df['目标']
X = sm.add_constant(X)  # 手动加常数项
model = sm.OLS(y, X)
results = model.fit()
```

**2. 公式 API（smf.）- R 风格**

```python
import statsmodels.formula.api as smf

# 特点：
# - 用字符串公式（像 R 语言）
# - 自动添加常数项
# - 更直观，适合简单模型

# 示例
model = smf.ols('目标 ~ 特征1 + 特征2', data=df)
#                ↑      ↑公式
#              目标    特征
results = model.fit()
```

### 详细对比

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf

# 示例数据
data = {
    'x1': [1, 2, 3, 4, 5],
    'x2': [2, 4, 6, 8, 10],
    'y': [3, 7, 11, 15, 19]
}
df = pd.DataFrame(data)

# ========== 标准 API ==========
print("=== 标准 API ===")

# 准备数据
X = df[['x1', 'x2']]
y = df['y']

# 手动添加常数项（重要！）
X = sm.add_constant(X)
print("X 的形状：", X.shape)  # (5, 3) - 包含常数项

# 建模
model = sm.OLS(y, X)
results = model.fit()

# 查看系数
print("截距：", results.params['const'])
print("x1 系数：", results.params['x1'])
print("x2 系数：", results.params['x2'])

# ========== 公式 API ==========
print("\n=== 公式 API ===")

# 建模（一行即可完成。）
model = smf.ols('y ~ x1 + x2', data=df)
#                ↑   ↑  ↑
#              目标 特征们（自动加常数项）

results = model.fit()

# 查看系数（名字略有不同）
print("截距：", results.params['Intercept'])
print("x1 系数：", results.params['x1'])
print("x2 系数：", results.params['x2'])
```

### 公式语法详解

公式 API 的语法非常强大：

```python
# 基本语法：y ~ x
'销售额 ~ 广告费'  # 单个特征

# 多个特征：用 +
'销售额 ~ 广告费 + 价格 + 促销'

# 交互项：用 *
'销售额 ~ 广告费 * 价格'
# 等价于：销售额 ~ 广告费 + 价格 + 广告费:价格

# 只要交互项：用 :
'销售额 ~ 广告费:价格'

# 多项式：用 I()
'销售额 ~ 广告费 + I(广告费**2)'  # 平方项

# 分类变量：用 C()
'销售额 ~ C(地区) + 广告费'  # 地区会被转换为虚拟变量

# 去掉截距：用 -1
'销售额 ~ 广告费 + 价格 - 1'  # 不要常数项

# 包含所有列：用 .
'销售额 ~ .'  # 除了销售额，其他列都作为特征

# 函数变换：直接使用
'销售额 ~ np.log(广告费) + np.sqrt(价格)'
```

### 实际例子

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

# 创建示例数据
np.random.seed(42)
n = 100
df = pd.DataFrame({
    '销售额': np.random.randn(n) * 10 + 50,
    '广告费': np.random.randn(n) * 5 + 20,
    '价格': np.random.choice([9.9, 19.9, 29.9], n),
    '地区': np.random.choice(['北京', '上海', '广州'], n),
    '季节': np.random.choice(['春', '夏', '秋', '冬'], n)
})

# 例1：基础回归
model1 = smf.ols('销售额 ~ 广告费 + 价格', data=df)
results1 = model1.fit()
print("例1 - R²:", results1.rsquared)

# 例2：包含分类变量
model2 = smf.ols('销售额 ~ 广告费 + 价格 + C(地区)', data=df)
results2 = model2.fit()
print("\n例2 - 地区的影响:")
print(results2.params[[p for p in results2.params.index if '地区' in p]])

# 例3：交互效应
model3 = smf.ols('销售额 ~ 广告费 * 价格', data=df)
results3 = model3.fit()
print("\n例3 - 交互项系数:")
print(results3.params)

# 例4：非线性变换
model4 = smf.ols('销售额 ~ 广告费 + I(广告费**2)', data=df)
results4 = model4.fit()
print("\n例4 - 平方项系数:")
print(results4.params)

# 例5：使用所有特征
model5 = smf.ols('销售额 ~ .', data=df)
results5 = model5.fit()
print("\n例5 - 使用所有特征的 R²:", results5.rsquared)
```


## 常见陷阱和注意事项

### 陷阱1：忘记添加常数项

```python
import numpy as np
import statsmodels.api as sm

# 生成数据：y = 10 + 2*x + 噪声
np.random.seed(42)
x = np.random.rand(100)
y = 10 + 2 * x + np.random.randn(100) * 0.1

# 错误：没有加常数项
X_wrong = x.reshape(-1, 1)
model_wrong = sm.OLS(y, X_wrong)
results_wrong = model_wrong.fit()
print("没有常数项：")
print(f"截距: {results_wrong.params[0]:.2f}")  # 不对！

# 正确：添加常数项
X_right = sm.add_constant(x)
model_right = sm.OLS(y, X_right)
results_right = model_right.fit()
print("\n有常数项：")
print(f"截距: {results_right.params[0]:.2f}")   # 约10
print(f"斜率: {results_right.params[1]:.2f}")   # 约2
```

**为什么会这样？**

```python
# 没有常数项：
# 模型被迫拟合：y = b*x（直线过原点）
# 实际数据：y = 10 + 2*x
# 结果：拟合不准确

# 有常数项：
# 模型可以拟合：y = a + b*x
# 实际数据：y = 10 + 2*x
# 结果：a≈10, b≈2，完美！
```

### 陷阱2：endog 和 exog 顺序搞反

```python
# 错误：顺序反了
model = sm.OLS(X, y)  # 错！X和y反了

# 正确：endog（y）在前，exog（X）在后
model = sm.OLS(y, X)  # 对！

# 记忆技巧：
# OLS(你想预测的, 用来预测的)
# OLS(目标, 特征)
# OLS(endog, exog)
```

### 陷阱3：数据类型不匹配

```python
import pandas as pd

df = pd.DataFrame({
    'x': ['1', '2', '3', '4', '5'],  # 字符串！
    'y': [1, 2, 3, 4, 5]
})

# 会报错
# model = sm.OLS(df['y'], sm.add_constant(df['x']))

# 正确：转换数据类型
df['x'] = df['x'].astype(float)
model = sm.OLS(df['y'], sm.add_constant(df['x']))
```

### 陷阱4：缺失值处理

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    'x': [1, 2, np.nan, 4, 5],  # 有缺失值
    'y': [2, 4, 6, 8, 10]
})

# 直接用会报错
# model = sm.OLS(df['y'], sm.add_constant(df['x']))

# 方法1：删除缺失值
df_clean = df.dropna()
model = sm.OLS(df_clean['y'], sm.add_constant(df_clean['x']))

# 方法2：填充缺失值
df['x'] = df['x'].fillna(df['x'].mean())
model = sm.OLS(df['y'], sm.add_constant(df['x']))
```

### 陷阱5：多重共线性

```python
# 问题：两个特征高度相关
df = pd.DataFrame({
    '特征1': [1, 2, 3, 4, 5],
    '特征2': [2, 4, 6, 8, 10],  # = 2 * 特征1
    '目标': [3, 7, 11, 15, 19]
})

# 建模
X = sm.add_constant(df[['特征1', '特征2']])
y = df['目标']
model = sm.OLS(y, X)
results = model.fit()

# ⚠️ 警告：系数不稳定，标准误很大
print(results.summary())

# 检查多重共线性：VIF
from statsmodels.stats.outliers_influence import variance_inflation_factor

vif = pd.DataFrame()
vif['特征'] = X.columns
vif['VIF'] = [variance_inflation_factor(X.values, i) for i in range(X.shape[1])]
print("\nVIF 检查：")
print(vif)
# VIF > 10 表示严重多重共线性
```

### 陷阱6：样本量太小

```python
# 问题：3个观测，2个特征
df = pd.DataFrame({
    'x1': [1, 2, 3],
    'x2': [4, 5, 6],
    'y': [7, 8, 9]
})

X = sm.add_constant(df[['x1', 'x2']])  # 3个参数（常数、x1、x2）
y = df['y']                             # 3个观测

model = sm.OLS(y, X).fit()
# ⚠️ R² = 1.0（完美拟合！）但没有意义

# 经验法则：
# 样本量 >= 10 * 特征数
# 例：10个特征 → 至少100个样本
```

### 2. 模型诊断要做

```python
# 拟合模型后，必须检查：

# 1. 残差图（检查线性假设）
plt.scatter(results.fittedvalues, results.resid)
plt.axhline(y=0, color='r', linestyle='--')
plt.xlabel('拟合值')
plt.ylabel('残差')
plt.title('残差图')
plt.show()

# 2. Q-Q图（检查正态性）
from statsmodels.graphics.gofplots import qqplot
qqplot(results.resid, line='s')
plt.title('Q-Q图')
plt.show()

# 3. 统计检验
# - Durbin-Watson（自相关）
from statsmodels.stats.stattools import durbin_watson
dw = durbin_watson(results.resid)
print(f"Durbin-Watson: {dw:.2f}")  # 接近2最好

# - Jarque-Bera（正态性）
jb_stat, jb_pvalue = results.jarque_bera
print(f"Jarque-Bera p值: {jb_pvalue:.4f}")  # >0.05 表示正态

# - Breusch-Pagan（异方差）
from statsmodels.stats.diagnostic import het_breuschpagan
_, bp_pvalue, _, _ = het_breuschpagan(results.resid, results.model.exog)
print(f"Breusch-Pagan p值: {bp_pvalue:.4f}")  # >0.05 表示同方差
```

### 3. 结果解读要谨慎

```python
results = model.fit()
print(results.summary())

# 关注重点：
# 1. R-squared：模型拟合优度
#    - 0-1之间，越大越好
#    - 但太大(>0.95)可能过拟合

# 2. P>|t|（p值）：显著性
#    - <0.05：显著（***）
#    - <0.01：非常显著（**）
#    - <0.001：极显著（*）

# 3. coef（系数）：影响方向和大小
#    - 正值：正相关
#    - 负值：负相关
#    - 绝对值大：影响大

# 4. [0.025, 0.975]：95%置信区间
#    - 不包含0：显著
#    - 包含0：不显著

# 5. AIC/BIC：模型选择指标
#    - 越小越好
#    - 用于比较不同模型
```

- **endog（目标）和 exog（特征）**：统计建模的两大主角
- **两种 API**：标准 API（灵活）vs 公式 API（直观）
- **公式语法**：R 风格的强大表达能力

### 常见陷阱
- ⚠️ 忘记添加常数项
- ⚠️ endog 和 exog 顺序搞反
- ⚠️ 数据类型不匹配
- ⚠️ 缺失值没处理
- ⚠️ 多重共线性
- ⚠️ 样本量太小

### 最佳实践
- 🎯 先探索数据再建模
- 🎯 建模后要做诊断
- 🎯 谨慎解读结果
- 🎯 保持代码整洁
