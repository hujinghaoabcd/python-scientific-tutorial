# 第10章：生存分析

生存分析研究“事件发生需要多长时间”，例如患者死亡、设备失效、用户流失、贷款违约。它与普通回归最大的区别是：数据中经常存在**删失（censoring）**——我们只知道某个样本在观察结束时尚未发生事件。

本章使用 Statsmodels 自己的 `SurvfuncRight` 和 `PHReg`，不依赖额外生存分析库。

## 10.1 基本概念

设随机事件时间为 `T`：

- 生存函数：`S(t) = P(T > t)`；
- 累积分布：`F(t) = P(T <= t) = 1 - S(t)`；
- 风险函数描述“已经生存到 t 时刻后，立即发生事件的瞬时风险”；
- `status=1` 表示事件发生；
- `status=0` 表示右删失。

生存分析不能简单地把删失样本当作“没有事件”后直接做普通回归，因为这样会丢失时间信息并产生偏差。

## 10.2 构造示例数据

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(42)
n = 300

age = rng.normal(55, 10, n)
treatment = rng.integers(0, 2, n)
biomarker = rng.normal(0, 1, n)

# 生成潜在事件时间：治疗降低风险，年龄和 biomarker 提高风险
linear_predictor = 0.025 * (age - 55) - 0.45 * treatment + 0.35 * biomarker
rate = 0.04 * np.exp(linear_predictor)
event_time = rng.exponential(1 / rate)

# 独立删失时间
censor_time = rng.exponential(28, n)
time = np.minimum(event_time, censor_time)
status = (event_time <= censor_time).astype(int)

df = pd.DataFrame({
    "time": time,
    "status": status,
    "age": age,
    "treatment": treatment,
    "biomarker": biomarker,
})

print(df.head())
print("事件比例:", df["status"].mean())
```

## 10.3 Kaplan–Meier 生存函数

Statsmodels 的 `SurvfuncRight` 用于右删失数据的生存函数估计。

```python
import statsmodels.api as sm

sf = sm.SurvfuncRight(df["time"], df["status"], title="Overall survival")
print(sf.summary().head())
```

关键属性：

```python
print(sf.surv_times[:5])
print(sf.surv_prob[:5])
print(sf.n_risk[:5])
print(sf.n_events[:5])
```

### 生存曲线

```python
import matplotlib.pyplot as plt

fig = sf.plot()
ax = fig.get_axes()[0]
ax.set_xlabel("Time")
ax.set_ylabel("Survival probability")
ax.set_ylim(0, 1.02)
plt.show()
```

### 中位生存时间

```python
median_time = sf.quantile(0.5)
print("中位生存时间:", median_time)
```

如果曲线在观察期内从未下降到 0.5，中位生存时间可能无法稳定估计，这不是程序错误，而是随访长度不足。

## 10.4 分组生存曲线

```python
sf_control = sm.SurvfuncRight(
    df.loc[df["treatment"] == 0, "time"],
    df.loc[df["treatment"] == 0, "status"],
    title="Control",
)

sf_treated = sm.SurvfuncRight(
    df.loc[df["treatment"] == 1, "time"],
    df.loc[df["treatment"] == 1, "status"],
    title="Treatment",
)

ax = sf_control.plot().get_axes()[0]
sf_treated.plot(ax=ax)
ax.set_xlabel("Time")
ax.set_ylabel("Survival probability")
plt.show()
```

曲线差异只能作为描述性证据。若要控制年龄、基线指标等协变量，应使用 Cox 比例风险模型。

## 10.5 Cox 比例风险模型：PHReg

Statsmodels 中 Cox 模型对应 `PHReg`。

```python
from statsmodels.duration.hazard_regression import PHReg

model = PHReg.from_formula(
    "time ~ age + treatment + biomarker",
    data=df,
    status=df["status"],
    ties="efron",
)
result = model.fit()
print(result.summary())
```

模型形式为：

`h(t | x) = h0(t) * exp(x beta)`

其中 `h0(t)` 是未指定参数形式的基线风险函数。

## 10.6 风险比 Hazard Ratio

Cox 回归系数本身是对数风险比。对系数取指数：

```python
hr = np.exp(result.params)
hr_table = pd.DataFrame({
    "coef": result.params,
    "hazard_ratio": hr,
}, index=model.exog_names)
print(hr_table)
```

解释规则：

- HR = 1：风险不变；
- HR > 1：风险升高；
- HR < 1：风险降低。

例如 `treatment` 的 HR 为 0.70，可以解释为在模型假设成立且其他变量相同时，治疗组瞬时风险约为对照组的 70%。不要直接说“死亡概率降低 30%”，因为风险比与固定时间点的概率比不是同一个概念。

## 10.7 置信区间

```python
conf = result.conf_int()
ci = pd.DataFrame({
    "HR": np.exp(result.params),
    "HR_low": np.exp(conf[:, 0]),
    "HR_high": np.exp(conf[:, 1]),
}, index=model.exog_names)
print(ci)
```

## 10.8 预测相对风险

模型的线性预测量可以用于排序风险：

```python
linear_hazard = model.predict(
    result.params,
    exog=df[["age", "treatment", "biomarker"]],
    pred_type="lhr",
    pred_only=True,
)

relative_risk = np.exp(linear_hazard)
print(relative_risk[:5])
```

如果需要生存概率预测，要明确预测时间，并正确理解基线风险估计。研究报告中不要把“风险排序”与“个体绝对生存概率”混为一谈。

## 10.9 左截断与分层

### 左截断

样本不是从时间 0 就进入风险集时，可以提供 `entry`：

```python
entry = np.zeros(len(df))
# 构造合法的延迟进入时间：必须严格早于每个样本的观察终点
entry[:20] = 0.5 * np.minimum(df.loc[df.index[:20], "time"].to_numpy(), 2.0)

model_entry = PHReg.from_formula(
    "time ~ age + treatment",
    data=df,
    status=df["status"],
    entry=entry,
)
```

必须保证每个样本的 `entry < time`。

### 分层 Cox 模型

当不同群体具有不同基线风险，但仍希望共享协变量系数时，可以使用 `strata`。

```python
strata = np.where(df["age"] >= 60, "older", "younger")

model_strata = PHReg.from_formula(
    "time ~ treatment + biomarker",
    data=df,
    status=df["status"],
    strata=strata,
)
result_strata = model_strata.fit()
```

## 10.10 比例风险假设

Cox 模型的重要假设是协变量的风险比随时间保持相对稳定。若治疗效果随时间明显改变，单一 Cox 系数可能不能充分描述真实关系。

实践中应：

1. 检查不同组的生存曲线是否出现明显交叉；
2. 检查 Schoenfeld 类残差或时间交互项；
3. 必要时分层、加入时间交互，或采用更适合的模型；
4. 在报告中明确比例风险假设是否得到支持。

Statsmodels 的 `PHRegResults` 提供多类残差，可用于进一步诊断。

## 10.11 删失机制

标准 Kaplan–Meier 和 Cox 分析通常要求删失在适当条件下近似独立。如果高风险患者更容易失访，简单生存曲线可能产生系统性偏差。

Statsmodels 的 `SurvfuncRight` 还支持通过 `exog` 对依赖协变量的删失进行边际生存函数调整，但这属于更高级的设定，需要清楚理解识别假设后再使用。

## 10.12 常见错误

### 错误 1：事件编码反了

确认 `status=1` 是事件，`status=0` 是右删失。

### 错误 2：把删失时间当成真实事件时间

删失只意味着“至少生存到这里”。

### 错误 3：只报告 p 值

至少同时报告 HR、95% CI、事件数、随访时间和模型变量。

### 错误 4：把风险比解释成概率比

HR 描述瞬时风险的相对变化，不等于某一时间点的绝对概率变化。

### 错误 5：忽略比例风险假设

显著性并不能替代模型假设检查。

## 10.13 完整分析模板

```python
import numpy as np
import pandas as pd
import statsmodels.api as sm
from statsmodels.duration.hazard_regression import PHReg

# 1. 数据质量
required = ["time", "status", "age", "treatment", "biomarker"]
analysis = df[required].dropna().copy()
assert (analysis["time"] > 0).all()
assert set(analysis["status"].unique()) <= {0, 1}

# 2. 描述性生存函数
sf = sm.SurvfuncRight(analysis["time"], analysis["status"])
print(sf.summary().head())

# 3. Cox 回归
model = PHReg.from_formula(
    "time ~ age + treatment + biomarker",
    data=analysis,
    status=analysis["status"],
    ties="efron",
)
result = model.fit()
print(result.summary())

# 4. HR 与区间
ci = result.conf_int()
report = pd.DataFrame({
    "HR": np.exp(result.params),
    "CI_low": np.exp(ci[:, 0]),
    "CI_high": np.exp(ci[:, 1]),
    "p_value": result.pvalues,
}, index=model.exog_names)
print(report)
```
