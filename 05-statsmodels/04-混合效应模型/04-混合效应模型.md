# 第04章：混合效应模型（Mixed Effects Models）

当数据有层次结构或重复测量时，普通回归就不够用了。这时候我们需要**混合效应模型**！

## 什么是混合效应模型？

### 从生活中理解

**场景1：学生成绩分析**

```python
# 问题：分析学习时间对成绩的影响
# 数据：100个学生，来自10个不同班级

# ❌ 普通线性回归的问题：
# 成绩 = β₀ + β₁×学习时间 + ε

问题1：同一个班级的学生更相似（不独立）
问题2：不同班级的基础水平不同（有差异）
问题3：忽略了"班级"这个层次

# 例子：
A班平均分：85分（好老师、好氛围）
B班平均分：70分（普通老师）
C班平均分：60分（新老师）

# 如果用普通回归：
# - 把所有学生混在一起
# - 假设他们相互独立
# - 忽略了班级差异
# → 结果不准确！

# ✅ 混合效应模型的解决：
# 成绩ᵢⱼ = (β₀ + u₀ⱼ) + β₁×学习时间ᵢⱼ + εᵢⱼ
#           ↑        ↑
#        固定效应  随机效应（班级差异）

# 其中：
# i = 学生编号
# j = 班级编号
# β₀ = 总体平均截距（固定）
# u₀ⱼ = 班级j的截距偏差（随机）
# β₁ = 学习时间的效应（固定）
```

**场景2：重复测量数据**

```python
# 问题：测试减肥药效果
# 数据：20个人，每人测量5次体重（第1周、第2周...第5周）

# ❌ 普通线性回归的问题：
# 体重 = β₀ + β₁×周数 + ε

问题1：同一个人的5次测量高度相关（不独立）
问题2：每个人的起始体重不同
问题3：每个人的减重速度可能不同

# 例子：
张三：起始90kg，每周减2kg（效果好）
李四：起始90kg，每周减0.5kg（效果差）

# 如果用普通回归：
# - 假设所有观测独立
# - 忽略了"个体"差异
# → 标准误估计错误，假设检验不准！

# ✅ 混合效应模型的解决：
# 体重ᵢⱼ = (β₀ + u₀ᵢ) + (β₁ + u₁ᵢ)×周数ⱼ + εᵢⱼ
#           ↑        ↑     ↑        ↑
#        固定截距 随机截距 固定斜率 随机斜率

# 允许每个人有：
# - 不同的起始体重（随机截距）
# - 不同的减重速度（随机斜率）
```

**场景3：面板数据**

```python
# 问题：分析公司业绩
# 数据：50家公司，观察5年

# ❌ 普通线性回归的问题：
# 业绩 = β₀ + β₁×研发投入 + β₂×市场份额 + ε

问题1：同一家公司的多年数据相关
问题2：不同公司有固有差异（品牌、文化等）
问题3：观测不独立

# ✅ 混合效应模型的解决：
# 考虑公司层面的随机效应
```

### 核心概念

**1. 固定效应（Fixed Effects）**

```python
# 固定效应 = 我们感兴趣的主效应

# 特点：
# - 对所有个体都一样
# - 可以直接解释
# - 是研究的重点

# 例子：
# 学习时间 → 成绩的效应（对所有学生都成立）
# 药物剂量 → 血压的效应（对所有患者都成立）
# 广告费 → 销售额的效应（对所有产品都成立）
```

**2. 随机效应（Random Effects）**

```python
# 随机效应 = 个体或组的差异

# 特点：
# - 因个体/组而异
# - 从某个分布中随机抽取
# - 描述异质性

# 例子：
# 不同班级的基础水平差异
# 不同个人的起始体重差异
# 不同公司的固有差异

# 假设：
# 随机效应 ~ N(0, σ²)
# 即：来自均值为0的正态分布
```

**3. 混合 = 固定 + 随机**

```python
# 混合效应模型 = 固定效应 + 随机效应

# 一般形式：
yᵢⱼ = 固定效应 + 随机效应 + 残差
    = (β₀ + β₁×xᵢⱼ) + (u₀ⱼ + u₁ⱼ×xᵢⱼ) + εᵢⱼ
      ↑                 ↑                   ↑
    固定部分         随机部分            个体内误差

# 其中：
# i = 个体编号（level 1）
# j = 组编号（level 2）
```

### 为什么需要混合效应模型？

**问题1：违反独立性假设**

```python
# 普通回归假设：所有观测独立
# 但实际中：
# - 同一个班的学生相似（聚类）
# - 同一个人的多次测量相关（重复测量）
# - 同一家公司的多年数据相关（面板数据）

# 后果：
# - 标准误估计偏小（太乐观）
# - p值偏小（假显著）
# - 置信区间太窄（不可信）
```

**问题2：忽略层次结构**

```python
# 数据的层次结构：
学校 → 班级 → 学生
国家 → 省份 → 城市
公司 → 部门 → 员工

# 普通回归：把所有观测混在一起
# 混合模型：考虑层次，更准确
```

**问题3：无法建模异质性**

```python
# 异质性：不同个体/组的差异

# 普通回归：假设所有个体一样
# 混合模型：允许个体差异（随机效应）

# 例子：
# 不同学生对教学方法的反应不同
# 不同患者对药物的响应不同
# 不同公司对经济危机的抵抗力不同
```

## 线性混合模型（LME）

### 数学表达

**最简单的形式：随机截距模型**

```python
# Level 1（个体层面）：
yᵢⱼ = β₀ⱼ + β₁×xᵢⱼ + εᵢⱼ

# Level 2（组层面）：
β₀ⱼ = γ₀₀ + u₀ⱼ

# 合并：
yᵢⱼ = (γ₀₀ + u₀ⱼ) + β₁×xᵢⱼ + εᵢⱼ
      ↑        ↑      ↑
    固定截距 随机截距 固定斜率

# 其中：
# γ₀₀ = 总体平均截距
# u₀ⱼ ~ N(0, τ₀₀) = 组j的截距偏差
# εᵢⱼ ~ N(0, σ²) = 个体内误差
```

**更复杂：随机截距+随机斜率**

```python
# Level 1：
yᵢⱼ = β₀ⱼ + β₁ⱼ×xᵢⱼ + εᵢⱼ

# Level 2：
β₀ⱼ = γ₀₀ + u₀ⱼ  # 截距随组变化
β₁ⱼ = γ₁₀ + u₁ⱼ  # 斜率也随组变化

# 合并：
yᵢⱼ = (γ₀₀ + u₀ⱼ) + (γ₁₀ + u₁ⱼ)×xᵢⱼ + εᵢⱼ

# 随机效应协方差：
[u₀ⱼ]   ~ N([0], [τ₀₀   τ₀₁])
[u₁ⱼ]      [0]  [τ₀₁   τ₁₁]

# τ₀₁ = 截距和斜率的协方差
```

### Statsmodels中的语法

```python
import statsmodels.api as sm
import statsmodels.formula.api as smf
from statsmodels.regression.mixed_linear_model import MixedLM

# 方法1：使用MixedLM类
model = MixedLM(endog, exog, groups)
results = model.fit()

# 方法2：使用公式API（推荐，更直观）
model = smf.mixedlm("y ~ x", data=df, groups=df["group"])
results = model.fit()

# 公式语法：

# 1. 只有随机截距
formula = "y ~ x"  # x是固定效应
groups = df["group_id"]

# 2. 随机截距 + 随机斜率
formula = "y ~ x"
re_formula = "~x"  # x也有随机效应

# 3. 多个固定效应，一个随机截距
formula = "y ~ x1 + x2 + x3"

# 4. 嵌套随机效应
# 学生嵌套在班级，班级嵌套在学校
# 需要特殊处理
```

## 完整示例1：学生成绩分析

### 场景：多层次数据

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
import statsmodels.formula.api as smf
from statsmodels.regression.mixed_linear_model import MixedLM

# 设置
np.random.seed(42)
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ===== 1. 生成模拟数据 =====
print("="*60)
print("学生成绩分析案例")
print("="*60)

# 数据结构：10个班级，每班30个学生
n_classes = 10
n_students_per_class = 30
n_total = n_classes * n_students_per_class

# 班级效应（随机截距）
# 不同班级有不同的基础水平
class_effects = np.random.normal(0, 10, n_classes)  # 均值0，标准差10
print(f"\n班级效应（随机截距）：")
for i, effect in enumerate(class_effects):
    print(f"  班级{i+1}: {effect:+.2f}分")

# 生成数据
data_list = []
for class_id in range(n_classes):
    for student_id in range(n_students_per_class):
        # 学习时间（小时/天）
        study_hours = np.random.uniform(1, 8)

        # 成绩模型：
        # 基础分：70
        # 学习时间效应：每小时+3分
        # 班级效应：随机
        # 个体随机误差：标准差5
        score = (70 +                           # 基础分
                3 * study_hours +               # 固定效应
                class_effects[class_id] +       # 随机效应（班级）
                np.random.normal(0, 5))         # 残差

        data_list.append({
            '班级ID': f'班级{class_id+1}',
            '学生ID': f'班级{class_id+1}_学生{student_id+1}',
            '学习时间': study_hours,
            '成绩': score
        })

df = pd.DataFrame(data_list)

print(f"\n数据形状：{df.shape}")
print(f"班级数：{df['班级ID'].nunique()}")
print(f"学生数：{len(df)}")
print("\n前10行：")
print(df.head(10))

# ===== 2. 探索性分析 =====
print("\n" + "="*60)
print("探索性分析")
print("="*60)

# 整体统计
print("\n整体统计：")
print(df[['学习时间', '成绩']].describe())

# 按班级统计
print("\n按班级统计：")
class_stats = df.groupby('班级ID').agg({
    '成绩': ['mean', 'std', 'count'],
    '学习时间': 'mean'
}).round(2)
print(class_stats)

# 可视化
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 1. 成绩分布
axes[0, 0].hist(df['成绩'], bins=30, edgecolor='black', alpha=0.7)
axes[0, 0].set_xlabel('成绩')
axes[0, 0].set_ylabel('频数')
axes[0, 0].set_title('成绩分布')
axes[0, 0].grid(True, alpha=0.3)

# 2. 学习时间 vs 成绩（整体）
axes[0, 1].scatter(df['学习时间'], df['成绩'], alpha=0.5)
axes[0, 1].set_xlabel('学习时间（小时/天）')
axes[0, 1].set_ylabel('成绩')
axes[0, 1].set_title('学习时间 vs 成绩（整体）')
axes[0, 1].grid(True, alpha=0.3)

# 3. 按班级的箱线图
df.boxplot(column='成绩', by='班级ID', ax=axes[1, 0])
axes[1, 0].set_xlabel('班级')
axes[1, 0].set_ylabel('成绩')
axes[1, 0].set_title('各班级成绩分布')
plt.setp(axes[1, 0].xaxis.get_majorticklabels(), rotation=45)

# 4. 按班级着色的散点图
for class_id in df['班级ID'].unique():
    class_data = df[df['班级ID'] == class_id]
    axes[1, 1].scatter(class_data['学习时间'], class_data['成绩'],
                      alpha=0.6, label=class_id)
axes[1, 1].set_xlabel('学习时间（小时/天）')
axes[1, 1].set_ylabel('成绩')
axes[1, 1].set_title('学习时间 vs 成绩（按班级）')
axes[1, 1].legend(bbox_to_anchor=(1.05, 1), loc='upper left', fontsize=8)
axes[1, 1].grid(True, alpha=0.3)

plt.suptitle('')
plt.tight_layout()
plt.show()

# ===== 3. 普通线性回归（错误的方法）=====
print("\n" + "="*60)
print("方法1：普通线性回归（错误）")
print("="*60)

# 忽略班级结构
model_ols = smf.ols('成绩 ~ 学习时间', data=df)
results_ols = model_ols.fit()

print("\n普通回归结果：")
print(results_ols.summary())

print("\n问题：")
print("  1. 假设所有学生独立（实际不是）")
print("  2. 忽略班级差异")
print("  3. 标准误可能不准确")

# ===== 4. 固定效应模型（把班级当固定效应）=====
print("\n" + "="*60)
print("方法2：固定效应模型（班级作为哑变量）")
print("="*60)

# 把班级当作固定效应（虚拟变量）
model_fe = smf.ols('成绩 ~ 学习时间 + C(班级ID)', data=df)
results_fe = model_fe.fit()

print("\n固定效应结果：")
print(results_fe.summary())

print("\n问题：")
print("  1. 班级多时，参数太多（浪费自由度）")
print("  2. 无法推广到新班级")
print("  3. 不能估计班级层面的变量")

# ===== 5. 混合效应模型（正确的方法）=====
print("\n" + "="*60)
print("方法3：混合效应模型（推荐）")
print("="*60)

# 随机截距模型
model_mixed = smf.mixedlm("成绩 ~ 学习时间", data=df, groups=df["班级ID"])
results_mixed = model_mixed.fit()

print("\n混合效应模型结果：")
print(results_mixed.summary())

# ===== 6. 结果解读 =====
print("\n" + "="*60)
print("结果解读")
print("="*60)

print("\n固定效应（所有班级共同的效应）：")
print(f"  截距: {results_mixed.fe_params['Intercept']:.2f}")
print(f"    → 学习时间为0时的平均成绩")
print(f"  学习时间: {results_mixed.fe_params['学习时间']:.2f}")
print(f"    → 学习时间每增加1小时，成绩增加{results_mixed.fe_params['学习时间']:.2f}分")

print("\n随机效应（班级间的差异）：")
print(f"  班级截距标准差: {np.sqrt(results_mixed.cov_re.iloc[0,0]):.2f}")
print(f"    → 班级间的基础水平差异（标准差）")
print(f"  残差标准差: {np.sqrt(results_mixed.scale):.2f}")
print(f"    → 学生个体内的变异")

# 组内相关系数（ICC）
tau_00 = results_mixed.cov_re.iloc[0, 0]
sigma_sq = results_mixed.scale
icc = tau_00 / (tau_00 + sigma_sq)
print(f"\n组内相关系数 (ICC): {icc:.4f}")
print(f"  → {icc*100:.2f}%的成绩变异来自班级差异")
print(f"  → {(1-icc)*100:.2f}%的变异来自学生个体")

# ===== 7. 提取随机效应 =====
print("\n" + "="*60)
print("各班级的随机效应")
print("="*60)

# 提取随机效应（BLUP: Best Linear Unbiased Predictor）
random_effects = results_mixed.random_effects

re_df = pd.DataFrame({
    '班级': list(random_effects.keys()),
    '随机截距': [random_effects[key]['Group'] for key in random_effects.keys()]
})
re_df = re_df.sort_values('随机截距', ascending=False)

print("\n各班级的随机截距（偏差）：")
print(re_df)

print("\n解读：")
print("  正值：该班级的平均成绩高于总体平均")
print("  负值：该班级的平均成绩低于总体平均")

# 可视化随机效应
plt.figure(figsize=(10, 6))
plt.barh(re_df['班级'], re_df['随机截距'])
plt.xlabel('随机截距（分）')
plt.ylabel('班级')
plt.title('各班级的随机效应', fontsize=14, fontweight='bold')
plt.axvline(x=0, color='red', linestyle='--', linewidth=2)
plt.grid(True, alpha=0.3, axis='x')
plt.tight_layout()
plt.show()

# ===== 8. 模型对比 =====
print("\n" + "="*60)
print("模型对比")
print("="*60)

comparison = pd.DataFrame({
    '模型': ['普通回归', '固定效应', '混合效应'],
    'AIC': [results_ols.aic, results_fe.aic, results_mixed.aic],
    'BIC': [results_ols.bic, results_fe.bic, results_mixed.bic],
    '学习时间系数': [
        results_ols.params['学习时间'],
        results_fe.params['学习时间'],
        results_mixed.fe_params['学习时间']
    ],
    '学习时间p值': [
        results_ols.pvalues['学习时间'],
        results_fe.pvalues['学习时间'],
        results_mixed.pvalues['学习时间']
    ]
})

print("\n模型对比：")
print(comparison)

print("\n结论：")
print(f"  - AIC最小的模型：{comparison.loc[comparison['AIC'].idxmin(), '模型']}")
print(f"  - BIC最小的模型：{comparison.loc[comparison['BIC'].idxmin(), '模型']}")
print(f"  - 混合效应模型通常最优（考虑了层次结构）")

# ===== 9. 预测 =====
print("\n" + "="*60)
print("预测")
print("="*60)

# 预测新学生（在已知班级中）
new_student_known_class = pd.DataFrame({
    '学习时间': [5],
    '班级ID': ['班级1']
})

pred_known = results_mixed.predict(new_student_known_class)
print(f"\n班级1的新学生（学习5小时/天）：")
print(f"  预测成绩: {pred_known[0]:.2f}分")

# 预测新学生（在新班级中，随机效应=0）
new_student_new_class = pd.DataFrame({
    '学习时间': [5]
})
# 对于新组，随机效应为0（使用总体平均）
pred_new = results_mixed.fe_params['Intercept'] + \
           results_mixed.fe_params['学习时间'] * 5
print(f"\n新班级的学生（学习5小时/天）：")
print(f"  预测成绩: {pred_new:.2f}分（基于总体平均）")

# ===== 10. 可视化拟合结果 =====
print("\n" + "="*60)
print("可视化拟合")
print("="*60)

fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# 左图：普通回归 vs 混合效应
# 普通回归的拟合线
x_range = np.linspace(df['学习时间'].min(), df['学习时间'].max(), 100)
y_ols = results_ols.params['Intercept'] + results_ols.params['学习时间'] * x_range

axes[0].scatter(df['学习时间'], df['成绩'], alpha=0.3, s=20)
axes[0].plot(x_range, y_ols, 'r-', lw=2, label='普通回归（忽略班级）')

# 混合效应的各班级拟合线
for class_id in df['班级ID'].unique()[:5]:  # 只画前5个班级
    re = random_effects[class_id]['Group']
    intercept = results_mixed.fe_params['Intercept'] + re
    slope = results_mixed.fe_params['学习时间']
    y_mixed = intercept + slope * x_range
    axes[0].plot(x_range, y_mixed, '--', lw=1.5, alpha=0.7,
                label=f'{class_id}（混合效应）')

axes[0].set_xlabel('学习时间（小时/天）')
axes[0].set_ylabel('成绩')
axes[0].set_title('普通回归 vs 混合效应')
axes[0].legend(fontsize=8)
axes[0].grid(True, alpha=0.3)

# 右图：各班级的截距和斜率
class_intercepts = []
```

## 关键概念深入

### 1. 组内相关系数（ICC）

```python
# ICC = Intraclass Correlation Coefficient
# 衡量组内观测的相似程度

# 计算：
ICC = τ₀₀ / (τ₀₀ + σ²)

# 其中：
# τ₀₀ = 组间方差（随机效应方差）
# σ² = 组内方差（残差方差）

# 解读：
ICC = 0.1  # 10%的变异来自组差异，90%来自个体
ICC = 0.5  # 50%的变异来自组差异
ICC = 0.9  # 90%的变异来自组差异（组内高度相似）

# 意义：
# - ICC接近0：组效应不重要，普通回归就够了
# - ICC接近1：组内高度相似，必须用混合模型
# - 通常：ICC > 0.05就应该考虑混合模型
```

### 2. 随机效应的收缩（Shrinkage）

```python
# 混合模型的随机效应会向总体均值"收缩"

# 例子：
# 假设某班只有3个学生，平均分95
# 如果直接估计：班级效应 = +15
# 但混合模型会：班级效应 = +10（收缩了）

# 原因：
# - 样本量小时，估计不稳定
# - 混合模型借用了总体信息
# - 防止过度拟合

# 收缩因子：
λ = τ₀₀ / (τ₀₀ + σ²/nⱼ)

# 其中：
# τ₀₀ = 组间方差
# σ² = 组内方差
# nⱼ = 组j的样本量

# 特点：
# - 样本量大 → 收缩少（更相信数据）
# - 样本量小 → 收缩多（更依赖总体）
```

### 3. 何时使用哪种模型？

```python
# 决策树：

数据有层次结构或重复测量吗？
├─ 否 → 普通线性回归
└─ 是
   ├─ 只关心组平均差异？
   │  └─ 固定效应模型（虚拟变量）
   └─ 想推广到新组？想估计组间变异？
      └─ 混合效应模型
         ├─ 斜率在各组一样？
         │  └─ 随机截距模型
         └─ 斜率也因组而异？
            └─ 随机截距+斜率模型

# 混合效应模型的优势：
# 1. 正确的标准误（考虑依赖性）
# 2. 可推广到新组
# 3. 借用信息（收缩估计）
# 4. 可以估计组间变异
# 5. 处理不平衡数据（各组样本量不同）
```

```python
# 三层结构：学生嵌套在班级，班级嵌套在学校
```
