# 第02章：线性回归

线性回归是统计建模中最基础、最常用的方法之一，也是理解后续回归模型的重要起点。

## 什么是线性回归？

### 从生活中理解

**场景1：买菜的规律**

你去菜市场买苹果：

```python
# 观察数据
买了 1 斤 → 花了 5 元
买了 2 斤 → 花了 10 元
买了 3 斤 → 花了 15 元

# 你发现规律：
价格 = 5元/斤 × 斤数

# 这就是线性关系！
# - 有一条直线
# - 可以预测：买 10 斤 → 花 50 元
```

**场景2：工资涨幅**

你工作多年，工资增长：

```python
# 工作经验 vs 月薪
1年经验 → 5000元
2年经验 → 6000元
3年经验 → 7000元
4年经验 → 8000元

# 发现规律：
月薪 = 4000元（起薪）+ 1000元/年 × 工作年限

# 预测：10年经验 → 4000 + 1000×10 = 14000元
```

**场景3：房价估算**

房产中介估价：

```python
# 观察数据：50套房子的成交记录
面积(m²)  价格(万)
50       150
60       180
70       210
...      ...

# 画个图：发现点都在一条线附近
# 拟合直线：价格 = 0 + 3万/m² × 面积

# 新房子：100m² → 预计 300万
```

### 线性回归的本质

**可以先把简单线性回归理解为“用一条直线描述变量关系”**：

```python
# 你有一堆点（数据）
散点 = [(x1, y1), (x2, y2), (x3, y3), ...]

# 你想画一条直线：y = a + b*x
# 使得这条线：
# - 尽可能靠近所有点
# - 预测误差最小

# 这就是线性回归！
```

**为什么叫"线性"？**

```python
# 线性关系：可以用直线表示
y = a + b*x              # ✓ 线性（直线）
y = a + b*x + c*x²       # ✓ 线性（对参数a,b,c是线性的）

# 非线性关系：不能用直线表示
y = a * e^(b*x)          # ✗ 非线性
y = a * sin(b*x)         # ✗ 非线性

# 注意："线性"指的是参数（a, b, c）的关系
# 不是指 x 和 y 的关系！
```

### 线性回归的数学表达

**简单线性回归（一个自变量）**

```python
y = β₀ + β₁*x + ε

# 中文表达：
目标值 = 截距 + 斜率 × 特征 + 误差

# 例子：
房价 = 50万 + 3万/m² × 面积 + 误差

# 参数含义：
β₀ (beta0) = 截距（intercept）    # x=0时y的值
β₁ (beta1) = 斜率（slope）         # x每增加1，y增加多少
ε (epsilon) = 误差（error）        # 随机误差项
```

**多元线性回归（多个自变量）**

```python
y = β₀ + β₁*x₁ + β₂*x₂ + ... + βₙ*xₙ + ε

# 例子：房价预测
房价 = β₀ + β₁×面积 + β₂×楼层 + β₃×房龄 + β₄×地段 + ε

# 这是一个"平面"或"超平面"，不再是直线
# 但对参数来说，仍然是"线性"的
```

### 最小二乘法（OLS）

**OLS = Ordinary Least Squares（普通最小二乘法）**

这是找最佳拟合直线的方法：

```python
# 目标：让所有点到直线的"距离"最小

# 对于每个点 i：
实际值 = yᵢ
预测值 = ŷᵢ = β₀ + β₁*xᵢ
误差 = eᵢ = yᵢ - ŷᵢ

# 总误差（残差平方和）：
SSE = Σ(yᵢ - ŷᵢ)² = Σeᵢ²

# 最小二乘法：找β₀和β₁，使得SSE最小
# 这就是 OLS 的基本思想
```

**为什么用"平方"？**

```python
# 如果不平方：
误差和 = (y₁-ŷ₁) + (y₂-ŷ₂) + ...
# 问题：正误差和负误差会抵消

# 用平方：
误差平方和 = (y₁-ŷ₁)² + (y₂-ŷ₂)² + ...
# 好处：
# 1. 都是正数，不会抵消
# 2. 大误差被放大（惩罚大误差）
# 3. 数学上容易求解
```

## 简单线性回归（一个自变量）

### 完整示例：房价预测

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
from scipy import stats

# 设置中文显示
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ===== 1. 生成模拟数据 =====
np.random.seed(42)

# 真实关系：房价 = 50 + 3*面积 + 噪声
面积 = np.linspace(40, 150, 50)  # 40-150平米
真实价格 = 50 + 3 * 面积
噪声 = np.random.normal(0, 20, 50)  # 随机误差
观察价格 = 真实价格 + 噪声

# 创建DataFrame
df = pd.DataFrame({
    '面积': 面积,
    '价格': 观察价格
})

print("数据预览：")
print(df.head())
print(f"\n数据形状：{df.shape}")
print("\n描述统计：")
print(df.describe())

# ===== 2. 数据可视化 =====
plt.figure(figsize=(12, 5))

# 左图：散点图
plt.subplot(1, 2, 1)
plt.scatter(df['面积'], df['价格'], alpha=0.6, s=50)
plt.xlabel('面积（平方米）', fontsize=12)
plt.ylabel('价格（万元）', fontsize=12)
plt.title('房价 vs 面积', fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)

# 右图：分布图
plt.subplot(1, 2, 2)
df['价格'].hist(bins=15, edgecolor='black', alpha=0.7)
plt.xlabel('价格（万元）', fontsize=12)
plt.ylabel('频数', fontsize=12)
plt.title('价格分布', fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# ===== 3. 建立模型 =====
print("\n" + "="*50)
print("建立线性回归模型")
print("="*50)

# 准备数据
X = df['面积']  # 自变量
y = df['价格']  # 因变量

# 添加常数项
X = sm.add_constant(X)

# 创建OLS模型
model = sm.OLS(y, X)

# 拟合模型
results = model.fit()

# ===== 4. 查看结果 =====
print("\n完整的回归结果：")
print(results.summary())

# ===== 5. 提取关键信息 =====
print("\n" + "="*50)
print("关键结果解读")
print("="*50)

# 回归系数
intercept = results.params['const']  # 截距
slope = results.params['面积']        # 斜率

print(f"\n回归方程：")
print(f"价格 = {intercept:.2f} + {slope:.2f} × 面积")
print(f"\n解读：")
print(f"  - 截距 {intercept:.2f}：基础价格（面积为0时的价格）")
print(f"  - 斜率 {slope:.2f}：面积每增加1m²，价格增加{slope:.2f}万元")

# 模型评估指标
r_squared = results.rsquared
adj_r_squared = results.rsquared_adj
f_statistic = results.fvalue
f_pvalue = results.f_pvalue

print(f"\n模型评估：")
print(f"  - R² = {r_squared:.4f}")
print(f"    解读：模型解释了{r_squared*100:.2f}%的价格变化")
print(f"  - 调整R² = {adj_r_squared:.4f}")
print(f"  - F统计量 = {f_statistic:.2f}, p值 = {f_pvalue:.4e}")
print(f"    解读：模型整体{'非常显著' if f_pvalue < 0.001 else '显著' if f_pvalue < 0.05 else '不显著'}")

# 系数的显著性
print(f"\n系数显著性：")
for name, coef, pval in zip(results.params.index, results.params.values, results.pvalues.values):
    significance = "***" if pval < 0.001 else "**" if pval < 0.01 else "*" if pval < 0.05 else "不显著"
    print(f"  - {name}: 系数={coef:.4f}, p值={pval:.4e} {significance}")

# 置信区间
conf_int = results.conf_int()
print(f"\n95%置信区间：")
for name in results.params.index:
    lower, upper = conf_int.loc[name]
    print(f"  - {name}: [{lower:.2f}, {upper:.2f}]")

# ===== 6. 预测 =====
print("\n" + "="*50)
print("预测新数据")
print("="*50)

# 预测几个新房子的价格
new_areas = pd.DataFrame({
    'const': [1, 1, 1],
    '面积': [80, 100, 120]
})

predictions = results.predict(new_areas)
prediction_interval = results.get_prediction(new_areas).summary_frame()

print("\n预测结果：")
for i, area in enumerate([80, 100, 120]):
    pred = predictions[i]
    lower = prediction_interval.iloc[i]['obs_ci_lower']
    upper = prediction_interval.iloc[i]['obs_ci_upper']
    print(f"  面积 {area}m² → 预计价格 {pred:.2f}万 (95% CI: [{lower:.2f}, {upper:.2f}])")

# ===== 7. 可视化拟合结果 =====
plt.figure(figsize=(14, 5))

# 左图：拟合直线
plt.subplot(1, 2, 1)
# 原始数据
plt.scatter(df['面积'], df['价格'], alpha=0.6, s=50, label='实际数据')
# 拟合直线
x_range = np.linspace(df['面积'].min(), df['面积'].max(), 100)
x_range_const = sm.add_constant(pd.DataFrame({'面积': x_range}))
y_pred_range = results.predict(x_range_const)
plt.plot(x_range, y_pred_range, 'r-', linewidth=2, label='拟合直线')
# 预测点
plt.scatter([80, 100, 120], predictions, s=200, c='green',
           marker='*', zorder=5, label='预测值')
plt.xlabel('面积（平方米）', fontsize=12)
plt.ylabel('价格（万元）', fontsize=12)
plt.title(f'线性回归拟合\n价格 = {intercept:.2f} + {slope:.2f}×面积',
         fontsize=14, fontweight='bold')
plt.legend()
plt.grid(True, alpha=0.3)

# 右图：残差 vs 拟合值
plt.subplot(1, 2, 2)
fitted_values = results.fittedvalues
residuals = results.resid
plt.scatter(fitted_values, residuals, alpha=0.6, s=50)
plt.axhline(y=0, color='r', linestyle='--', linewidth=2)
plt.xlabel('拟合值', fontsize=12)
plt.ylabel('残差', fontsize=12)
plt.title('残差图', fontsize=14, fontweight='bold')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# ===== 8. 模型诊断 =====
print("\n" + "="*50)
print("模型诊断")
print("="*50)

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 图1：残差 vs 拟合值（检查线性和同方差性）
axes[0, 0].scatter(fitted_values, residuals, alpha=0.6)
axes[0, 0].axhline(y=0, color='r', linestyle='--')
axes[0, 0].set_xlabel('拟合值')
axes[0, 0].set_ylabel('残差')
axes[0, 0].set_title('残差 vs 拟合值\n（应该随机分布，无明显模式）')
axes[0, 0].grid(True, alpha=0.3)

# 图2：Q-Q图（检查正态性）
from scipy.stats import probplot
probplot(residuals, dist="norm", plot=axes[0, 1])
axes[0, 1].set_title('Q-Q图\n（点应该在直线上）')
axes[0, 1].grid(True, alpha=0.3)

# 图3：标准化残差分布
standardized_residuals = residuals / np.std(residuals)
axes[1, 0].hist(standardized_residuals, bins=15, edgecolor='black', alpha=0.7)
axes[1, 0].set_xlabel('标准化残差')
axes[1, 0].set_ylabel('频数')
axes[1, 0].set_title('残差分布\n（应该接近正态分布）')
axes[1, 0].grid(True, alpha=0.3)

# 图4：残差顺序图（检查独立性）
axes[1, 1].plot(residuals, 'o-', alpha=0.6)
axes[1, 1].axhline(y=0, color='r', linestyle='--')
axes[1, 1].set_xlabel('观测顺序')
axes[1, 1].set_ylabel('残差')
axes[1, 1].set_title('残差顺序图\n（应该无明显趋势）')
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# ===== 9. 统计检验 =====
print("\n统计检验：")

# Durbin-Watson检验（自相关）
from statsmodels.stats.stattools import durbin_watson
dw = durbin_watson(residuals)
print(f"  - Durbin-Watson: {dw:.3f}")
print(f"    解读：接近2表示无自相关（1.5-2.5可接受）")

# Jarque-Bera检验（正态性）
jb_stat, jb_pvalue = results.jarque_bera
print(f"  - Jarque-Bera: 统计量={jb_stat:.3f}, p值={jb_pvalue:.4f}")
print(f"    解读：p>{0.05}表示残差服从正态分布")

# Breusch-Pagan检验（异方差）
from statsmodels.stats.diagnostic import het_breuschpagan
_, bp_pvalue, _, _ = het_breuschpagan(residuals, results.model.exog)
print(f"  - Breusch-Pagan: p值={bp_pvalue:.4f}")
print(f"    解读：p>{0.05}表示同方差（方差齐性）")

print("\n" + "="*50)
print("分析完成！")
print("="*50)
```

### 代码详解

**1. 数据准备**

```python
# 为什么生成模拟数据？
# - 教学目的：知道真实关系，便于验证
# - 实际工作：用真实数据

# 真实关系
y = 50 + 3*x + ε
# ↑    ↑   ↑    ↑
# 真  截  斜  随
# 值  距  率  机
#                误差

# 模型会尝试估计出接近 50 和 3 的值
```

**2. 为什么要可视化？**

```python
# 原因1：发现异常值
# 如果有个点远离其他点 → 可能是错误数据

# 原因2：判断关系类型
# 看散点图：
# - 线性关系？→ 用线性回归
# - 曲线关系？→ 考虑变换或多项式
# - 无关系？→ 换特征

# 原因3：检查分布
# 看直方图：
# - 正态分布？→ 好
# - 严重偏态？→ 可能需要变换
```

**3. 添加常数项**

```python
X = sm.add_constant(X)

# 作用：让模型有截距
# 不加：y = b*x（直线过原点）
# 加了：y = a + b*x（直线可以不过原点）

# 大多数情况都要加！
```

**4. 拟合模型**

```python
model = sm.OLS(y, X)  # 创建模型
results = model.fit()  # 拟合数据

# fit()做了什么？
# 1. 计算参数估计值（β₀, β₁）
# 2. 计算各种统计量（R², p值等）
# 3. 计算标准误、置信区间
# 4. 存储残差、拟合值等
```

**5. 理解输出**

```python
print(results.summary())

# 重点看：
# - coef（系数）：参数估计值
# - std err（标准误）：估计的不确定性
# - t（t统计量）：coef / std err
# - P>|t|（p值）：显著性
#   * p < 0.001：***（极显著）
#   * p < 0.01：**（非常显著）
#   * p < 0.05：*（显著）
# - [0.025, 0.975]：95%置信区间
```

**6. R² 的含义**

```python
# R² = 模型解释的变异占总变异的比例

# 例如：R² = 0.85
# 意思：模型解释了85%的价格变化
#       还有15%是其他因素或随机误差

# 计算公式：
SST = Σ(yᵢ - ȳ)²      # 总平方和（Total Sum of Squares）
SSE = Σ(yᵢ - ŷᵢ)²     # 残差平方和（Error Sum of Squares）
SSR = Σ(ŷᵢ - ȳ)²      # 回归平方和（Regression Sum of Squares）

R² = SSR / SST = 1 - SSE/SST
```

**7. 预测**

```python
# 点预测：单个预测值
pred = results.predict(new_data)

# 区间预测：预测区间
pred_interval = results.get_prediction(new_data).summary_frame()
# 包含：
# - mean：预测值
# - mean_se：标准误
# - mean_ci_lower/upper：均值的置信区间
# - obs_ci_lower/upper：新观测的预测区间

# 区别：
# 置信区间：估计平均值的范围（窄）
# 预测区间：估计新观测的范围（宽）
```

**8. 残差诊断**

```python
# 残差 = 实际值 - 预测值
residuals = y - ŷ

# 好的模型，残差应该：
# 1. 均值为0
# 2. 方差恒定（同方差性）
# 3. 服从正态分布
# 4. 相互独立（无自相关）

# 检查方法：
# - 残差图：看是否随机分布
# - Q-Q图：看是否正态
# - Durbin-Watson：检验自相关
# - Breusch-Pagan：检验异方差
```

## 多元线性回归（多个自变量）

### 完整示例：房价预测（多因素）

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

# 设置
np.random.seed(42)
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ===== 1. 生成模拟数据 =====
n = 200  # 200套房子

# 生成特征
面积 = np.random.uniform(50, 150, n)
楼层 = np.random.randint(1, 30, n)
房龄 = np.random.uniform(0, 20, n)
地段得分 = np.random.uniform(60, 100, n)

# 真实关系：
# 价格 = 基础价 + 3×面积 + 0.5×楼层 - 2×房龄 + 1×地段 + 噪声
真实价格 = (30 +
           3.0 * 面积 +
           0.5 * 楼层 +
           -2.0 * 房龄 +
           1.0 * 地段得分)
噪声 = np.random.normal(0, 20, n)
观察价格 = 真实价格 + 噪声

# 创建DataFrame
df = pd.DataFrame({
    '面积': 面积,
    '楼层': 楼层,
    '房龄': 房龄,
    '地段': 地段得分,
    '价格': 观察价格
})

print("="*60)
print("数据概览")
print("="*60)
print(f"\n数据形状：{df.shape}")
print("\n前5行：")
print(df.head())
print("\n描述统计：")
print(df.describe())

# ===== 2. 探索性数据分析 =====
print("\n" + "="*60)
print("探索性数据分析")
print("="*60)

# 相关矩阵
print("\n相关矩阵：")
print(df.corr())

# 可视化
fig, axes = plt.subplots(2, 3, figsize=(15, 10))

# 各特征与价格的关系
for i, col in enumerate(['面积', '楼层', '房龄', '地段']):
    ax = axes[i//2, i%2]
    ax.scatter(df[col], df['价格'], alpha=0.5)
    ax.set_xlabel(col)
    ax.set_ylabel('价格')
    ax.set_title(f'价格 vs {col}')
    ax.grid(True, alpha=0.3)

# 价格分布
axes[1, 2].hist(df['价格'], bins=30, edgecolor='black', alpha=0.7)
axes[1, 2].set_xlabel('价格')
axes[1, 2].set_ylabel('频数')
axes[1, 2].set_title('价格分布')
axes[1, 2].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# 相关矩阵热图
plt.figure(figsize=(10, 8))
sns.heatmap(df.corr(), annot=True, cmap='coolwarm', center=0,
           square=True, linewidths=1)
plt.title('特征相关矩阵', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.show()

# ===== 3. 建立多元线性回归模型 =====
print("\n" + "="*60)
print("多元线性回归模型")
print("="*60)

# 准备数据
X = df[['面积', '楼层', '房龄', '地段']]
y = df['价格']

# 添加常数项
X = sm.add_constant(X)

# 拟合模型

results = model.fit()
```

## 理解关键概念

### 1. R² vs 调整R²

```python
# R²（R-squared）
# - 范围：0-1
# - 含义：模型解释的变异比例
# - 问题：添加任何变量都会增加R²

# 调整R²（Adjusted R²）
# - 考虑了变量个数
# - 公式：Adj-R² = 1 - (1-R²) × (n-1)/(n-p-1)
#   n = 样本量, p = 变量数
# - 好处：只有当新变量真正提升模型时才增加

# 例子：
R² = 0.85, n=100, p=1 → Adj-R² = 0.848
R² = 0.86, n=100, p=5 → Adj-R² = 0.852

# 增加4个变量，R²从0.85→0.86
# 但Adj-R²只从0.848→0.852
# 说明新变量贡献不大！
```

### 2. 系数的解释

```python
# 简单回归：
# 价格 = 50 + 3×面积
# 解读：面积每增加1m²，价格增加3万元

# 多元回归：
# 价格 = 30 + 3×面积 + 0.5×楼层 - 2×房龄
# 解读（重要！）：
# - 面积系数3：在楼层和房龄不变的情况下，
#              面积每增加1m²，价格增加3万元
# - 这是"偏效应"或"边际效应"
```

### 3. 显著性检验

```python
# p值的含义：
# "如果真实系数为0，观察到当前结果的概率"

# 例如：
# 面积系数 = 3.0, p值 = 0.001
# 意思：如果面积真的对价格没影响（系数=0），
#       我们观察到系数≥3.0的概率只有0.1%
#       所以我们有99.9%的把握：面积确实有影响！

# 显著性水平：
α = 0.05  # 常用标准
α = 0.01  # 更严格
α = 0.001  # 非常严格

# 判断：
if p值 < α:
    print("拒绝H₀：系数显著不为0")
else:
    print("不能拒绝H₀：系数可能为0")
```

### 4. 置信区间

```python
# 95%置信区间：[2.5, 3.5]
# 含义：我们有95%的把握，真实系数在2.5到3.5之间

# 与显著性的关系：
# - 如果区间不包含0 → 显著（p<0.05）
# - 如果区间包含0 → 不显著（p>0.05）

# 例子：
面积系数 = 3.0, 95% CI = [2.5, 3.5]  # 不含0，显著
楼层系数 = 0.1, 95% CI = [-0.2, 0.4]  # 含0，不显著
```

### 5. 多重共线性

```python
# 问题：两个特征高度相关

# 例子：
特征1 = 面积
特征2 = 房间数（与面积高度相关）

# 后果：
# - 系数不稳定（轻微数据变化导致系数剧变）
# - 标准误变大（显著性下降）
# - 难以解释各特征的独立效应

# 检验：VIF（Variance Inflation Factor）
VIF = 1 / (1 - R²ⱼ)
# R²ⱼ = 用其他特征预测特征j的R²

# 判断：
VIF < 5：无问题
5 ≤ VIF < 10：中等共线性
VIF ≥ 10：严重共线性

# 解决办法：
# 1. 删除高相关的特征
# 2. 合并相关特征
# 3. 主成分分析（PCA）
# 4. 岭回归（Ridge Regression）
```

### 6. AIC 和 BIC

```python
# AIC（Akaike Information Criterion）
# 赤池信息准则
AIC = -2×ln(L) + 2×k
# L = 似然函数, k = 参数个数

# BIC（Bayesian Information Criterion）
# 贝叶斯信息准则
BIC = -2×ln(L) + ln(n)×k
# n = 样本量

# 特点：
# - 越小越好
# - 同时考虑拟合优度和模型复杂度
# - BIC 对复杂度惩罚更重（ln(n) > 2）

# 用途：模型选择
models = [model1, model2, model3]
best_model = min(models, key=lambda m: m.aic)
```

### 练习3：诊断和修正

针对一个模型：
1. 做完整的诊断
2. 识别问题
3. 应用解决方案
4. 比较前后效果
