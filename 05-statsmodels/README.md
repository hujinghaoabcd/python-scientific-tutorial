# Statsmodels 统计建模教程

本模块使用 Statsmodels 0.14.6 系列 API，面向需要“**模型估计 + 统计推断 + 诊断 + 可解释结果**”的学习者。与偏预测导向的机器学习库相比，Statsmodels 更强调参数估计、标准误、置信区间、假设检验和模型诊断。

## 学习目标

- 理解回归建模所需的统计基础；
- 使用 OLS、GLM、混合效应和稳健回归；
- 完成 ARIMA/SARIMAX 等时间序列分析；
- 处理 Logit/Probit 等离散选择模型；
- 使用统计检验和非参数方法；
- 使用 Statsmodels 原生工具完成 Kaplan–Meier 生存函数和 Cox 比例风险模型；
- 对模型假设、残差、置信区间和推断边界进行正确说明。

## 推荐环境

```bash
python -m pip install "statsmodels>=0.14.6,<0.15" "numpy>=2,<3" "pandas>=3,<4" scipy matplotlib
```

推荐使用 Python 3.12–3.14。教程中的示例数据优先使用本地可生成数据或随依赖包提供的数据集，避免把联网下载作为运行前提。

## 建模习惯

1. 明确因变量、解释变量与研究问题；
2. 先做数据质量和描述性分析；
3. 根据数据生成机制选择模型，而不是只看拟合优度；
4. 同时报告系数、区间估计与必要的诊断；
5. 区分统计关联、预测能力和因果解释。

完成后可以进入 [linearmodels 教程](../06-linearmodels/README.md)，继续学习面板数据、工具变量、系统回归和资产定价模型。
