# 第05章：稳健回归和其他回归方法

当数据中有异常值或违反某些假设时，普通最小二乘法（OLS）可能不够用。本章介绍几种更"稳健"的回归方法！

## 为什么需要稳健回归？

### 从生活中理解

**场景1：工资数据中的CEO**

```python
# 公司员工工资数据
普通员工工资 = [3000, 3500, 4000, 4500, 5000, 5500, 6000]  # 7个人
CEO工资 = 500000  # 1个人

# 计算平均工资
平均工资 = (sum(普通员工工资) + CEO工资) / 8
# 结果：67625元

# 问题：
# - 平均工资6.7万，但大部分员工只拿3-6千
# - CEO的高工资严重影响了"代表性"
# - 这就是异常值的影响！

# 解决方案：
# 1. 使用中位数（更稳健）
中位数工资 = 4250元  # 更能代表大多数员工

# 2. 稳健回归（降低异常值的影响）
```

**场景2：房价预测中的豪宅**

```python
# 预测房价：房价 = f(面积)

大部分房子：
50m² → 150万
80m² → 240万
100m² → 300万
120m² → 360万

异常值（豪宅）：
300m² → 5000万  # 远高于正常价格（特殊装修、学区房等）

# 如果用OLS：
# - 模型会被豪宅"拉偏"
# - 对普通房子的预测不准

# 如果用稳健回归：
# - 降低豪宅的影响
# - 对大部分房子预测更准
```

**场景3：测量误差**

```python
# 实验测量：体重 vs 身高

正常数据点：
(160cm, 50kg)
(165cm, 55kg)
(170cm, 60kg)

异常点（测量错误）：
(175cm, 30kg)  # 记录错误！实际应该是130kg

# OLS：
# - 会被错误数据严重影响
# - 拟合线被"拉歪"

# 稳健回归：
# - 自动识别异常点
# - 降低其影响
# - 拟合更合理
```

### OLS的问题

**问题1：对异常值敏感**

```python
# OLS最小化：Σ(yᵢ - ŷᵢ)²
#              ↑
#            平方！

# 问题：
# - 误差平方后被放大
# - 大误差影响巨大
# - 一个异常点可以毁掉整个模型

# 例子：
正常残差：[1, -1, 2, -2, 1.5]
异常残差：[50]

# 平方和：
正常：1² + 1² + 2² + 2² + 1.5² = 12.25
异常：50² = 2500

# 异常值的影响是正常值的 200 倍！
```

**问题2：假设残差正态分布**

```python
# OLS假设：εᵢ ~ N(0, σ²)

# 如果残差有重尾分布（有异常值）：
# - 参数估计有偏
# - 标准误不准
# - 假设检验失效
```

## 稳健回归（Robust Regression）

### 核心思想

```python
# OLS：对所有点一视同仁
# 稳健回归：对异常点降权

# 损失函数对比：

# OLS（L2损失）：
L = Σ(yᵢ - ŷᵢ)²
# 特点：平方，大误差影响大

# 绝对值损失（L1损失）：
L = Σ|yᵢ - ŷᵢ|
# 特点：线性，大误差影响较小

# Huber损失（折中）：
L = Σρ(yᵢ - ŷᵢ)
# 其中：
ρ(r) = r²/2          if |r| ≤ k
ρ(r) = k|r| - k²/2   if |r| > k
# 小误差用平方，大误差用线性
```

### M估计（M-estimators）

```python
# M估计是稳健回归的一大类方法

# 最小化：Σρ(rᵢ) × wᵢ
# 其中：
# rᵢ = 残差
# ρ = 损失函数
# wᵢ = 权重（根据残差大小调整）

# 迭代算法：
# 1. 用OLS得到初始估计
# 2. 计算残差
# 3. 根据残差计算权重（大残差低权重）
# 4. 用加权最小二乘重新估计
# 5. 重复2-4直到收敛
```

### 常用损失函数

```python
import numpy as np
import matplotlib.pyplot as plt

# 定义不同的损失函数
x = np.linspace(-4, 4, 100)

# 1. L2（OLS）
l2 = x ** 2

# 2. L1（绝对值）
l1 = np.abs(x)

# 3. Huber
k = 1.345
huber = np.where(np.abs(x) <= k,
                 x ** 2 / 2,
                 k * np.abs(x) - k ** 2 / 2)

# 4. Tukey's biweight
c = 4.685
tukey = np.where(np.abs(x) <= c,
                 (c ** 2 / 6) * (1 - (1 - (x / c) ** 2) ** 3),
                 c ** 2 / 6)

# 可视化
plt.figure(figsize=(12, 8))

plt.subplot(2, 2, 1)
plt.plot(x, l2, label='L2 (OLS)', lw=2)
plt.xlabel('残差')
plt.ylabel('损失')
plt.title('L2损失（OLS）\n大残差影响大')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(2, 2, 2)
plt.plot(x, l1, label='L1 (LAD)', lw=2, color='orange')
plt.xlabel('残差')
plt.ylabel('损失')
plt.title('L1损失（绝对值）\n对大残差不敏感')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(2, 2, 3)
plt.plot(x, huber, label='Huber', lw=2, color='green')
plt.xlabel('残差')
plt.ylabel('损失')
plt.title('Huber损失\n折中方案')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(2, 2, 4)
plt.plot(x, tukey, label="Tukey's biweight", lw=2, color='red')
plt.xlabel('残差')
plt.ylabel('损失')
plt.title("Tukey's biweight\n极端异常值影响为0")
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 加权最小二乘（WLS）

### 为什么需要WLS？

```python
# OLS假设：同方差（所有点的误差方差相同）
# Var(εᵢ) = σ²  对所有i

# 但实际中常见异方差：
# Var(εᵢ) = σᵢ²  因i而异

# 例子：收入 vs 消费
# 低收入家庭：消费稳定（方差小）
# 高收入家庭：消费波动大（方差大）

# WLS解决方案：
# 给不同观测赋予不同权重
# 方差大的点 → 权重小
# 方差小的点 → 权重大
```

### WLS原理

```python
# WLS最小化加权残差平方和：
Σ wᵢ(yᵢ - ŷᵢ)²

# 其中：wᵢ = 1/σᵢ²
# 即：权重与方差成反比

# 如果知道方差结构：
# σᵢ² = σ² × f(xᵢ)

# 例如：
# σᵢ² ∝ xᵢ  （方差与x成比例）
# → wᵢ = 1/xᵢ

# σᵢ² ∝ xᵢ² （方差与x²成比例）
# → wᵢ = 1/xᵢ²
```

### 完整示例：异方差数据

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm
from statsmodels.stats.diagnostic import het_breuschpagan

# 设置
np.random.seed(42)

# ===== 1. 生成异方差数据 =====
print("="*60)
print("加权最小二乘案例（异方差数据）")
print("="*60)

n = 200
x = np.linspace(1, 10, n)

# 真实关系：y = 2 + 3*x
y_true = 2 + 3 * x

# 异方差噪声：方差与x成比例
noise_std = 0.5 * x  # 标准差与x成比例
noise = np.random.normal(0, noise_std)
y = y_true + noise

df = pd.DataFrame({'x': x, 'y': y})

print(f"数据形状：{df.shape}")

# ===== 2. 可视化异方差 =====
plt.figure(figsize=(12, 5))

# 左图：散点图
plt.subplot(1, 2, 1)
plt.scatter(x, y, alpha=0.5, s=20)
plt.plot(x, y_true, 'r-', lw=2, label='真实关系')
plt.xlabel('x')
plt.ylabel('y')
plt.title('数据分布（注意方差随x增大）')
plt.legend()
plt.grid(True, alpha=0.3)

# 右图：残差 vs x（显示异方差）
y_pred_prelim = 2 + 3 * x
residuals_prelim = y - y_pred_prelim
plt.subplot(1, 2, 2)
plt.scatter(x, residuals_prelim, alpha=0.5, s=20)
plt.axhline(y=0, color='r', linestyle='--')
plt.xlabel('x')
plt.ylabel('残差')
plt.title('残差图（方差随x增大=异方差）')
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# ===== 3. OLS回归（错误）=====
print("\n" + "="*60)
print("方法1：OLS回归（忽略异方差）")
print("="*60)

X = sm.add_constant(df['x'])
model_ols = sm.OLS(df['y'], X)
results_ols = model_ols.fit()

print(results_ols.summary())

# 检验异方差
_, bp_pvalue, _, _ = het_breuschpagan(results_ols.resid, X)
print(f"\nBreusch-Pagan异方差检验：")
print(f"  p值 = {bp_pvalue:.4f}")
if bp_pvalue < 0.05:
    print("  → 存在异方差（p < 0.05）")
else:
    print("  → 无异方差证据（p > 0.05）")

# ===== 4. WLS回归（正确）=====
print("\n" + "="*60)
print("方法2：加权最小二乘（WLS）")
print("="*60)

# 权重 = 1/x（因为方差∝x）
weights = 1 / df['x']

model_wls = sm.WLS(df['y'], X, weights=weights)
results_wls = model_wls.fit()

print(results_wls.summary())

# ===== 5. 对比结果 =====
print("\n" + "="*60)
print("结果对比")
```

## 分位数回归（Quantile Regression）

### 理解分位数回归

```python
# OLS回归：预测条件均值
E(y|x) = β₀ + β₁x

# 分位数回归：预测条件分位数
Q_τ(y|x) = β₀(τ) + β₁(τ)x

# 其中τ∈(0,1)是分位数
# τ = 0.5：中位数回归
# τ = 0.25：下四分位数
# τ = 0.75：上四分位数
```

**为什么需要分位数回归？**

```python
# 场景：研究教育对收入的影响

# OLS：教育每增加1年，平均收入增加5000元
# → 但"平均"可能不够

# 分位数回归可以回答：
# - 对低收入者（Q0.25）：教育增加1年，收入增加3000元
# - 对中等收入者（Q0.50）：教育增加1年，收入增加5000元
# - 对高收入者（Q0.75）：教育增加1年，收入增加8000元

# 发现：教育对高收入者影响更大！
```

### 完整示例：工资与教育

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.api as sm
import statsmodels.formula.api as smf

# 设置
np.random.seed(42)

# ===== 1. 生成模拟数据 =====
print("="*60)
print("分位数回归案例：工资 vs 教育年限")
print("="*60)

n = 500
教育年限 = np.random.uniform(8, 20, n)

# 工资模型：
# - 基础：与教育年限正相关
# - 异质性：高教育者收入差异大
基础工资 = 2000 + 500 * 教育年限
噪声标准差 = 200 + 100 * 教育年限  # 方差随教育增加
噪声 = np.random.normal(0, 噪声标准差)
工资 = 基础工资 + 噪声

df = pd.DataFrame({
    '教育年限': 教育年限,
    '工资': 工资
})

print(f"数据形状：{df.shape}")
print("\n描述统计：")
print(df.describe())

# ===== 2. 可视化 =====
plt.figure(figsize=(12, 5))

# 左图：散点图
plt.subplot(1, 2, 1)
plt.scatter(df['教育年限'], df['工资'], alpha=0.5, s=20)
plt.xlabel('教育年限（年）')
plt.ylabel('工资（元/月）')
plt.title('工资 vs 教育年限\n（注意高教育者工资差异大）')
plt.grid(True, alpha=0.3)

# 右图：按教育年限分组的箱线图
plt.subplot(1, 2, 2)
df['教育分组'] = pd.cut(df['教育年限'], bins=5)
df.boxplot(column='工资', by='教育分组', ax=plt.gca())
plt.xlabel('教育年限分组')
plt.ylabel('工资（元/月）')
plt.title('不同教育水平的工资分布')
plt.suptitle('')

plt.tight_layout()
plt.show()

# ===== 3. OLS回归（均值）=====
print("\n" + "="*60)
print("OLS回归（条件均值）")
print("="*60)

model_ols = smf.ols('工资 ~ 教育年限', data=df)
results_ols = model_ols.fit()

print(results_ols.summary())
print(f"\n解释：教育年限每增加1年，平均工资增加{results_ols.params['教育年限']:.2f}元")

# ===== 4. 分位数回归 =====
print("\n" + "="*60)
print("分位数回归（不同分位数）")
print("="*60)

# 拟合多个分位数
quantiles = [0.1, 0.25, 0.5, 0.75, 0.9]
results_quantile = {}

for q in quantiles:
    model_q = smf.quantreg('工资 ~ 教育年限', data=df)
    results_quantile[q] = model_q.fit(q=q)

    print(f"\n{q*100:.0f}%分位数回归：")
    print(f"  截距：{results_quantile[q].params['Intercept']:.2f}")
    print(f"  斜率：{results_quantile[q].params['教育年限']:.2f}")
    print(f"  → 教育年限每增加1年，{q*100:.0f}%分位数工资增加{results_quantile[q].params['教育年限']:.2f}元")

# ===== 5. 系数对比 =====
print("\n" + "="*60)
print("系数对比")
print("="*60)

coef_comparison = pd.DataFrame({
    '分位数': ['OLS(均值)'] + [f'Q{q}' for q in quantiles],
    '截距': [results_ols.params['Intercept']] +
            [results_quantile[q].params['Intercept'] for q in quantiles],
    '教育年限系数': [results_ols.params['教育年限']] +
                    [results_quantile[q].params['教育年限'] for q in quantiles]
})

print("\n", coef_comparison)

# ===== 6. 可视化所有分位数回归 =====
print("\n" + "="*60)
print("可视化")
print("="*60)

plt.figure(figsize=(14, 6))

# 左图：所有拟合线
plt.subplot(1, 2, 1)
plt.scatter(df['教育年限'], df['工资'], alpha=0.3, s=20, label='数据')

x_range = np.linspace(df['教育年限'].min(), df['教育年限'].max(), 100)

# OLS线
y_ols = results_ols.params['Intercept'] + results_ols.params['教育年限'] * x_range
plt.plot(x_range, y_ols, 'k-', lw=3, label='OLS（均值）', zorder=10)

# 分位数线
colors = ['#1f77b4', '#ff7f0e', '#2ca02c', '#d62728', '#9467bd']
for i, q in enumerate(quantiles):
    y_q = (results_quantile[q].params['Intercept'] +
           results_quantile[q].params['教育年限'] * x_range)
    plt.plot(x_range, y_q, '--', lw=2,
            color=colors[i], label=f'Q{q}', alpha=0.8)

plt.xlabel('教育年限（年）')
plt.ylabel('工资（元/月）')
plt.title('分位数回归 vs OLS')
plt.legend(loc='upper left')
plt.grid(True, alpha=0.3)

# 右图：系数随分位数变化
plt.subplot(1, 2, 2)
slopes = [results_quantile[q].params['教育年限'] for q in quantiles]
plt.plot(quantiles, slopes, 'o-', lw=2, markersize=8)
plt.axhline(y=results_ols.params['教育年限'],
           color='red', linestyle='--', lw=2, label='OLS系数')
plt.xlabel('分位数τ')
plt.ylabel('教育年限系数')
plt.title('教育年限效应随分位数变化')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

print("\n发现：")
print("  - Q0.1（低收入）：教育每增加1年，工资增加约400元")
print("  - Q0.5（中等收入）：教育每增加1年，工资增加约500元")
print("  - Q0.9（高收入）：教育每增加1年，工资增加约600元")
print("  → 教育对高收入者的影响更大！")

print("\n" + "="*60)
print("分析完成！")
print("="*60)
```

## 方法选择指南

```python
# 决策树：选择合适的回归方法

数据有什么问题？
├─ 有异常值？
│  ├─ 少数几个异常值
│  │  └─ 稳健回归（Huber、Tukey）
│  └─ 想完全忽略异常值
│     └─ 中位数回归（Q0.5分位数回归）
│
├─ 有异方差？
│  ├─ 知道方差结构
│  │  └─ WLS（加权最小二乘）
│  └─ 不知道方差结构
│     └─ 用异方差稳健标准误（HC）
│
├─ 想研究分布的不同位置？
│  └─ 分位数回归
│
└─ 数据都正常？
   └─ OLS

# 组合使用：
# - 稳健回归 + 异方差稳健标准误
# - WLS + 稳健回归
```

## 实战建议

### 1. 异常值诊断

```python
# 步骤：
# 1. 画散点图和残差图
# 2. 计算标准化残差
standardized_resid = results.resid_pearson

# 3. 识别异常值（|标准化残差| > 3）
outliers = np.abs(standardized_resid) > 3

# 4. 检查杠杆值（leverage）
from statsmodels.stats.outliers_influence import OLSInfluence
influence = OLSInfluence(results)
leverage = influence.hat_matrix_diag

# 5. Cook距离（综合影响）
cooks_d = influence.cooks_distance[0]
```

### 2. 异方差检验

```python
# 方法1：Breusch-Pagan检验
from statsmodels.stats.diagnostic import het_breuschpagan
_, pval, _, _ = het_breuschpagan(results.resid, X)

# 方法2：White检验
from statsmodels.stats.diagnostic import het_white
_, pval, _, _ = het_white(results.resid, X)

# 方法3：残差图（视觉检查）
plt.scatter(results.fittedvalues, results.resid)
# 如果呈喇叭形 → 异方差
```

### 3. 选择权重（WLS）

```python
# 方法1：已知方差结构
weights = 1 / sigma_squared

# 方法2：两步法
# Step 1: OLS得到残差
results_ols = sm.OLS(y, X).fit()
resid = results_ols.resid

# Step 2: 用|残差|对X回归，预测方差
var_model = sm.OLS(np.abs(resid), X).fit()
predicted_var = var_model.fittedvalues ** 2
weights = 1 / predicted_var

# Step 3: 用权重做WLS
results_wls = sm.WLS(y, X, weights=weights).fit()
```
