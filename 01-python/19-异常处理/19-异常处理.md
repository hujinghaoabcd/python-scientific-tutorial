# 第19章：异常处理

学习如何优雅地处理错误，让程序更健壮、用户体验更好。

## 什么是异常？

### 从生活中理解异常

想象一下这个场景：你开车去上班，正常情况下一切顺利。但突然：
- 车没油了 ⛽
- 前方道路施工，需要绕路 🚧
- 遇到了交通事故 🚗

如果你没有任何应对措施，你就会被困在路上，无法到达公司。但如果你：
- **提前检查油量**，油不够就去加油（预防异常）
- **遇到施工时看导航**，找到替代路线（处理异常）
- **发生事故时打电话**，联系拖车和保险（异常恢复）

这样你就能处理这些"意外情况"，最终还是能到达目的地。

**程序中的异常就是这样的"意外情况"**：
- 用户输入了无效的数据（比如要求输入数字，却输入了文字）
- 要读取的文件不存在
- 网络连接突然断开
- 除数为零
- 内存不足

如果不处理这些异常，程序就会像车没油一样"抛锚"——直接崩溃！

### 异常处理的重要性

让我们看一个真实的例子。假设你写了一个在线商城的订单系统：

```python
# 没有异常处理的代码 - 危险！
def process_order(order_id):
    order = database.get_order(order_id)  # 如果订单不存在？崩溃！
    payment = process_payment(order.amount)  # 如果支付失败？崩溃！
    inventory = update_inventory(order.items)  # 如果库存不足？崩溃！
    send_confirmation_email(order.email)  # 如果邮件服务器宕机？崩溃！
    return "订单处理成功"

# 用户看到的结果：白屏、500错误、或者程序直接退出
# 更糟糕的是：可能钱扣了，但订单没处理，商品也没发货！
```

现在我们加上异常处理：

```python
# 有异常处理的代码 - 安全！
def process_order(order_id):
    try:
        # 尝试获取订单
        order = database.get_order(order_id)
    except OrderNotFoundError:
        return "订单不存在，请检查订单号"

    try:
        # 尝试处理支付
        payment = process_payment(order.amount)
    except PaymentFailedError as e:
        return f"支付失败：{e.reason}，请检查支付方式"

    try:
        # 尝试更新库存
        inventory = update_inventory(order.items)
    except InsufficientStockError:
        # 支付成功但库存不足，需要退款
        refund_payment(payment)
        return "商品库存不足，已退款到原支付账户"

    try:
        # 尝试发送确认邮件
        send_confirmation_email(order.email)
    except EmailError:
        # 邮件发送失败不影响订单，记录到日志即可
        log_warning("确认邮件发送失败")

    return "订单处理成功！"

# 用户看到的结果：清晰的错误提示，或者成功消息
# 最重要的是：每一步都在控制之中，不会出现数据不一致的情况！
```

看到区别了吗？**异常处理让你的程序从"脆弱易碎"变成"坚韧可靠"**！

### 异常 vs 错误：有什么区别？

很多初学者会混淆这两个概念：

**语法错误（Syntax Error）**：
- 代码写错了，Python解释器连运行都不让
- 就像写作文时写了错别字，老师连看都不看就退回来
- 必须修改代码才能运行

```python
# 语法错误示例
if x > 10  # 缺少冒号，这是语法错误
    print("大于10")

# Python直接报错：SyntaxError: invalid syntax
# 程序根本不会运行
```

**异常（Exception）**：
- 代码语法正确，但运行时出现了问题
- 就像作文没有错别字，但内容有问题（比如数据不对）
- 可以通过try-except来处理，让程序继续运行

```python
# 异常示例
x = 10
y = 0
result = x / y  # 语法正确，但运行时会出错

# Python运行时报错：ZeroDivisionError: division by zero
# 但这个错误可以通过try-except来捕获和处理
```

**简单记忆**：
- **语法错误** = 代码本身写错了，**必须改代码**
- **异常** = 代码没错，但运行时遇到了问题，**可以通过代码处理**

### 不处理异常会怎样？

让我们看一个现实中的例子：

```python
# 一个简单的用户注册程序
def register_user():
    print("=== 用户注册 ===")
    username = input("请输入用户名: ")
    age = int(input("请输入年龄: "))  # 如果用户输入"abc"呢？
    email = input("请输入邮箱: ")

    # 保存到文件
    with open("users.txt", "a") as f:
        f.write(f"{username},{age},{email}\n")

    print("注册成功！")

# 测试运行
register_user()

# 如果用户输入年龄时输入了"二十岁"：
# === 用户注册 ===
# 请输入用户名: 张三
# 请输入年龄: 二十岁
# Traceback (most recent call last):
#   File "register.py", line 3, in register_user
#     age = int(input("请输入年龄: "))
# ValueError: invalid literal for int() with base 10: '二十岁'
#
# 程序直接崩溃！用户看到一堆错误信息，体验很差
```

加上异常处理后：

```python
# 改进的注册程序
def register_user():
    print("=== 用户注册 ===")
    username = input("请输入用户名: ")

    # 处理年龄输入的异常
    while True:
        try:
            age = int(input("请输入年龄: "))
            if age < 0 or age > 150:
                print("年龄不合理，请输入0-150之间的数字")
                continue
            break  # 输入有效，跳出循环
        except ValueError:
            print("年龄必须是数字，请重新输入")

    email = input("请输入邮箱: ")

    # 处理文件写入的异常
    try:
        with open("users.txt", "a", encoding="utf-8") as f:
            f.write(f"{username},{age},{email}\n")
        print("注册成功！")
    except PermissionError:
        print("无法保存用户信息：没有文件写入权限")
    except IOError as e:
        print(f"保存失败：{e}")

# 测试运行
register_user()

# 现在的用户体验：
# === 用户注册 ===
# 请输入用户名: 张三
# 请输入年龄: 二十岁
# 年龄必须是数字，请重新输入
# 请输入年龄: 20
# 请输入邮箱: zhangsan@example.com
# 注册成功！
#
# 程序不会崩溃，而是友好地提示用户重新输入！
```

**总结一下异常处理的好处**：
1. **程序不会崩溃** - 即使出错也能继续运行
2. **用户体验好** - 显示友好的错误提示，而不是吓人的错误堆栈
3. **数据安全** - 可以在出错时回滚操作，避免数据不一致
4. **易于调试** - 可以记录详细的错误信息到日志文件
5. **代码健壮** - 考虑了各种边界情况，更可靠

**异常（Exception）** 是程序运行时发生的错误。如果不处理，程序就会崩溃。

```python
# 不处理异常 - 程序崩溃
result = 10 / 0  # ZeroDivisionError: division by zero
print("这行不会执行")

# 处理异常 - 程序继续运行
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零")
    result = 0
print("程序继续运行")  # 这行会执行
```

### 为什么需要异常处理？

```python
# 没有异常处理的程序
def divide(a, b):
    return a / b

result = divide(10, 0)  # 崩溃！
print("后续代码不执行")

# 有异常处理的程序
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("除数不能为0")
        return None

result = safe_divide(10, 0)
print("程序正常继续")  # 继续运行
```

## 常见的异常类型

Python中有很多内置的异常类型，每种异常都对应一种特定的错误情况。就像医院里的科室一样，不同的病要去不同的科室看：
- 肚子疼去消化科
- 头疼去神经科
- 牙疼去口腔科

Python的异常也是这样，不同的错误有不同的异常类型。让我们来认识这些"常见病"！

### 1. ZeroDivisionError - 除以零错误

**什么时候发生**：当你试图用0作为除数时

**生活中的例子**：10个苹果要平均分给0个人，怎么分？这在数学上是没有意义的。

```python
# 最基本的除以零错误
try:
    result = 10 / 0
except ZeroDivisionError:
    print("不能除以零！")

# 实际场景：计算平均分
def calculate_average(scores):
    """计算平均分"""
    try:
        total = sum(scores)
        count = len(scores)
        average = total / count  # 如果scores是空列表，count=0就会出错
        return average
    except ZeroDivisionError:
        print("错误：没有任何分数，无法计算平均值")
        return None

# 测试
print(calculate_average([80, 90, 100]))  # 90.0
print(calculate_average([]))  # 错误：没有任何分数，无法计算平均值

# 实际场景：计算比率
def calculate_ratio(part, total):
    """计算百分比"""
    try:
        ratio = (part / total) * 100
        return f"{ratio:.2f}%"
    except ZeroDivisionError:
        return "总数不能为0"

print(calculate_ratio(5, 10))  # 50.00%
print(calculate_ratio(5, 0))   # 总数不能为0
```

### 2. ValueError - 值错误

**什么时候发生**：函数接收到的参数类型正确，但值不合适

**生活中的例子**：你去银行存钱，柜员问你存多少，你说"一些"。类型对了（都是在说数量），但这个值不具体，无法处理。

```python
# 类型转换失败 - 最常见的ValueError
try:
    age = int("二十岁")  # 字符串无法转换为整数
except ValueError:
    print("无法将'二十岁'转换为数字")

try:
    price = float("¥99.99")  # 包含货币符号，无法转换
except ValueError:
    print("价格格式错误")

# 实际场景：安全的用户输入
def get_positive_integer(prompt):
    """获取正整数输入，带完整的错误处理"""
    while True:
        user_input = input(prompt)

        # 检查是否为空
        if not user_input.strip():
            print("输入不能为空，请重新输入")
            continue

        try:
            number = int(user_input)

            # 值的范围检查
            if number <= 0:
                print("必须输入正整数（大于0）")
                continue

            return number

        except ValueError:
            print(f"'{user_input}' 不是有效的整数，请输入数字")

# 使用
# age = get_positive_integer("请输入年龄: ")

# 其他ValueError场景
try:
    # 列表中查找不存在的值
    numbers = [1, 2, 3, 4, 5]
    index = numbers.index(10)  # 10不在列表中
except ValueError:
    print("值不在列表中")

try:
    # 解包时数量不匹配
    a, b = [1, 2, 3]  # 左边2个变量，右边3个值
except ValueError as e:
    print(f"解包错误：{e}")  # too many values to unpack
```

### 3. TypeError - 类型错误

**什么时候发生**：对不兼容的类型进行操作

**生活中的例子**：你想用扳手拧螺丝（可以），但用螺丝刀切菜（类型不对）。

```python
# 不同类型之间的运算
try:
    result = "hello" + 5  # 字符串不能和数字相加
except TypeError:
    print("不能把字符串和数字相加")

# 正确做法：先转换类型
result = "hello" + str(5)  # "hello5"
print(result)

# 函数参数类型错误
try:
    number = len(123)  # len()期望的是序列，不是数字
except TypeError:
    print("len()不能用于数字")

# 实际场景：数据处理
def calculate_total(prices):
    """计算总价，带类型检查"""
    try:
        total = sum(prices)
        return total
    except TypeError:
        print("错误：prices必须是数字列表")
        return None

print(calculate_total([10, 20, 30]))  # 60
print(calculate_total([10, "20", 30]))  # 错误：包含非数字元素

# 调用不可调用的对象
try:
    x = 10
    result = x()  # 10不是函数，不能调用
except TypeError:
    print("这个对象不是函数，不能调用")

# 字符串格式化类型错误
try:
    result = "%d" % "hello"  # %d期望数字，不是字符串
except TypeError:
    print("格式化类型不匹配")
```

### 4. FileNotFoundError - 文件不存在

**什么时候发生**：试图打开一个不存在的文件

**生活中的例子**：你想打开家门，但找不到钥匙（文件不存在）。

```python
# 基本的文件不存在错误
try:
    with open("nonexistent.txt", "r") as f:
        content = f.read()
except FileNotFoundError:
    print("文件不存在")

# 实际场景：读取配置文件
def load_config(filename):
    """加载配置文件，不存在时使用默认配置"""
    try:
        with open(filename, "r", encoding="utf-8") as f:
            config = f.read()
        print(f"配置文件 {filename} 加载成功")
        return config
    except FileNotFoundError:
        print(f"⚠️  配置文件 {filename} 不存在，使用默认配置")
        default_config = "host=localhost\nport=8080"
        # 可以选择创建默认配置文件
        with open(filename, "w", encoding="utf-8") as f:
            f.write(default_config)
        return default_config

config = load_config("app_config.txt")

# 实际场景：读取用户数据
def read_user_data(username):
    """读取用户数据文件"""
    filename = f"users/{username}.txt"
    try:
        with open(filename, "r", encoding="utf-8") as f:
            data = f.read()
        return data
    except FileNotFoundError:
        return f"用户 {username} 不存在"

print(read_user_data("zhangsan"))
```

### 5. KeyError - 字典键不存在

**什么时候发生**：访问字典中不存在的键

**生活中的例子**：你想从抽屉里拿"护照"，但抽屉里根本没有护照。

```python
# 基本的KeyError
try:
    data = {"name": "张三", "age": 20}
    city = data["city"]  # 'city'这个键不存在
except KeyError:
    print("键 'city' 不存在")

# 正确做法：使用get()方法
city = data.get("city", "未知")  # 如果键不存在，返回默认值"未知"
print(f"城市：{city}")

# 实际场景：处理API响应
def get_user_email(user_data):
    """从用户数据中提取邮箱"""
    try:
        email = user_data["contact"]["email"]
        return email
    except KeyError as e:
        print(f"数据不完整，缺少键：{e}")
        return None

# 测试数据
user1 = {"name": "张三", "contact": {"email": "zhangsan@example.com"}}
user2 = {"name": "李四"}  # 缺少contact

print(get_user_email(user1))  # zhangsan@example.com
print(get_user_email(user2))  # 数据不完整，缺少键：'contact'

# 实际场景：配置管理
class Config:
    """配置管理类"""
    def __init__(self):
        self.settings = {
            "app_name": "我的应用",
            "version": "1.0.0"
        }

    def get(self, key, default=None):
        """安全地获取配置"""
        try:
            return self.settings[key]
        except KeyError:
            if default is not None:
                return default
            else:
                raise KeyError(f"配置项 '{key}' 不存在且没有提供默认值")

config = Config()
print(config.get("app_name"))  # 我的应用
print(config.get("database", "sqlite"))  # sqlite（使用默认值）
```

### 6. IndexError - 索引超出范围

**什么时候发生**：访问列表或元组时，索引超出了有效范围

**生活中的例子**：一栋楼只有10层，你却按电梯去20楼。

```python
# 基本的IndexError
try:
    numbers = [1, 2, 3, 4, 5]
    value = numbers[10]  # 索引10超出范围（最大索引是4）
except IndexError:
    print("索引超出列表范围")

# 实际场景：安全地获取列表元素
def safe_get(lst, index, default=None):
    """安全地获取列表元素"""
    try:
        return lst[index]
    except IndexError:
        print(f"索引 {index} 超出范围（列表长度：{len(lst)}）")
        return default

numbers = [10, 20, 30]
print(safe_get(numbers, 1))   # 20
print(safe_get(numbers, 10))  # 索引10超出范围，返回None

# 实际场景：处理命令行参数
import sys

def get_command_arg(index, default=None):
    """获取命令行参数"""
    try:
        return sys.argv[index]
    except IndexError:
        return default

# 使用
# filename = get_command_arg(1, "default.txt")

# 实际场景：分割字符串后访问
def parse_user_input(text):
    """解析用户输入：name,age,city"""
    try:
        parts = text.split(",")
        name = parts[0].strip()
        age = int(parts[1].strip())
        city = parts[2].strip()
        return {"name": name, "age": age, "city": city}
    except IndexError:
        print("输入格式错误，应该是：姓名,年龄,城市")
        return None
    except ValueError:
        print("年龄必须是数字")
        return None

print(parse_user_input("张三,20,北京"))  # {'name': '张三', 'age': 20, 'city': '北京'}
print(parse_user_input("张三,20"))  # 输入格式错误
```

### 7. AttributeError - 属性不存在

**什么时候发生**：访问对象不存在的属性或方法

**生活中的例子**：你想调节电风扇的"制冷模式"，但电风扇只能吹风，没有制冷功能。

```python
# 基本的AttributeError
try:
    result = "hello".nonexistent_method()  # 字符串没有这个方法
except AttributeError:
    print("字符串对象没有这个方法")

# 访问不存在的属性
try:
    text = "hello"
    length = text.length  # 正确的是len(text)，不是text.length
except AttributeError:
    print("字符串没有length属性")

# 实际场景：动态访问属性
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person("张三", 20)

def get_attribute(obj, attr_name, default=None):
    """安全地获取对象属性"""
    try:
        return getattr(obj, attr_name)
    except AttributeError:
        print(f"对象没有属性 '{attr_name}'")
        return default

print(get_attribute(person, "name"))   # 张三
print(get_attribute(person, "email"))  # 对象没有属性 'email'，返回None

# 实际场景：检查对象是否有某个方法
def call_if_exists(obj, method_name, *args):
    """如果方法存在就调用它"""
    try:
        method = getattr(obj, method_name)
        if callable(method):
            return method(*args)
    except AttributeError:
        print(f"对象没有方法 '{method_name}'")
        return None

# 测试
text = "hello"
print(call_if_exists(text, "upper"))  # HELLO
print(call_if_exists(text, "foo"))    # 对象没有方法 'foo'
```

### 8. ImportError / ModuleNotFoundError - 导入失败

**什么时候发生**：导入的模块不存在

**生活中的例子**：你想借用工具箱里的电钻，但工具箱里根本没有电钻。

```python
# 基本的ImportError
try:
    import nonexistent_module  # 这个模块不存在
except ImportError:
    print("模块不存在")

# ModuleNotFoundError (Python 3.6+，更具体的错误)
try:
    import some_random_package
except ModuleNotFoundError:
    print("找不到这个包，可能需要先安装：pip install some_random_package")

# 实际场景：可选依赖
def use_advanced_features():
    """尝试使用高级功能（需要额外的包）"""
    try:
        import numpy as np
        print("使用NumPy进行高级计算")
        return np.array([1, 2, 3])
    except ImportError:
        print("⚠️  NumPy未安装，使用基本功能")
        return [1, 2, 3]

result = use_advanced_features()

# 实际场景：跨平台兼容
```

### 异常类型总结

| 异常类型 | 触发条件 | 常见场景 | 预防方法 |
|---------|---------|---------|---------|
| `ZeroDivisionError` | 除数为0 | 计算平均值、比率 | 检查除数是否为0 |
| `ValueError` | 值不合适 | 类型转换、数据验证 | 验证输入的格式和范围 |
| `TypeError` | 类型不匹配 | 不同类型运算 | 检查数据类型 |
| `FileNotFoundError` | 文件不存在 | 读取文件 | 检查文件是否存在 |
| `KeyError` | 字典键不存在 | 访问字典 | 使用get()或in检查 |
| `IndexError` | 索引超出范围 | 访问列表/元组 | 检查索引是否在有效范围 |
| `AttributeError` | 属性不存在 | 访问对象属性 | 使用hasattr()检查 |
| `ImportError` | 导入失败 | 导入模块 | 确保模块已安装 |

**选择正确的异常类型**就像看病要去对的科室一样重要！如果你捕获了错误的异常类型，就像去牙科看胃病，问题还是解决不了。

## try-except基础

### 基本语法

try-except是Python中处理异常的基本结构，就像给代码穿上"防护服"：

```python
try:
    # 这里放可能出错的代码（危险区域）
    risky_code()
except ExceptionType:
    # 如果出错了，执行这里的代码（应急措施）
    handle_error()
```

**工作原理**（就像保险一样）：

1. **正常情况**：try块中的代码顺利执行，except块被忽略
   ```python
   try:
       result = 10 / 2  # 没问题，正常执行
       print(result)    # 5.0
   except ZeroDivisionError:
       print("除以零")   # 这行不会执行
   ```

2. **异常情况**：try块中出错，立即跳转到对应的except块
   ```python
   try:
       result = 10 / 0  # 出错！
       print("这行不执行")  # 跳过这里
   except ZeroDivisionError:
       print("除以零")  # 执行这里
   ```

```python
# 版本2：智能转换（处理浮点数）
def safe_int_v2(value):
    """智能地转换为整数"""
    try:
        # 先转为字符串并去空格
        value = str(value).strip()

        # 如果包含小数点，先转为float再转为int
        if '.' in value:
            return int(float(value))
        else:
            return int(value)

    except ValueError:
        print(f"无法转换：'{value}' 不是有效的数字")

    except Exception as e:
        print(f"转换错误：{e}")
        return None

print(safe_int_v2("  123  "))  # 123（处理了空格）
print(safe_int_v2("12.5"))     # 12（处理了小数）
print(safe_int_v2("abc"))      # 无法转换

def parse_number(value, default=None, allow_float=False):
    """
    解析数字（生产级）

    参数:
        value: 要转换的值
        default: 转换失败时的默认值
        allow_float: 是否允许浮点数

    返回:
        转换后的数字，失败返回default
    """
    try:
        # 处理None
        if value is None:
            return default

        # 转为字符串并清理
        value_str = str(value).strip()

        # 处理空字符串
        if not value_str:
            print("⚠️  输入为空")
            return default

        # 转换
        if allow_float:
            result = float(value_str)
        else:
            # 如果不允许浮点数，但输入是小数字符串，四舍五入
            if '.' in value_str:
                result = int(round(float(value_str)))
            else:
                result = int(value_str)

        return result

    except ValueError:
        print(f"'{value}' 不是有效的数字格式")
        return default
    except Exception as e:
        print(f"转换出错：{type(e).__name__}: {e}")
        return default

# 测试

print(parse_number("12.7"))                   # 13（四舍五入）
print(parse_number("12.7", allow_float=True)) # 12.7
print(parse_number("abc", default=0))         # 不是有效数字，返回0
print(parse_number("", default=-1))           # ⚠️  输入为空，返回-1
print(parse_number(None, default=100))        # 100

            print("请重新输入")
            continue

        if price < 0:
            print("价格不能为负数")
            continue

        return price
```

```python
class InputValidator:
    """输入验证器"""

    @staticmethod
    def get_integer(prompt, min_value=None, max_value=None):
        """获取整数输入"""
        while True:
            try:
                value = int(input(prompt))

                if min_value is not None and value < min_value:

                    continue

                return None

    @staticmethod
    def get_float(prompt, positive=False):
        """获取浮点数输入"""

                value = float(input(prompt))

                if positive and value <= 0:
                    print("值必须为正数")

                return value

            except ValueError:
                print("请输入有效的数字")
            except KeyboardInterrupt:
                print("\n操作已取消")
                return None

    @staticmethod
    def get_choice(prompt, choices):
        """获取选择（从列表中）"""
        while True:
            print(prompt)
            for i, choice in enumerate(choices, 1):
                print(f"{i}. {choice}")

            try:
                index = int(input("请选择(输入数字): ")) - 1

                if 0 <= index < len(choices):
                    return choices[index]
                else:
                    print("无效的选择")

            except ValueError:
                print("请输入数字")
            except KeyboardInterrupt:
                print("\n操作已取消")
                return None

# 使用
age = InputValidator.get_integer("请输入年龄: ", min_value=0, max_value=150)
price = InputValidator.get_float("请输入价格: ", positive=True)
fruit = InputValidator.get_choice("选择水果:", ["苹果", "香蕉", "橙子"])

print(f"年龄：{age}，价格：{price}，水果：{fruit}")
```

### 例子4：配置文件加载

```python
import json

class ConfigLoader:
    """配置文件加载器"""

    def __init__(self, filename):
        self.filename = filename
        self.config = {}

    def load(self):
        """加载配置"""
        try:
            with open(self.filename, "r", encoding="utf-8") as f:
                self.config = json.load(f)
            print(f"配置加载成功：{self.filename}")
            return True

        except FileNotFoundError:
            print(f"配置文件不存在：{self.filename}")
            self._create_default_config()
            return False

        except json.JSONDecodeError as e:
            print(f"配置文件格式错误：{e}")
            return False

        except Exception as e:
            print(f"加载配置失败：{e}")
            return False

    def _create_default_config(self):
        """创建默认配置"""
        default_config = {
            "host": "localhost",
            "port": 8080,
            "debug": True
        }

        try:
            with open(self.filename, "w", encoding="utf-8") as f:
                json.dump(default_config, f, indent=2)
            print(f"已创建默认配置：{self.filename}")
            self.config = default_config
        except Exception as e:
            print(f"创建默认配置失败：{e}")

    def get(self, key, default=None):
        """获取配置项"""
        return self.config.get(key, default)

# 使用
config = ConfigLoader("app_config.json")
if config.load():
    host = config.get("host")
    port = config.get("port")
    print(f"服务器：{host}:{port}")
```

### 例子5：批量处理任务

```python
def process_batch(items):
    """
    批量处理任务，记录成功和失败
    """
    results = {
        "success": [],
        "failed": []
    }

    for i, item in enumerate(items):
        try:
            # 处理单个项目
            result = process_item(item)
            results["success"].append({
                "index": i,
                "item": item,
                "result": result
            })

        except ValueError as e:
            # 记录失败的项目
            results["failed"].append({
                "index": i,
                "item": item,
                "error": str(e),
                "type": "ValueError"
            })

        except Exception as e:
            results["failed"].append({
                "index": i,
                "item": item,
                "error": str(e),
                "type": type(e).__name__
            })

    return results

def process_item(item):
    """处理单个项目（模拟）"""
    if not isinstance(item, (int, float)):
        raise ValueError(f"无效的数据类型：{type(item)}")
    if item < 0:
        raise ValueError("值不能为负数")
    return item * 2

# 使用
items = [10, 20, -5, "abc", 30, None, 40]
results = process_batch(items)

print(f"成功：{len(results['success'])} 个")
print(f"失败：{len(results['failed'])} 个")

print("\n失败的项目：")
for failed in results["failed"]:
    print(f"  索引 {failed['index']}: {failed['item']} - {failed['error']}")
```

## 常见陷阱

### 陷阱1：捕获异常后吞掉错误

```python
# 错误 - 捕获后什么都不做
try:
    important_operation()
except:
    pass  # 错误被吞掉，无法调试

# 正确 - 至少记录错误
try:
    important_operation()
except Exception as e:
    print(f"操作失败：{e}")
    # 或者记录到日志
    logging.error(f"操作失败：{e}")
```

### 陷阱2：捕获范围过大

```python
# 错误 - 捕获所有异常
try:
    value = int(input())
    result = 10 / value
except:  # 连KeyboardInterrupt都捕获了
    print("出错了")

# 正确 - 只捕获特定异常
try:
    value = int(input())
    result = 10 / value
except ValueError:
    print("输入无效")
except ZeroDivisionError:
    print("不能除以0")
```

### 陷阱3：异常处理代码中又出错

```python
# 危险 - except块中可能出错
try:
    value = data["key"]
except KeyError:
    # 这里可能引发另一个异常
    log_error(undefined_variable)  # NameError!

# 正确 - 确保except块安全
try:
    value = data["key"]
except KeyError as e:
    # 安全的错误处理
    error_message = str(e)
    print(f"键不存在：{error_message}")
```

### 陷阱4：finally中return

```python
# 错误 - finally中return会覆盖异常
def bad_function():
    try:
        return 1 / 0
    finally:
        return "finally"  # 异常被吞掉！

result = bad_function()  # 返回 "finally"，没有抛出异常

# 正确 - finally只做清理
def good_function():
    try:
        return 1 / 0
    finally:
        print("清理资源")  # 只做清理，不return
```

## 最佳实践

### 1. 捕获具体的异常

```python
# 好
try:
    value = int(user_input)
except ValueError:
    handle_invalid_input()

# 不好
try:
    value = int(user_input)
except:
    handle_error()  # 太宽泛
```

### 2. 不要忽略异常

```python
# 不好
try:
    operation()
except Exception:
    pass  # 忽略所有错误

# 好
try:
    operation()
except Exception as e:
    logger.error(f"操作失败：{e}")
```

### 3. 在合适的层级处理异常

```python
# 好 - 在合适的层级处理
def low_level_function():
    # 不处理，让上层决定
    return int(value)

def high_level_function():
    try:
        result = low_level_function()
        return result
    except ValueError:
        # 在这里处理更合适
        show_error_to_user("输入无效")
        return None
```

### 4. 使用上下文管理器

```python
# 好 - 自动清理
with open("file.txt", "r") as f:
    content = f.read()
# 文件自动关闭

# 而不是
f = open("file.txt", "r")
try:
    content = f.read()
finally:
    f.close()
```

### 5. 提供有用的错误信息

```python
# 不好
raise ValueError("Error")

# 好
raise ValueError(f"无效的年龄值：{age}，必须在0-150之间")
```

## 调试技巧

### 打印异常的详细信息

```python
import traceback

try:
    problematic_code()
except Exception as e:
    # 打印异常类型和消息

```
