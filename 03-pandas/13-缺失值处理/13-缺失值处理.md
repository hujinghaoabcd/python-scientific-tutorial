# 第13章：缺失值处理

缺失值处理不是“看到空值就填掉”，而是一个需要结合业务含义、缺失机制和模型目标做判断的过程。本章面向 Pandas 3.x，系统介绍缺失值识别、统计、删除、填充、插值、分组处理和质量评估。

## 13.1 Pandas 中的缺失值

Pandas 常见缺失标记包括 `np.nan`、`pd.NA`、`pd.NaT` 和 Python 的 `None`。对于可空整数、布尔和字符串，优先使用 Pandas 的可空 dtype。

```python
import numpy as np
import pandas as pd

df = pd.DataFrame({
    "float": [1.0, np.nan, 3.0],
    "int_nullable": pd.array([1, pd.NA, 3], dtype="Int64"),
    "bool_nullable": pd.array([True, pd.NA, False], dtype="boolean"),
    "string": pd.array(["A", pd.NA, "C"], dtype="string"),
    "datetime": pd.to_datetime(["2026-01-01", None, "2026-01-03"]),
})

print(df)
print(df.dtypes)
print(df.isna())
```

> 不要直接用 `x == np.nan` 判断缺失。统一使用 `isna()` / `notna()`。

## 13.2 先统计，再决定怎么处理

```python
summary = pd.DataFrame({
    "missing_count": df.isna().sum(),
    "missing_ratio": df.isna().mean(),
    "dtype": df.dtypes.astype(str),
}).sort_values("missing_ratio", ascending=False)

print(summary)
```

还可以检查“某些列是否同时缺失”：

```python
missing_pattern = df.isna().value_counts(dropna=False)
print(missing_pattern)
```

实际项目中建议至少回答三个问题：

1. 缺失比例多大？
2. 缺失是否集中在特定时间、地区、群体或数据源？
3. 缺失本身是否携带信息？

## 13.3 删除缺失值

当缺失比例很低且缺失近似随机时，可以删除行；当某列几乎不可用时，可以考虑删除列。

```python
raw = pd.DataFrame({
    "x": [1, 2, np.nan, 4],
    "y": [10, np.nan, 30, 40],
    "group": ["A", "A", "B", "B"],
})

# 任意列缺失就删除
print(raw.dropna())

# 只关注关键列
print(raw.dropna(subset=["x"]))

# 至少保留两个非缺失值
print(raw.dropna(thresh=2))
```

删除前应保留原始数据，避免不可逆操作。

## 13.4 常数、统计量和映射填充

```python
sales = pd.DataFrame({
    "amount": [120, np.nan, 98, 150, np.nan],
    "city": ["南京", "南京", None, "苏州", "苏州"],
})

# 数值列：中位数通常比均值更抗异常值
sales["amount_filled"] = sales["amount"].fillna(sales["amount"].median())

# 类别列：可用明确的“未知”标签
sales["city_filled"] = sales["city"].fillna("未知")

# 不同列使用不同值
filled = sales.fillna({"amount": 0, "city": "未知"})
print(filled)
```

## 13.5 前向填充与后向填充

Pandas 3.x 中推荐直接调用 `ffill()` 和 `bfill()`，避免旧式的 method 参数填充写法。

```python
s = pd.Series([10, np.nan, np.nan, 20, np.nan, 30])

print(s.ffill())
print(s.bfill())
print(s.ffill(limit=1))
```

前向填充特别适合“状态在下一次更新前保持不变”的业务数据；它不适合价格、浓度等本身持续变化的变量。

## 13.6 插值

```python
dates = pd.date_range("2026-01-01", periods=8, freq="D")
ts = pd.Series([10, 12, np.nan, np.nan, 20, 23, np.nan, 28], index=dates)

linear = ts.interpolate()
time_based = ts.interpolate(method="time")

print(linear)
print(time_based)
```

如果使用多项式或样条插值，需要 SciPy：

```python
spline = ts.interpolate(method="spline", order=3)
print(spline)
```

插值适用于变量随索引有连续变化关系的场景。不要为了“填满数据”而对本来离散、突变或事件型变量做高阶插值。

## 13.7 分组内填充

不同群体的分布差异明显时，使用全局均值可能产生偏差。

```python
scores = pd.DataFrame({
    "class": ["A", "A", "A", "B", "B", "B"],
    "score": [80, np.nan, 90, 60, np.nan, 70],
})

scores["score_filled"] = (
    scores.groupby("class")["score"]
    .transform(lambda s: s.fillna(s.median()))
)

print(scores)
```

时间序列分组也可以前向填充：

```python
panel = pd.DataFrame({
    "station": ["S1", "S1", "S1", "S2", "S2", "S2"],
    "value": [1.0, np.nan, 3.0, 10.0, np.nan, 12.0],
})

panel["value_ffill"] = panel.groupby("station")["value"].ffill()
```

## 13.8 可空 dtype 与类型转换

```python
raw = pd.DataFrame({
    "count": ["1", "2", None, "4"],
    "flag": ["true", "false", None, "true"],
})

raw["count"] = pd.to_numeric(raw["count"], errors="coerce").astype("Int64")
raw["flag"] = raw["flag"].map({"true": True, "false": False}).astype("boolean")
print(raw.dtypes)
```

可空 dtype 的优势是：既能保留缺失值，又不必把整数列强制转换成浮点数。

## 13.9 机器学习填充：什么时候才需要

简单规则不足以描述变量关系时，可以使用 `scikit-learn` 的插补器。但要注意：**插补器只能在训练集上拟合，再用于验证集/测试集**，否则会发生数据泄漏。

```python
import pandas as pd
from sklearn.impute import KNNImputer

train = pd.DataFrame({
    "x1": [1, 2, None, 4, 5],
    "x2": [10, None, 30, 40, 50],
    "x3": [100, 200, 300, None, 500],
})

imputer = KNNImputer(n_neighbors=2)
filled = pd.DataFrame(
    imputer.fit_transform(train),
    columns=train.columns,
    index=train.index,
)
print(filled)
```

## 13.10 缺失指示变量

有些业务中，“是否缺失”本身具有预测价值。

```python
customers = pd.DataFrame({
    "income": [5000, None, 9000, None],
})

customers["income_missing"] = customers["income"].isna().astype("int8")
customers["income"] = customers["income"].fillna(customers["income"].median())
print(customers)
```

是否保留缺失指示变量要结合领域知识和验证结果判断。

## 13.11 一套可复用的数据质量报告

```python
def missing_report(frame: pd.DataFrame) -> pd.DataFrame:
    report = pd.DataFrame({
        "dtype": frame.dtypes.astype(str),
        "missing_count": frame.isna().sum(),
        "missing_ratio": frame.isna().mean(),
        "unique": frame.nunique(dropna=True),
    })
    return report.sort_values("missing_ratio", ascending=False)

print(missing_report(sales))
```

## 13.12 处理策略建议

| 场景 | 常见策略 | 风险 |
| --- | --- | --- |
| 缺失极少且近似随机 | 删除少量行 | 样本量下降 |
| 数值分布偏态 | 中位数填充 | 方差被压缩 |
| 类别值缺失 | 众数或“未知” | 可能掩盖缺失机制 |
| 连续时间序列 | 插值、ffill/bfill | 可能制造不存在的趋势 |
| 分组差异明显 | 组内统计量填充 | 小组样本不足时不稳定 |
| 建模任务 | Pipeline 中插补 | 必须避免数据泄漏 |

## 13.13 常见错误

### 错误 1：用全量数据计算填充值

模型评估时会泄漏测试集信息。应只在训练数据上估计填充值。

### 错误 2：把所有列都填 0

0 可能是一个真实、有含义的观测值，不能默认代表缺失。

### 错误 3：高阶插值过度拟合

三次样条或高阶多项式可能产生超出合理范围的值，必须做边界检查。

### 错误 4：没有记录填充规则

正式分析中应记录“哪些列、为何缺失、采用什么规则、填充多少值”，保证结果可追溯。
