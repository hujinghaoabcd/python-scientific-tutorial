# Pandas 数据分析教程

本模块面向 Pandas 3.x，覆盖从 `Series`、`DataFrame` 到数据清洗、合并、分组、时间序列、缺失值、字符串处理和性能优化的完整工作流。示例尽量采用当前 API，而不是延续已经弃用的历史写法。

## 学习目标

- 熟练使用 `Series` 与 `DataFrame`；
- 掌握标签索引、布尔筛选和安全赋值；
- 完成清洗、连接、分组、聚合、重塑与透视；
- 正确处理日期时间、缺失值和字符串；
- 理解 dtype 对正确性、内存和性能的影响；
- 能够从文件读取数据、完成分析并导出结果；
- 建立“先保证正确，再测量性能”的优化习惯。

## 推荐环境

```bash
python -m pip install "pandas>=3,<4" openpyxl matplotlib
```

### Pandas 3.x 使用习惯

- 前向/后向填充直接使用 `ffill()` 与 `bfill()`；
- 月末、季末等时间偏移量使用明确的现代别名；
- 避免链式赋值，优先使用 `.loc[...] = ...`；
- 不假设“就地修改”天然更快或更省内存，实际优化应通过基准测试验证；
- 大文件优先考虑 `usecols`、`dtype`、分块读取和更合适的存储格式。
